# 数字系统设计

## 概述

数字系统
: 具有存储、传输、处理信息能力的逻辑系统集合

数字系统由"**数据通路 + 控制逻辑**"构成，其工作具有周期性。

!!! note "数字系统与逻辑功能部件的本质区别"
    数字系统与逻辑功能部件的关键区别在于**有无控制器**。逻辑功能部件（如加法器、编码器）只能完成固定的单一功能；数字系统则通过控制器协调数据通路，实现复杂的、周期性的信息处理流程。

数据通路
: 在各部件之间传送信息的公共通路，由总线连接的运算单元（组合电路）和存储单元构成

## 设计方法

### 自顶向下方法

自顶向下方法（Top-Down）是将规模较大的系统从逻辑上划分为**控制电路 + 受控电路**，逐步细化设计。

!!! tip "自顶向下的设计理念"
    从系统整体出发，先确定控制逻辑与数据通路的分工，再逐层细化到子模块，确保系统功能的完整性与一致性。

### 设计步骤

自顶向下方法的具体设计步骤如下：

- [x] **划分子系统、子模块**：将整体系统按功能分解为若干子系统与子模块，明确各模块的功能边界与接口
- [x] **设计数据通路**：确定各模块之间的数据流向与传输路径，构建由总线、运算单元和存储单元组成的数据通路
- [x] **描述控制器控制过程**：使用数学语言（工具）精确描述控制器的控制过程，明确状态转换与控制信号
- [x] **设计控制器**：根据控制过程的描述，实现控制器的逻辑设计，输出控制信号以协调数据通路
- [x] **设计数据处理器**：在控制器信号的驱动下，完成数据通路中各处理单元的详细设计
