# 算法复杂度分析

算法复杂度分析是算法设计与分析的核心工具，为评估和比较不同算法的效率提供理论基础。本文涵盖渐近复杂性分析与递归方程求解两大主题。

## 渐近复杂性分析

### 算法的定义与性质

算法是解决特定问题的一种方法，或一个业务逻辑/处理流程。从计算机角度，算法是对问题求解过程的形式化或半形式化描述。算法必须满足以下四个性质：

输入
: 算法有零个或多个外部提供的输入量。

输出
: 算法有一个或多个输出量，与输入之间存在某种确定关系。

确定性
: 算法的每一步操作必须有精确的定义，无二义性。

有限性
: 算法必须在有限的步骤内终止，不能无限执行。

!!! tip "算法 vs 程序"
    算法强调**有限性**——必须在有限步骤内结束；程序则不一定满足此条件（如操作系统的主循环是无限运行的）。算法是问题的解法描述，程序是算法在特定语言下的具体实现。

### 时间复杂性

$T(n)$
: 算法中**简单操作执行次数关于问题规模 $n$ 的函数**。只与问题规模 $n$ 有关，默认取最坏情况。

$T(n, I)$
: 同时考虑规模 $n$ 和输入特征 $I$ 的时间复杂性函数。

!!! info "$T(n)$ 与 $T(n, I)$ 的区别"
    - $T(n)$：只与**问题规模 $n$** 有关，隐含取**最坏情况**。
    - $T(n, I)$：同时考虑规模 $n$ 和**输入特征 $I$**，能够区分同一规模下不同输入的差异。

### 最好、最坏与平均复杂性

对于同一规模 $n$ 的不同输入，算法的执行时间可能差异很大。根据对输入的假设不同，可以得到三种复杂性度量：

最坏情况复杂性
: 对规模 $n$ 的所有可能输入，取运行时间的**最大值**。给出算法运行时间的上界保证，是最常用的度量方式。

最好情况复杂性
: 对规模 $n$ 的所有可能输入，取运行时间的**最小值**。反映算法在最理想输入下的表现，实际意义较小。

平均情况复杂性
: 对规模 $n$ 的所有可能输入，取运行时间的**数学期望**（需假设输入的概率分布）。能更真实地反映算法的实际性能，但分析通常较复杂。

!!! warning "最优算法"
    若某算法在最坏情况下的时间复杂性下界与该问题的复杂性下界相同，则称该算法为**最优算法**。注意：最优算法指的是在最坏情况下与问题下界匹配，而非指平均情况下表现最好。

### 渐近上界符号 $O$

当输入 $n$ 趋近于无穷大时的**渐进上界**，用于表示算法的最坏情况运行时间。

???+ definition "大 $O$ 符号的正式定义"
    若存在常数 $c_0 > 0$ 和 $n_0 \in \mathbb{N}$，使得对所有 $n \ge n_0$，都有

    $$T(n) \le c_0 \cdot f(n)$$

    则记 $T(n) = O(f(n))$。

### 渐进下界符号 $\Omega$

当输入 $n$ 趋近于无穷大时的**渐进下界**，用于表示算法的最好情况运行时间或某个问题的计算复杂度下界。

???+ definition "大 $\Omega$ 符号的正式定义"
    若存在常数 $c_0 > 0$ 和 $n_0 \in \mathbb{N}$，使得对所有 $n \ge n_0$，都有

    $$T(n) \ge c_0 \cdot g(n)$$

    则记 $T(n) = \Omega(g(n))$。

<figure markdown="span">
  ![渐进下界符号](https://webp-pic.yokumi.cn/2025/09/20250925202518677.png){ loading=lazy width="70%" }
</figure>

### 紧渐近界符号 $\Theta$

即同时满足大 $O$ 和大 $\Omega$ 条件，表示算法的运行时间与某函数**同阶**。

???+ definition "大 $\Theta$ 符号的正式定义"
    若存在常数 $c_1 > 0$、$c_2 > 0$ 和 $n_0 \in \mathbb{N}$，使得对所有 $n \ge n_0$，都有

    $$c_1 \cdot h(n) \le T(n) \le c_2 \cdot h(n)$$

    则记 $T(n) = \Theta(h(n))$。

<figure markdown="span">
  ![紧渐近界符号](https://webp-pic.yokumi.cn/2025/09/20250925203951449.png){ loading=lazy width="70%" }
</figure>

!!! tip "$O$、$\Omega$、$\Theta$ 的关系"
    - $T(n) = \Theta(h(n))$ 当且仅当 $T(n) = O(h(n))$ **且** $T(n) = \Omega(h(n))$。
    - $\Theta$ 给出的是**紧界**，既不高于也不低于真实增长率。
    - $O$ 只给出上界（可能宽松），$\Omega$ 只给出下界（可能宽松）。

### 非紧上界符号 $o$

小 $o$ 符号表示**严格低于**的渐近关系，即 $f(n)$ 的增长率严格小于 $g(n)$。

???+ definition "小 $o$ 符号的正式定义"
    若对**任意**常数 $c > 0$，存在 $n_0 \in \mathbb{N}$，使得对所有 $n \ge n_0$，都有

    $$T(n) < c \cdot f(n)$$

    则记 $T(n) = o(f(n))$。

    等价定义：

    $$\lim_{n \to \infty} \frac{T(n)}{f(n)} = 0$$

<figure markdown="span">
  ![非紧上界符号](https://webp-pic.yokumi.cn/2025/09/20250925204201305.png){ loading=lazy width="70%" }
</figure>

### 非紧下界符号 $\omega$

小 $\omega$ 符号表示**严格高于**的渐近关系，即 $f(n)$ 的增长率严格大于 $g(n)$。

???+ definition "小 $\omega$ 符号的正式定义"
    若对**任意**常数 $c > 0$，存在 $n_0 \in \mathbb{N}$，使得对所有 $n \ge n_0$，都有

    $$T(n) > c \cdot g(n)$$

    则记 $T(n) = \omega(g(n))$。

    等价定义：

    $$\lim_{n \to \infty} \frac{T(n)}{g(n)} = \infty$$

<figure markdown="span">
  ![非紧下界符号](https://webp-pic.yokumi.cn/2025/09/20250925204243335.png){ loading=lazy width="70%" }
</figure>

???+ note "五种渐近符号对比"
    | 符号 | 含义 | 严格性 | 极限定义 |
    |------|------|--------|----------|
    | $O$ | 渐进上界 | $\le$（非紧） | $\lim \le c$ |
    | $\Omega$ | 渐进下界 | $\ge$（非紧） | $\lim \ge c$ |
    | $\Theta$ | 紧渐近界 | $=$（同阶） | $\lim = c \in (0, \infty)$ |
    | $o$ | 非紧上界 | $<$（严格低） | $\lim = 0$ |
    | $\omega$ | 非紧下界 | $>$（严格高） | $\lim = \infty$ |


## 递归方程求解

当算法采用递归或分治结构时，其时间复杂性通常满足递归方程的形式。本节介绍用**特征方程法**求解线性齐次递归方程。

### 递推方程的基本形式

一般递推方程的形式为：

$$T(n) = a \, T\!\left(\frac{n}{b}\right) + f(n)$$

其中：

- $a$：子问题个数
- $n/b$：子问题规模
- $f(n)$：分解与合并的代价

!!! info "递推方程的求解方法"
    对于形如 $T(n) = a \, T(n/b) + f(n)$ 的递推方程，常用 **主定理（Master Theorem）** 求解。本文重点介绍特征方程法，主定理将在分治策略章节中详细展开。

### 特征方程法

对于**线性齐次递归方程**，标准形式如下：

$$T(n) = a_1 T(n-1) + a_2 T(n-2) + \cdots + a_k T(n-k)$$

右侧不存在**非递归项**（齐次），即所有项均为 $T$ 的递归调用。

???+ info "齐次 vs 非齐次"
    - **齐次**：递归方程右侧只含递归项，不含常数或其他非递归函数。
    - **非齐次**：递归方程右侧含有非递归项（如常数、多项式等）。本文仅讨论齐次情形。

求解步骤如下：

1.  写出递归方程；
2.  设解的形式为 $T(n) = r^n$；
3.  代入递归方程，得到**特征方程**；
4.  求解特征方程，根据根的情况确定通解。

### 无重根情况

当特征方程的所有根 $r_1, r_2, \ldots, r_k$ **互不相同**时，通解为：

$$\boxed{T(n) = c_1 r_1^n + c_2 r_2^n + \cdots + c_k r_k^n}$$

其中 $c_1, c_2, \ldots, c_k$ 由初始条件确定。

???+ example "无重根求解示例"
    递归方程：$T(n) = 5T(n-1) - 6T(n-2)$，初始条件 $T(0) = 1$, $T(1) = 2$。

    1. 设 $T(n) = r^n$，代入得 $r^n = 5r^{n-1} - 6r^{n-2}$。
    2. 两边除以 $r^{n-2}$（$r \neq 0$），得特征方程 $r^2 - 5r + 6 = 0$。
    3. 解得 $r_1 = 2$, $r_2 = 3$，无重根。
    4. 通解：$T(n) = c_1 \cdot 2^n + c_2 \cdot 3^n$。
    5. 代入初始条件：
       - $T(0) = c_1 + c_2 = 1$
       - $T(1) = 2c_1 + 3c_2 = 2$
       - 解得 $c_1 = 1$, $c_2 = 0$。
    6. 最终解：$T(n) = 2^n$。

### 有重根情况

当特征方程出现重根 $r$，重数为 $k$ 时，对应的通解为：

$$\boxed{T(n) = (c_1 + c_2 n + c_3 n^2 + \cdots + c_k n^{k-1}) \, r^n}$$

即对重数为 $k$ 的根 $r$，通解中需乘以 $n$ 的 $0$ 到 $k-1$ 次幂的线性组合。

???+ example "有重根求解示例"
    递归方程：$T(n) = 4T(n-1) - 4T(n-2)$，初始条件 $T(0) = 1$, $T(1) = 3$。

    1. 设 $T(n) = r^n$，代入得特征方程 $r^2 - 4r + 4 = 0$。
    2. 解得 $r = 2$（二重根）。
    3. 通解：$T(n) = (c_1 + c_2 n) \cdot 2^n$。
    4. 代入初始条件：
       - $T(0) = c_1 = 1$
       - $T(1) = (c_1 + c_2) \cdot 2 = 3 \Rightarrow c_2 = \frac{1}{2}$
    5. 最终解：$T(n) = (1 + \frac{1}{2}n) \cdot 2^n$。
