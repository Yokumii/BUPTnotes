# 指令系统

## 指令分类

微指令
: 微程序级的命令，属于**硬件**

机器指令
: 介于微指令与宏指令之间，单独一条即可完成一个独立的算术/逻辑运算

宏指令
: 由若干条机器指令组成的软件指令，属于**软件**

!!! abstract "指令系统 ISA (Instruction Set Architecture)"
    指令系统也称**指令集架构**，包含了所有机器指令的集合，定义机器级程序的格式和行为，以及处理器状态。

    指令系统应满足以下要求：

    - **完备性**：指令系统应提供足够的指令以满足各种功能需求
    - **有效性**：指令系统应能高效地执行各种操作
    - **规整性**：
        - 对称性：寄存器和存储器单元同等对待，都可以使用各种寻址方式
        - 匀齐性：一种操作性质的指令可以支持各种数据类型
        - 一致性：指令长度与数据长度有一定关系
    - **兼容性**：向后兼容，即旧处理器上运行的软件仍可以在新处理器上运行

## 指令格式

指令字（即指令）
: 表示一条指令的机器字

指令格式
: 指令字用二进制表示的结构形式。由以下两部分构成：

    操作码 OP 字段
    : 长度取决于指令集的规模

    地址码字段
    : 指定参与操作的操作数的地址。一条指令地址码部分有 $x$ 个操作地址，则称该指令为 $x$ 操作数指令或 $x$ 地址指令

### 按操作数物理位置分类

存储器-存储器（SS）型指令
: 操作数都存在内存中

寄存器-寄存器（RR）型指令
: 操作数都存在寄存器中，不需要访问内存

寄存器-存储器（RS）型指令
: 一个操作数在寄存器中，另一个在内存中

### 按指令字长度分类

- 单字长指令
- 半字长指令
- 双字长指令

???+ info "多字长指令"
    多字长指令能提供更大的地址空间，但必须多次访问内存取出一整条指令。

指令字结构可分为**等长指令字结构**与**变长指令字结构**。

- 二进制操作码 $\rightarrow$ 助记符：**反汇编**

## 寻址方式

在存储器中，读/写操作数或指令字的方式有：

- 地址指定方式（最主要）
- 相联存储方式（按内容寻址）
- 堆栈存取方式

### 指令寻址

#### 顺序寻址

通过**程序计数器 PC** 来计数指令的顺序号，该顺序号就是指令在内存中的地址。

#### 跳跃寻址

用于实现条件转移、无条件转移和子程序调用等。

### 操作数寻址

形成操作数有效地址的方法称为操作数寻址方法。一种单地址指令的结构如下：

<figure markdown="span">
  ![单地址指令结构](https://webp-pic.yokumi.cn/2026/01/20260101165616326.png){ loading=lazy width="70%" }
</figure>

操作数地址由变址 X、间址 I、形式地址 A（也称偏移量 offset）组成。

#### 隐含寻址

隐含寻址
: 隐含默认地给出操作数的地址

#### 立即寻址

立即寻址
: 地址码字段是操作数本身而不是操作数的地址（**立即数**），不需要访存

    有效地址：A 即是操作数

    访存次数：0

#### 直接寻址

直接寻址
: 在地址码字段直接给出操作数在内存中的地址 A，即形式地址 A 就是操作数的有效地址 EA

    有效地址：

    $$EA = A$$

    访存次数：1

#### 间接寻址

间接寻址
: 在地址码字段给出的是操作数地址的地址，需要两次访存

    有效地址：

    $$EA = (A)$$

    访存次数：2

???+ info "寻址特征位"
    一般用寻址特征位 $I$ 区分直接寻址和间接寻址：$I = 0$ 表示直接寻址，$I = 1$ 表示间接寻址。

#### 寄存器寻址

寄存器寻址
: 操作数地址不是内存地址，而是寄存器的编号。地址码字段直接取指定寄存器的内容就是操作数

    有效地址：$EA = R_i$

    访存次数：0

#### 寄存器间接寻址

寄存器间接寻址
: 地址码字段指定的寄存器的内容是操作数的地址

    有效地址：$EA = (R_i)$

    访存次数：1

#### 偏移寻址

偏移寻址将某个寄存器的内容加上偏移量 A（有符号数）形成有效地址。

##### 相对寻址

<figure markdown="span">
  ![相对寻址](https://webp-pic.yokumi.cn/2026/01/20260101165619136.png){ loading=lazy width="70%" }
</figure>

相对寻址
: 程序计数器 PC 的内容加上偏移量 A（有符号数）形成操作数的有效地址

    有效地址：

    $$EA = (PC) + A$$

    访存次数：1

##### 基址寻址

<figure markdown="span">
  ![基址寻址](https://webp-pic.yokumi.cn/2026/01/20260101165621927.png){ loading=lazy width="70%" }
</figure>

基址寻址
: 基址寄存器的内容加上偏移量 A（有符号数）形成操作数的有效地址

    有效地址：

    $$EA = (BR) + A$$

    访存次数：1

##### 变址寻址

变址寻址
: 变址寄存器的内容加上偏移量 A（有符号数）形成操作数的有效地址，变址寄存器的内容会自动递增或递减

    有效地址：

    $$EA = (IX) + A$$

    访存次数：1

???+ tip "变址寻址与数组访问"
    数组访问适合用**变址寻址**，因为变址寄存器的内容会自动递增或递减，可以方便地遍历数组元素。

#### 寻址方式汇总

| 寻址方式 | 有效地址 | 访存次数 |
| --- | --- | --- |
| 立即寻址 | A 即是操作数 | 0 |
| 直接寻址 | $EA = A$ | 1 |
| 一次间接寻址 | $EA = (A)$ | 2 |
| 寄存器寻址 | $EA = R_i$ | 0 |
| 寄存器间接一次寻址 | $EA = (R_i)$ | 1 |
| 相对寻址 | $EA = (PC) + A$ | 1 |
| 基址寻址 | $EA = (BR) + A$ | 1 |
| 变址寻址 | $EA = (IX) + A$ | 1 |

!!! warning "注意"
    **主存地址不能为负数**，但偏移量可以为负，所以注意直接寻址中的地址范围。

### 堆栈寻址

堆栈是一块能存储数据的存储区域，且数据的存取一般只能通过栈顶进行，其特点是"后进先出"（LIFO）。

#### 寄存器堆栈（硬堆栈）

- **栈顶不动，数据移动**
- 数据的读出具有破坏性
- 堆栈大小受限

#### 存储器堆栈（软堆栈）

在主存中划分出一片堆栈区域，CPU 用一个专门的寄存器 **SP（Stack Pointer，栈顶指示器）** 存储栈顶的位置。

- **栈顶移动，数据不动**
- 堆栈空间可以自行分配
- 栈顶指示有 2 种方式：
    - SP 指向空单元
    - SP 指向满单元

## CISC 与 RISC

### CISC (Complex Instruction Set Computer，复杂指令集)

- 指令系统庞大
- 指令长度不固定
- 指令格式复杂
- 寻址方式多
- 通用寄存器数量少
- 各种指令的指令时间相差很大
- 各种指令的使用频度相差较大
- 使用**微程序控制器**

### RISC (Reduced Instruction Set Computer，精简指令集)

- 选取使用频率最高的一些简单指令，指令数量少
- 指令长度固定
- 指令格式种类少
- 寻址方式简单
- 只有 Load / Store 指令访问存储器，其他均在寄存器之间进行
- 通用寄存器数量较多，减少访存次数
- 大部分指令在一个机器周期内完成
- 使用**硬布线控制器**

### 对比

| 特性 | CISC | RISC |
| --- | --- | --- |
| 指令数量 | 多、复杂（上百种） | 少、简单（几十种） |
| 指令长度 | 不固定，指令格式复杂 | 固定长度 |
| 执行时间 | 每条指令执行时间不确定 | 一般在一个机器周期内完成 |
| 指令使用频度 | 差异很大 | 差异不大，都比较常用 |
| 寻址方式 | 多种寻址方式 | 寻址方式较少，简单 |
| 操作对象 | 内存和寄存器都可操作，访问存储器的指令不受限制 | **只操作寄存器**，访问内存需专门指令（Load/Store） |
| 通用寄存器数量 | 较少 | 较多，减少访存次数 |
| 控制器 | **微程序控制方式** | **硬布线控制逻辑** |
| 编译 | 难以用优化编译生成高效的目标代码 | 编译器技术优化 |
| 性能优化方式 | 各种指令执行时间相差很大，不利于流水线处理 | 大部分指令都能在一个机器周期内完成，采用**流水线**技术 |

???+ info "RISC 的代价"
    RISC 由于指令结构精简，**每条指令功能简单**，往往需要通过组合实现复杂功能，编译器的设计难度和编程难度增大，兼容性差于 CISC。
