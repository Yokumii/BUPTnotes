# 外围设备

外围设备（Peripheral Device）是计算机系统中除主机（CPU + 主存）以外的所有设备，大致由三部分组成：

存储介质
: 保存信息的物理载体

驱动装置
: 驱动存储介质移动的机械部件

控制电路
: 控制数据读写与传输的电子线路

!!! info "外围设备的分类"
    外围设备按功能可分为**输入设备**、**输出设备**、**外存设备**和**通信设备**等。本章重点讨论磁盘、磁带、光盘等外存设备以及显示设备。

## 磁盘存储器

磁盘又称磁表面存储器（如硬盘等），是最重要的外存设备之一。

!!! tip "磁盘的优点与缺点"
    **优点**

    - 存储容量大
    - 位成本低
    - 记录介质可重复使用
    - 记录信息可长久保存
    - 非破坏性读出

    **缺点**

    - 存取速度较慢
    - 机械结构复杂

!!! abstract "关键概念：柱面"
    **柱面**（Cylinder）是所有磁盘面上**相同编号磁道**的集合。磁盘按**记录面 → 柱面 → 扇区**的层次组织信息。

磁盘的关键技术指标如下：

#### 存储密度

道密度
: 沿磁盘半径方向单位长度的磁道数，单位：道/英寸（TPI）

位密度
: 磁道单位长度上能记录的二进制代码位数，单位：位/英寸（bPI）

面密度
: 位密度 $\times$ 道密度，单位：位/平方英寸

#### 存储容量

非格式化容量
: 磁记录表面可利用的磁化单元总数：

$$C_{非格式化} = \text{磁头数} \times \text{磁道(柱面)数} \times \text{内圈周长} \times \text{位密度}$$

???+ warning "注意"
    部分教材给出的非格式化容量公式为：

    $$C_{非格式化} = \text{磁头数} \times \text{磁道(柱面)数} \times \text{每道扇区数} \times \text{每扇区字节数}$$

    此公式实际上计算的是格式化后的容量形式。严格来说，非格式化容量应以内圈周长乘以位密度为基础计算。

格式化容量
: 用户真正可使用的容量，因记录格式占用部分空间，一般为非格式化容量的 $60\% \sim 70\%$：

$$C_{格式化} = \text{磁头数} \times \text{柱面数} \times \text{每道扇区数} \times \text{每扇区字节数}$$

#### 平均存取时间

平均存取时间 $T_a$ 是从发出读/写命令到完成**1 个扇区**数据读/写所需的总时间：

$$T_a = T_{avg\_seek} + T_{avg\_rotation} + T_{avg\_trans}$$

寻道时间 $T_{seek}$
: 将磁头移动至目标磁道的时间，$T_{avg\_seek} = 3 \sim 10\text{ms}$

旋转等待时间 $T_{rotation}$
: 目标扇区旋转到磁头下的时间，通常取平均值（旋转 1/2 圈所需时间）。用 RPM（Round Per Minute）表示转速：

$$T_{avg\_rotation} = \frac{1}{2} \times \frac{60}{\text{RPM}} \text{ (秒)}$$

传送时间 $T_{trans}$
: 读出/写入 1 个扇区数据所需的时间，$S$ 为每磁道平均扇区数：

$$T_{avg\_trans} = \frac{1}{\text{RPM}} \times \frac{1}{S} \times 60 \text{ (秒)}$$

#### 数据传输率

数据传输率指单位时间内磁盘与主机间传输的数据量：

$$\text{数据传输率} = \text{每转传输的数据} \times \text{转速}$$

#### 磁盘地址格式

磁盘地址由以下字段组成：

$$\text{磁盘地址} = \text{组号} + \text{柱面号} + \text{记录面号} + \text{扇区号}$$

!!! abstract "最小寻址单位"
    磁盘的最小寻址单位是**扇区（Sector）**，而非字节或磁道。

### 提高磁盘 I/O 速度的手段

???+ info "三种主要手段"
    - **加快磁盘机主轴转速**：旋转时间和传送时间均减小，平均存取时间减小
    - **提高 I/O 总线速度**：缩短数据在总线上的传输时间
    - **采用磁盘 Cache**：弥补慢速磁盘和主存之间的速度差异
        - 由硬件和软件共同完成
        - 可采用 SRAM 或 DRAM 实现

### 磁盘阵列 RAID

RAID（Redundant Arrays of Independent Disks）即**独立磁盘冗余阵列**，将多个硬盘组合成一个逻辑磁盘，利用**数据分块**和**并行处理**技术在多个磁盘上交错存放数据，使之可以**并行存取**；同时磁盘可存有**冗余信息**，一旦某磁盘失效，可利用冗余信息重建用户数据。

!!! tip "RAID 的优点"
    - 传输速率快
    - 有容错功能
    - 成本低

常见 RAID 级别：

RAID 0：数据条带方式
: 无冗余信息，无校验码；多个磁盘以条带为单位交替存放数据，实现并行读写；简单但无容错能力

RAID 1：镜像方式
: 具有 $100\%$ 数据冗余，每个磁盘都有完整的镜像副本，提供最高的数据安全保障；空间利用率低（仅为 $50\%$）

???+ info "更高级别的 RAID"
    RAID 2 及之后级别均引入了校验码机制，在保证一定容错能力的同时兼顾空间利用率，如 RAID 5 采用分布式奇偶校验等。

总之，RAID 通过同时使用多个磁盘提高了传输速率；通过并行存取大幅提高存储系统的数据吞吐量；通过镜像功能提高安全可靠性；通过数据校验提供容错能力。

## 磁带存储器

磁带是另一种磁表面存储器，了解其与磁盘的区别即可：

| **比较项** | **磁盘** | **磁带** |
| --- | --- | --- |
| 读写方式 | **直接访问（DAM）**，即**随机访问**（任意位置可读写） | **顺序访问**（从头到尾依次读写） |
| 速度 | 较快（可随机寻址） | 较慢（需前进/倒带） |

!!! abstract "磁带 vs. 磁盘"
    磁盘属于**直接存取存储器（DAM）**，支持随机访问；磁带属于**顺序存取存储器（SAM）**，必须从头到尾依次读写。磁盘适合频繁随机读写场景，磁带适合大批量备份与归档。

## 光盘存储器

光盘的读写原理：

- 记录信息以**凹坑方式永久性存储**，根据反射光的光强变化并进行光电转换，即可读出记录信息
- 信息记录的轨迹称为**光道**
- 光道上划分出一个个扇区，**扇区是光盘的最小可寻址单位**

???+ info "光盘的分类"
    按读写特性，光盘可分为：

    - **只读型**（CD-ROM）：出厂时数据已写入，不可修改
    - **一次写入型**（WORM / CD-R）：可写入一次，之后只读
    - **可擦写型**（CD-RW / DVD-RW）：可多次读写

## 显示设备

### 显示系统组成

显示系统由**显示器**和**显示适配器**（即显卡）组成：

显示器
: 输出视觉信息的设备

显示适配器（显卡）
: 控制显示器工作的接口电路

    - **集成显卡**：集成在主板或 CPU 上
    - **独立显卡**：单独插在总线插槽上

### CRT 显示器

CRT（Cathode Ray Tube）显示器是经典的显示设备类型，其关键计算涉及**刷新存储器**。

刷新存储器（VRAM）是为刷新屏幕提供信号的存储器，其容量和带宽取决于分辨率与灰度级：

!!! abstract "刷新存储器的关键计算"
    **容量**

    $$\text{VRAM 容量} = \text{分辨率} \times \text{灰度级位数}$$

    ???+ example "示例"
        若分辨率为 $1024 \times 768$，灰度级为 256 色（即 8 位），则：

        $$\text{容量} = 1024 \times 768 \times 8 = 6291456 \text{ bit} = 768 \text{ KB}$$

    **带宽**

    $$\text{VRAM 带宽} = \text{分辨率} \times \text{灰度级位数} \times \text{刷新率}$$

    ???+ example "示例"
        若分辨率为 $1024 \times 768$，灰度级 256 色，刷新率 60 Hz，则：

        $$\text{带宽} = 1024 \times 768 \times 8 \times 60 = 47185920 \text{ bit/s} \approx 47.2 \text{ Mbit/s}$$

!!! warning "存取周期要求"
    刷新存储器的存取周期必须满足刷新频率的要求，即存取周期 $\le \frac{1}{\text{分辨率} \times \text{刷新率}}$。
