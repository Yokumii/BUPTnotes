# 离散数学概述

离散数学是计算机科学与技术的核心基础课程，涵盖代数结构、图论等分支，为程序设计语言、算法分析、数据结构、密码学等领域提供理论支撑。

## 代数结构

代数结构部分以群论为核心，从半群逐步推广到群，讨论同态、同构等映射关系以及乘积半群、商半群的构造方法。

涉及的笔记篇目：

群论Intro
: 群论的基本概念引入，包括代数系统的定义与性质

半群、同态、同构
: 半群与独异点的定义，以及同态、同构映射的概念与性质

乘积半群、商半群
: 由已知半群构造新半群的两种方法——乘积与商

群
: 群的定义、性质、子群、循环群与置换群等核心内容


## 图论

图论部分从基本概念出发，逐步讨论欧拉环游与哈密尔顿环游、平面图、匹配问题及染色问题等经典主题。

涉及的笔记篇目：

图论基本概念
: 图的定义、度、路径、连通性、子图等基础概念

欧拉环游和哈密尔顿环游
: 欧拉图与哈密尔顿图的判定条件及相关性质

平面图
: 平面图的定义、Euler 公式、 Kuratowski 定理等

图论有关题型
: 图论常见题型的解题思路与方法总结

匹配问题
: 二部图匹配、最大匹配、完美匹配与 Hall 婚姻定理

图的染色问题
: 顶点染色、边染色、色数及相关定理
