# C 语言程序设计

## 数据类型与变量

### 存储单元

位（bit）
: 计算机中最小的存储单元，只能存储 0 或 1。

字（word）
: 设计计算机时运算单元给定的**整数运算的数据通路宽度**。因此，计算机中每个数据的二进制位数都是固定长度的。

### 数据数字化

计算机内部一切信息均以二进制表示。汉字同样需要数字化编码才能在计算机中存储和处理。

### 数据类型

数据类型
: 包括两层含义：

    1. **值的集合**：定义了属于该类型的数据能够取值的范围。
    2. **操作集合**：定义了能应用于这些数值上的数据操作。

C 语言的基本数据类型包括 `int`、`float`、`double`、`char` 等，每种类型决定了数据的存储大小和可执行的操作。

### 常量与变量

标识符
: 程序中用来标识变量、常量、函数、数组等名称的字符序列。

常量
: 值固定不变的量。分为字面常量（直接写在程序中的值）和命名常量。

命名常量
: 不能改写的变量，使用 `const` 关键字声明。

    ```c
    const float pi = 3.14;
    ```

!!! tip "命名常量的好处"
    - **增强可读性**：用有意义的名称代替数值
    - **方便修改**：只需一处修改即可全局生效
    - **避免魔法数**：消除代码中含义不明的硬编码数值

## 运算符与表达式

### 算术运算

C 语言中默认的算术运算符的结合方向为**自左至右**（左结合），即先左后右。

!!! warning "赋值运算符是右结合"
    赋值运算符的结合方向为**从右到左**。例如 `a = b = c = 5` 先将 5 赋给 c，再赋给 b，最后赋给 a。

### 自增与自减

`++` 和 `--` 运算符分为前缀形式和后缀形式，区别在于运算时机：

| 形式 | 示例 | 含义 |
|------|------|------|
| 前缀 | `++i` | 先将 i 加 1，再使用 i 的值 |
| 后缀 | `i++` | 先使用 i 的当前值，再将 i 加 1 |

```c
int i = 5;
int a = ++i;  // a = 6, i = 6（先加后用）
int b = i++;  // b = 6, i = 7（先用后加）
```

### 类型转换

小数转化为整数有三种方式：

- **四舍五入**：通过 `(int)(x + 0.5)` 等方式实现
- **向上取整**：`ceil()` 函数，返回不小于 x 的最小整数
- **向下取整**：`floor()` 函数，返回不大于 x 的最大整数

### 逻辑运算

逻辑运算的优先级关系：

- **逻辑非** `!` 优先级最高
- 然后是**算术运算**和**关系运算**
- 其他逻辑运算（`&&`、`||`）的优先级仅高于赋值运算

!!! note "逻辑运算的结合性"
    逻辑运算的结合性默认是**左结合**，只有逻辑非 `!` 是**右结合**。

### exit() 函数

`exit()` 函数用于终止程序运行：

- `exit(0)`：正常退出
- `exit(x)`（x 不为 0）：异常退出

## 函数与子程序

### 子程序概念

子程序
: 封装并命名的一段程序代码，可供调用。

引入子程序的目的：

- **复用**：避免重复编写相同逻辑
- **结构化设计**：将复杂问题分解为若干子问题
- **调试维护**：每个子程序可独立测试与修改

???+ note "子程序设计原则"
    **高内聚、低耦合**——每个子程序应专注于单一功能，子程序之间的依赖应尽量减少。

### 函数定义与声明

函数
: 具有特定功能的代码块，是 C 语言中子程序的主要形式。

函数声明（原型）
: 向编译器声明函数的**名称、返回类型和参数类型**（个数、类型、顺序），使编译器在调用处能进行类型检查。

    ```c
    int max(int a, int b);  // 函数原型
    ```

函数定义
: 包括**返回类型、函数名、参数列表和函数体**，是函数的完整实现。

    ```c
    int max(int a, int b) {
        return a > b ? a : b;
    }
    ```

!!! warning "return 语句与返回值类型不一致"
    当 `return` 语句返回的值类型与函数声明的返回值类型不一致时，以**函数声明的返回值类型为准**，编译器会自动进行类型转换。

### 函数调用机制

函数调用的实质是**控制转移**——程序从调用点跳转到函数体执行，执行完毕后再返回调用点继续执行。

???+ details "参数传递方式"
    **按值传递**

    : 将实参的值复制给形参，形参的改变不影响实参。C 语言默认使用按值传递。

    **按引用传递**

    : 将实参的地址传递给形参，形参通过地址间接访问实参，形参的改变会影响实参。C 语言通过指针实现按引用传递的效果。

### 内存存储区域

程序运行时，内存划分为以下几个区域：

| 区域 | 说明 |
|------|------|
| 系统区 | 操作系统使用的内存区域 |
| 用户程序代码区 | 存放程序的机器指令 |
| 静态存储区 | 存放全局变量和静态变量，程序运行期间始终存在 |
| 栈区 | 存放局部变量和函数调用信息，自动分配和释放 |
| 堆区 | 动态分配的内存区域，由程序员手动管理 |

## 数组

### 线性表与数组

线性表
: 具有相同数据类型的 $n$（$n \geq 0$）个数据元素的有限序列。

数组是线性表在顺序存储结构上的实现，用一段连续的内存空间存储同类型数据元素。

### 初始化

- 数组初始化在**编译阶段**进行
- 当初始化值个数小于数组元素个数时，剩余元素**自动初始化为 0**

```c
int a[5] = {1, 2, 3};  // a[3] = 0, a[4] = 0
int b[5] = {0};        // 全部元素为 0
```

### 二维数组作为函数参数

二维数组作为函数形参时，**第二个下标必须给出**，因为编译器需要据此计算元素地址偏移。

```c
// 正确：给出第二维大小
void printMatrix(int mat[][4], int rows);

// 错误：省略第二维大小
void printMatrix(int mat[][], int rows);  // 编译报错
```

## 字符串

C 语言中字符串以字符数组的形式存储，末尾以 `'\0'` 作为终止标志。

### 输入函数对比

| 函数 | 读取行为 | 分隔符处理 | 末尾处理 |
|------|----------|-----------|----------|
| `scanf` | 读到空格/回车/EOF 为止 | **丢弃**分隔符 | 写入 `'\0'` |
| `gets` | 读整行直至换行符 | **丢弃**换行符 | 末尾加 `'\0'` |
| `fgets` | 读 n-1 个字符或到 `'\n'` | **不丢弃**换行符 | 末尾加 `'\0'` |

!!! warning "gets() 的安全性"
    `gets()` 不检查缓冲区大小，容易导致缓冲区溢出。在实际开发中应使用 `fgets()` 替代。

### 输出函数对比

| 函数 | 输出行为 |
|------|----------|
| `puts` | 输出字符串，末尾自动追加 `'\n'` |
| `fputs` | 输出字符串，`'\0'` 不被输出，不追加换行 |

## 结构体

### 基本概念

结构（struct）
: 一种**派生数据类型**，由若干成员组合而成，每个成员可以具有不同的数据类型。

???+ details "结构体定义的位置"
    **函数外定义**

    : 全局可见，所有函数均可使用该结构类型。

    **函数内定义**

    : 仅在该函数内部可见，属于局部类型定义。

### 成员命名规则

- **同一结构内**的成员不能同名
- **不同结构间**的成员可以同名（因为通过不同结构变量访问，不会冲突）

### 嵌套结构

结构体的成员本身也可以是另一个结构体类型，形成嵌套结构：

```c
struct Date {
    int year, month, day;
};

struct Student {
    char name[20];
    struct Date birthday;  // 嵌套结构成员
    float score;
};
```

### 初始化

当初始化值个数少于成员数目时，剩余成员**自动初始化为 0**（与数组的规则一致）。

```c
struct Student s = {"Zhang", 90.5};  // birthday 未初始化，自动为 0
```

### 结构体作为函数参数

传递结构变量有两种方式：

| 方式 | 优点 | 缺点 |
|------|------|------|
| 传指针 | 速度快，不复制整个结构 | 缺少保护，函数可修改原数据 |
| 传结构值 | 安全，函数修改不影响原数据 | 慢，需要复制整个结构 |

!!! tip "选择建议"
    对于小型结构体，传值更安全直观；对于大型结构体，传指针效率更高。若需传指针但又担心数据被修改，可用 `const` 修饰指针参数：

    ```c
    void printStudent(const struct Student *s);
    ```
