# 互连网络

## 基本概念

* **互连网络**：由网络元件按照一定的拓扑结构和控制方式构成的网络，用来实现计算机系统中的部件之间的相互连接。
* 设计目标：在最少传输延迟（成本、能耗等）的约束内，传输尽可能多的数据，避免成为系统的瓶颈。
* **三大要素**：**网络元件** + **互联结构** + **控制方式**
    * 互连结构是**静态**连接拓扑；
    * 控制方式时基于静态拓扑结构的**动态传输**机制。
* 结构参数：
    * 网络规模 $N$：网路中结点的个数；
    * 结点度 $d$：与结点相连的边（通道）的数量，包括
        * 入度：进入结点的边数；
        * 出度：从结点出来的边数；
    * 结点距离：从一个结点到另一个结点的最短路径长度；
    * 网络直径 $D$：网络中任意两个结点之间的最大距离，**应尽可能的小**。
    * 等分宽度 $b$：把由 $N$ 个结点构成的网络切成结点数近似相同（$N/2$）的两半（$N1 + N2$），在各种切法中，沿切口边数的最小值。
        * 线等分宽度 $B = b\times w$，其中 $w$ 是通道宽度，表示网络最大流量。
    * 对称性：从任何结点看到的拓扑结构都是相同的网络称为**对称网络**。
* 性能指标：
    * **通信时延**：从源结点到目的结点传送一条消息所需时间
        * 通信时延 = 软件开销 + 通道时延 + 选路时延 + 竞争时延
            * 软件开销：结点用于收发消息的软件所需的执行时间，主要取决于软件内核。
            * 通道时延 = 消息长度 / 通道带宽
            * 选路时延：消息在传送路径上所需的一系列选路决策所需的时间开销，与经过结点数成正比
            * 竞争时延：多个消息同时在网络中传送时，会发生争用网络资源的冲突。为避免或解决争用冲突所需的时间就是竞争时延。
    * **网络时延**：网络时延 = **通道时延 + 选路时延**
        * 由网络硬件特征决定，与程序和网络传输状态无关；
    * **端口带宽**：互连网络中任一端口到另一端口传输消息的最大速率。
        * 对称网络的端口带宽与端口位置无关，网络的端口带宽与各端口的端口带宽相同。
        * 非对称网络的端口带宽则是指所有端口带宽的**最小值**。
    * **聚集带宽**：互连网络中从一半节点到另外一半节点传输消息的最大速率。
        * 对于对称网络，聚集带宽 = 端口带宽 $\times$ 结点数 / 2
    * **等分带宽**：与等分宽度对应的切平面中，所有边合起来传输信息的最大速率。

## 互连函数

### 循环表示法

$$
f(x) = (x_0, x_1, \ldots, x_{j-1})
$$

表示 $f(x_0) = x_1, f(x_1) = x_2, \ldots, f(x_{j-1}) = x_0$，其中 $j$ 为循环的长度。

### 基本互连函数

1. **恒等函数**：$I(x) = x$，表示结点 $x$ 与自身相连。
2. **交换函数 / Cube 函数**：实现二进制地址编码中第 $k$ 位互反的输入端与输出端之间的连接：
    $$
    E(b_{n-1}b_{n-2}\ldots b_{k+1}b_kb_{k-1}\ldots b_1b_0) = b_{n-1}b_{n-2}\ldots b_{k+1}\bar{b_k}b_{k-1}\ldots b_1b_0
    $$
    * 用于构造立方体和超立方体互连网络
    * 共有 $n = \log_2 N$ 种互连函数（$N$ 为结点个数，需 $n$ 位二进制编码，选择一位取反共 $n$ 种）
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260619185133257.png){ loading=lazy width="70%" } </figure>
3. **均匀洗牌函数 / 混洗函数 / 置换函数 $\sigma$**：将输入端分为数目相等的两半，前一半和后一半按类似均匀混洗扑克牌的方式交叉地连接到输出端。
    * **全混洗**：
        $$
        \sigma(b_{n-1}b_{n-2}\ldots b_1b_0) = b_{n-2}b_{n-3}\ldots b_0b_{n-1}
        $$
        即把输入端的二进制编号循环左移一位得到输出端的二进制编号。
    * **子混洗**：互连函数 $s$ 的第 $k$ 个子函数，即把 $s$ 作用于输入端的二进制编号的低 $k$ 位
        $$
        \sigma_{(k)}(b_{n-1}\ldots b_{k}b_{k-1}b_{k-2}\ldots b_0) = b_{n-1}\ldots b_{k}b_{k-2}\ldots b_0b_{k-1}
        $$
        即把输入端的二进制编号的低 $k$ 位循环左移一位得到输出端的二进制编号。
    * **超混洗**：互连函数 $s$ 的第 $k$ 个超函数，即把 $s$ 作用于输入端的二进制编号的高 $k$ 位
        $$
        \sigma^{(k)}(b_{n-1}b_{n-2}\ldots b_{n-k}b_{n-k-1}\ldots b_0) = b_{n-2}\ldots b_{n-k}b_{n-1}\ldots b_0
        $$
        即把输入端的二进制编号的高 $k$ 位循环左移一位得到输出端的二进制编号。
    * **逆混洗**：互连函数 $\sigma^{-1}$，即把输入端的二进制编号循环右移一位得到输出端的二进制编号。
        $$
        \sigma^{-1}(b_{n-1}b_{n-2}\ldots b_1b_0) = b_0b_{n-1}b_{n-2}\ldots b_1
        $$
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260619190827322.png){ loading=lazy width="70%" } </figure>
4. **蝶式函数 $\beta$**：
    * **全蝶式**：
        $$
        \beta(b_{n-1}b_{n-2}\ldots b_1b_0) = b_0b_{n-2}\ldots b_1b_{n-1}
        $$
        把输入端的二进制编号的最高位和最低位互换得到输出端的二进制编号。
    * **子蝶式**：
        $$
        \beta_{(k)}(b_{n-1}\ldots b_{k}b_{k-1}b_{k-2}\ldots b_0) = b_{n-1}\ldots b_{k}b_0b_{k-2}\ldots b_1b_{k-1}
        $$
        即把输入端的二进制编号的低 $k$ 位的最高位和最低位互换得到输出端的二进制编号。
    * **超蝶式**：
        $$
        \beta^{(k)}(b_{n-1}b_{n-2}\ldots b_{n-k+1}b_{n-k}b_{n-k-1}\ldots b_0) = b_{n-k}b_{n-2}\ldots b_{n-k+1}b_{n-1}b_{n-k-1}\ldots b_0
        $$
        即把输入端的二进制编号的高 $k$ 位的最高位和最低位互换得到输出端的二进制编号。
5. **反位序函数 $\rho$**：
    * **全反位序**：
        $$
        \rho(b_{n-1}b_{n-2}\ldots b_1b_0) = b_0b_1\ldots b_{n-2}b_{n-1}
        $$
        即把输入端的二进制编号的位序完全颠倒得到输出端的二进制编号。
    * **子反位序**：
        $$
        \rho_{(k)}(b_{n-1}\ldots b_{k}b_{k-1}b_{k-2}\ldots b_0) = b_{n-1}\ldots b_{k}b_0b_1\ldots b_{k-2}b_{k-1}
        $$
        即把输入端的二进制编号的低 $k$ 位的位序完全颠倒得到输出端的二进制编号。
    * **超反位序**：
        $$
        \rho^{(k)}(b_{n-1}b_{n-2}\ldots b_{n-k+1}b_{n-k}b_{n-k-1}\ldots b_0) = b_{n-k}b_{n-k+1}\ldots b_{n-2}b_{n-1}b_{n-k-1}\ldots b_0
        $$
        即把输入端的二进制编号的高 $k$ 位的位序完全颠倒得到输出端的二进制编号。
6. **移数函数 $\alpha$**：把各输入端都错开一定位置模 N 后连到输入端
    * $\alpha(x) = (x \pm d) \mod N$
7. **PM2I 函数**：移数函数的一种
    * $PM2_{+i} = (x + 2^i) \mod N$
    * $PM2_{-i} = (x - 2^i) \mod N$
    * 共有 $2n$ 种 PM2I 函数

## 动态互连网络

### 总线网络

* 每一次总线只能用于一个源（主部件）到一个或多个目的（从部件）之间的数据传送。
* 多个请求时，仲裁逻辑决定哪个请求被允许使用总线，并按分时原则轮流为多个请求服务。
* 特点：**结构简单**、**实现成本低**、**带宽较窄**

### 交叉开关网络

* 一个 $n\times n$ 的交叉开关网络可以无阻塞地实现 $n!$ 种置换。

??? info "例题"
    $8\times 8$ 的交叉开关网络，可以无阻塞地实现几种置换？需要多少个交叉点开关？

    解答：$8! = 40320$ 种置换，需要 $8\times 8 = 64$ 个交叉点开关。

* 交换开关：
    * $2\times 2$ 开关
        <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260619204622408.png){ loading=lazy width="70%" } </figure>
* 相邻的各级开关之间都有固定的级间连接函数。
* 开关模块允许一对一和一对多映射，不允许多对一映射。
* 区别：**所用开关模块** + **控制方式** + **级间互连模式**
    * **控制方式**：对各个开关模块进行控制的方式
        * **级控制**：每级的所有开关只用一个控制信号控制，只能同时处于同一种状态；
        * **单元控制**：每个开关单元都有独立的控制信号；
        * **部分级控制**：第 $i$ 级的开关分别用 $i + 1$ 个信号控制，几个开关会合用一个信号

### 多级立方体网络

* 包括 STARAN 网络和间接二进制 n 方体网络
    - 相同：都采用 $2\times 2$ 开关。当第 $i$ 级交换开关处于交换状态时，实现的是 $Cube_i$ 互连函数
    - 仅在控制方式上不同：
        - STARAN 网络采用的是 **级控制（用于实现交换功能） + 部分级控制（用于实现移数功能）**。
        - 间接二进制 n 方体网络采用的是**单元控制**，更灵活。
* 一个 $N$ 输入的多级立方体网络有 $\log_2 N$ 级，每级有 $N/2$ 个 $2\times 2$ 开关，共需要 $\log_2 N\times N/2$ 个 $2\times 2$ 开关。

## 消息传递机制

### 消息寻径方案

* **消息**：结点之间进行通信的逻辑单位
    * 由若干“**包（Packet）**”组成
    * 包长度固定
    * 一条消息包含的包数量可变，因此消息长度不定
* **包**：包含寻径所需目的地址的基本单位。
    * 一条消息中的各个包都依次被分配一个序号以便能重新组装
    * 包可以被进一步分为一些更小的固定长度的单位，称为“**片（Flit）**”
    * 寻径信息和包序列号形成头片，其余是数据片

包含 4 种寻径方式 / 2 类交换：

* **线路交换/电路交换（Circuit Switching）**：
    * 先建立一条从源结点到目的结点的物理通路才能传递消息
    * 以**消息粒度**运行
    * 传输时延 $T = \frac{L + L_t\times(D + 1)}{B}$，其中
        * $L$：信息包长度（bit）；
        * $L_t$：建立路径所需的最小包长度（bit）；
        * $D$：经过中间结点数
        * $B$：通道带宽（bit/s）
    * 优点：传输带宽较大、平均传输时延较小、使用缓冲区小
        - 适用于动态、突发性的大规模并行处理数据的传送
    * 缺点：需要频繁建立和拆除连接，开销大；
* **包交换/分组交换（Packet Switching）**：
    1. **存储转发**：以**包粒度**运行，包从源结点经过一系列中间结点到达目的结点，所经过的每一个中间结点都需要设置一个包缓冲器。
        * $T_{SF} = \frac{L}{B}(D+1)$
        * 优点：简单
        * 缺点：包缓冲区大，时延大
    2. **虚拟直通**：没有必要等到信息包全部放入缓冲器后再作路由选择，只要接收到用作寻径的包头，就可作出判断。
        * 通信时延：$T = \frac{L + L_h\times(D+1)}{B}\approx \frac{L}{B}$，其中：
            * $L_h$：信息包寻径头部长度
            * 一般来说 $L >> L_h\times(D+1)$
        * 缺点：中间结点仍需要缓冲区，当出现寻径阻塞时，依然需要缓存整个包。
    3. **虫蚀方式**：把信息包切割成更小的单位 —— “片”，以**片粒度**分撇，各片传送按流水进行。
        * 能减少缓冲器容量，缩短传送延迟；
        * 不同包的片不能混合在一起传送
        * 通信时延：$T_{WH} = T_f\times D + \frac{L}{B} = \frac{L + L_f\times D}{B} \approx \frac{L}{B}$，其中：
            * $T_f$：片经过一个结点所需的时间，$L>>L_f\times D$
            * $L_f$：片长度
        * 优点：
            * 每个结点的缓冲器容量小；易于 VLSI 实现
            * 有较小的网络传输延迟
            * 通道共享性好，利用率高
            * 易于实现选播/广播
        * 缺点：
            * 链路利用率低，当包的一片被阻塞时，整个包的片都将被阻塞在所在结点，占用资源；

### 死锁与虚拟通道

* **虚拟通道**：两个结点间的逻辑链接，它由源结点的片缓冲区、结点间的物理通道以及接收结点的片缓冲区组成。
* **死锁**：缓冲区或通道上的循环等待引起
    - 解决方法：增加虚拟通道
