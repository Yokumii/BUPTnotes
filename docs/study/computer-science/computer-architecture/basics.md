# 计算机系统结构的基础知识

## 计算机系统的层次结构

- **计算机系统** = 软件 + 硬件

| 层数 | 语言             | 实现                                                   |
| ---- | ---------------- | ------------------------------------------------------ |
| 0    | 布尔语言（硬件） | |
| 1    | 微程序指令       | 用微指令集编写微程序，固件、硬件来解释  |
| 2    | 传统机器语言     | 传统机器语言程序有 L1 级微程序或 L0 级硬联逻辑进行解释 |
| 3    | 操作系统         | 包括传统机器及操作系统级指令，由微程序解释 |
| 4    | 汇编语言         | 翻译成 L3 和 L2 级语言执行 |
| 5    | 高级语言         | 通过编译程序翻译到 L4 或 L3 级，或通过解释方法实现 |
| 6    | 应用语言         | 由应用程序包翻译到 L5 |

- **物理机**：L1 和 L2；**虚拟机**：L3 及以上。
- **翻译**：用转换程序把高一级机器上的程序转换为低一级机器上的等效程序，然后再在这低一级机器上运行，**L4 ~ L6 采用翻译实现，时间少，占用空间大**；
- **解释**：对于高一级机器上程序中的每一条语句或指令，转换为低级语言的一段等效程序执行，执行完后再去高一级机器取下一条语句或指令，**L1 ~ L3 采用解释实现，时间长，占用空间小**。

## 计算机系统结构的定义

- 经典定义（Amdahl定义）：传统机器程序员所看到的计算机属性，即**概念性结构**与**功能特性**。
- 广义定义：指令系统结构、组成、硬件。
- 实质：确定计算机系统中软硬件的界面，界面之上是软件实现的功能，界面之下是硬件和固件实现的功能。

## 计算机系统结构的分类

* Flynn 分类法：根据指令流和数据流的多倍性，分为
    - SISD（单指令流单数据流）
    - SIMD（单指令流多数据流）
    - MISD（多指令流单数据流）
    - MIMD（多指令流多数据流）

<figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260607163659775.png){ loading=lazy width="70%" } </figure>

* 冯氏分类法：用**最大并行度**（$P_m$，计算机系统在单位时间内能处理的最大的二进制位数）来分类
    - 字串位串 WSBS：$n=1,m=1$，纯串行计算机
    - 字串位并 WSBP：$n>1,m=1$，单处理机，同时处理单个字的多个位
    - 字并位串 WPBS：$n=1,m>1$，单处理机，同时处理多个字的同一位
    - 字并位并 WPBP：$n>1,m>1$，多处理机，同时处理多个字的多个位

??? info "平均并行度"
    假设每个时钟周期内同时处理的二进制位数为 $P_i$，则 $T$ 个时钟周期内的平均并行度为：
    $$
    \frac{\sum_{i=1}^{T} P_i}{T}
    $$

??? info "利用率"
    系统在 $T$ 个时钟周期内的平均利用率为：
    $$
    \mu = \frac{P_a}{P_m} = \frac{\sum_{i=1}^{T} P_i}{T \cdot P_m}
    $$

* Handler 分类法：根据并行度和流水线对计算机进行分类
    - 程序控制部件 PCU 数量 $k$，在宏流水线中的个数为 $k^\prime$
    - 算术逻辑部分 ALU 或处理部件 PE 数量 $d$，在指令流水线中的个数为 $d^\prime$
    - 每个算数逻辑部件包含的基本逻辑线路 ELC 套数 $w$，在操作流水线中的个数为 $w^\prime$
    - $t\text{(系统型号)} = (k, d, w)$
    - 进一步改进为 $t\text{(系统型号)} = (k\times k^\prime, d\times d^\prime, w\times w^\prime)$

## 基本公式

### Amdahl 定律

- **可改进比例 $F_e$**：在改进前系统中，可被改进的部分占总执行时间的比例，$F_e \le 1$；
- **部件加速比 $S_e$**：可改进部分改进后性能提高的倍数，即改进前执行时间与改进后执行时间的比值，$S_e \ge 1$；
- 改进后程序总执行时间 $T_{new}(T_n)$：$T_n = T_o \cdot [(1 - F_e) + \frac{F_e}{S_e}]$，其中 $T_o$ 是改进前程序的总执行时间；
- **系统加速比 $S_n$**：改进前程序总执行时间与改进后程序总执行时间的比值，$S_n = \frac{T_o}{T_n} = \frac{1}{(1 - F_e) + \frac{F_e}{S_e}}$；

用文字描述就是：**系统加速比等于 1 除以（不可改进部分的比例 + 可改进部分的比例除以部件加速比）**。

显然，如果仅针对整个任务的一部分进行改进和优化，那么所获得的加速比不会超过 $\frac{1}{1 - F_e}$。

### CPU 性能公式

- CPI（每条指令的平均时钟周期数）= $\frac{\text{执行程序所需的时钟周期数}}{\text{指令数}}$；
- CPU 时间 = $\sum_{i=1}^{n} CPI_i \times I_i\times \text{时钟频率}$，其中 $I_i$ 是第 $i$ 条指令的执行次数；

因此，CPI 还可以表示为 $CPI = \frac{\text{时钟周期数}}{\text{指令数}} = \frac{\sum_{i=1}^{n} CPI_i \times I_i}{\sum_{i=1}^{n} I_i} = \sum_{i=1}^{n} CPI_i \times \frac{I_i}{\sum_{j=1}^{n} I_j}$，$\frac{I_i}{\sum_{j=1}^{n} I_j}$ 表示第 $i$ 条指令在总指令数中的比例。

### 性能测评

- X 的性能是 Y 的 n 倍，即 $n = \frac{T_Y}{T_X} = \frac{\text{性能X}}{\text{性能Y}}$；
- MIPS（每秒百万条指令数）= $\frac{\text{指令数}}{\text{执行时间} \times 10^6} = \frac{\text{时钟频率} f}{CPI \times 10^6}$；
- 程序执行时间 $T_e = \frac{\text{指令数}}{\text{MIPS} \times 10^6}$；

## 模拟和仿真

- **模拟**：用软件的方法在一台现有的机器（**宿主机**）上实现另一台机器（**虚拟机**）的指令集；
    - 用**机器语言**解释执行，存放在**主存**中；
    - 运行速度较慢，性能较差；
- **仿真**：用一台现有机器（宿主机）的微程序去解释实现另一台机器（目标机）的指令集；
    - 运行速度较快，性能较好；
    - 只能在系统结构相似的机器上实现；
    - 用**微程序**解释执行，解释程序存放在**控制存储器**中。
