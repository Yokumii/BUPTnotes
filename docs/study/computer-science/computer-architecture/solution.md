# 题解

## 填空题

### 系统结构基础知识相关概念

!!! note "计算机系统结构发展的因素"
    <u>**软件**</u> 是促使计算机系统结构发展最重要的因素，<u>**应用**</u> 是促使计算机系统结构发展最根本的动力，<u>**器件**</u> 是促使计算机系统结构发展最活跃的因素。

!!! note "物理机 vs. 虚拟机"
    计算机系统可以按功能划分成多级层次结构，底层由硬件实现的机器称为 <u>**物理机**</u>，上层由软件实现的机器称为 <u>**虚拟机**</u>。

!!! note "Flynn 分类法"
    Flynn分类法按照 <u>**指令流**</u> 和 <u>**数据流**</u> 的多倍性，把计算机系统的结构分为单指令流单数据流（SISD）、单指令流多数据流（SIMD）、多指令流单数据流（MISD）和多指令流多数据流（MIMD）四类。

!!! note "局部性原理"
    程序的局部性原理指出，程序执行时所访问的存储器地址分布是相对簇聚的，主要包括 <u>**时间局部性**</u> 和 <u>**空间局部性**</u>。

!!! note "计算机系统设计的定量原理"
    计算机系统设计的定量原理中，应以 <u>**经常性事件**</u> 为重点。

!!! note "软件兼容性"
    一个软件可以不经修改或者只需少量修改就可以由一台机器移植到另一台机器上正确地运行，得到的 <u>**结果相同**</u>，差别只是 <u>**执行时间**</u> 的不同。我们称这两台机器是 <u>**软件兼容（Software Compatible）**</u> 的。
!!! note "向后兼容"
    软件兼容中的系列机的根本特征是实现 <u>**向后兼容**</u>，即按某个时期投入市场的机型编制的程序，不加修改就能运行于在它之后投入市场的机器上。

!!! note "提高并行性的技术途径"
    提高计算机并行性的三种基本技术途径是 <u>**时间重叠**</u>、<u>**资源重复**</u> 和 <u>**资源共享**</u>。

!!! note "计算机系统结构的重大转折"
    系统结构的重大转折是从单纯依靠指令级并行转向开发 <u>**线程级并行**</u> 和 <u>**数据级并行**</u>。

!!! note "计算机系统结构的经典定义"
    经典定义（Amdahl定义）：传统机器程序员所看到的计算机属性，即 <u>**概念性结构**</u> 与 <u>**功能特性**</u>。

!!! note "广义的计算机系统结构定义"
    广义的计算机系统结构设计包括：<u>**指令系统结构**</u>、<u>**组成**</u> 和 <u>**硬件/实现**</u>。

!!! note "多倍性"
    系统最受限部件上同时执行的指令/数据最大数目称为 <u>**多倍性 (Multiplicity)**</u>。

### 时间并行技术（流水线）

!!! note "流水线的级/段"
    流水线中每个子过程及其功能部件被称为流水线的 <u>**级或段（Stage）**</u>。

!!! note "流水线的分类"
    * 按照流水技术用于计算机系统的等级不同，流水线可分为 <u>**部件级流水线**</u>、<u>**处理机级流水线**</u> 和 <u>**系统级流水线**</u>。
    * 按照流水线所完成的功能来分类，可分为 <u>**单功能流水线**</u> 和 <u>**多功能流水线**</u>。
    * 按照同一时间内各段之间的连接方式，多功能流水线可分为 <u>**静态流水线**</u> 和 <u>**动态流水线**</u>。（注意是多功能流水线的划分！！！）
    * 按照流水线中是否有反馈回路进行分类，可分为 <u>**线性流水线**</u> 和 <u>**非线性流水线**</u>。
    * 根据任务流入和流出的顺序是否相同，流水线可分为 <u>**顺序流水线**</u> 和 <u>**乱序流水线**</u>。

!!! note "解决流水线瓶颈的方法"
    在各段时间不完全相等的流水线中，解决流水线瓶颈问题的常用方法有 <u>**细分瓶颈段**</u> 和 <u>**重复设置瓶颈段**</u>。

!!! note "相关"
    两条指令之间存在某种依赖关系称为相关，相关主要有3种类型：<u>**数据相关（真数据相关）**</u>、<u>**名相关**</u> 和 <u>**控制相关**</u>。

!!! note "流水线冲突"
    流水线冲突（Pipeline Hazard）主要有3种类型：<u>**结构冲突**</u>、<u>**数据冲突**</u> 和 <u>**控制冲突**</u>。

!!! note "定向技术 & 指令调度 & 流水线互锁"
    * 减少数据冲突引起的停顿的常用硬件技术是 <u>**定向技术（旁路或短路）**</u>；
    * 而依靠编译器重新组织指令顺序来消除冲突的技术称为 <u>**指令调度（或流水线调度）**</u>；
    * 需要停顿的数据冲突必须依靠 <u>**流水线互锁机制**</u>来解决，检测发现数据冲突，并使流水线停顿（插入“暂停”或“气泡”），直至冲突消失。

### 指令级并行技术

!!! note "细粒度并行性"
    在一个过程中进行 <u>**指令一级或操作一级**</u> 的并行处理，称为 <u>**细粒度**</u> 并行性。

!!! note "指令级并行"
    <u>**指令级并行 ILP（Instruction Level Parallelism）**</u>是指在同一时间内，计算机系统中有多条指令同时处于执行状态。

    一个 <u>**时钟周期**</u> 内流水线流出的 <u>**指令数**</u> 被称为 <u>**指令级并行度**</u>。

!!! note "开发指令级并行（ILP）的两种主要途径"
    开发指令级并行（ILP）的两种主要途径是 <u>**资源重复**</u> 和 <u>**采用流水线技术**</u>。

!!! note "开发循环级并行的最基本技术"
    开发循环级并行的最基本技术是 <u>**循环展开（loop unrolling）**</u>、<u>**向量指令和向量数据表示**</u>。

!!! note "相关 vs. 冲突"
    相关是 <u>**程序**</u> 固有的一种属性，而冲突是 <u>**流水线**</u> 的属性。

!!! note "正确执行程序的必要条件"
    对于正确地执行程序来说，必须保持的最关键的两个属性是 <u>**数据流**</u> 和 <u>**异常行为**</u>。

!!! note "Tomasulo算法寄存器换名"
    Tomasulo算法中，寄存器换名是通过 <u>**保留站（Reservation Station）**</u> 和 <u>**流出逻辑**</u>来共同完成的。

!!! note "Tomasulo算法 CDB"
    在Tomasulo算法中，所有功能部件的计算结果都是送到 <u>**公共数据总线（CDB）**</u> 上，由它把结果直接播送到各个需要该结果的地方。

!!! note "动态分支预测技术包括"
    动态分支预测技术包括 <u>**分支历史表（BHT）**</u>、<u>**分支目标缓冲器（BTB）**</u> 和 <u>**基于硬件的前瞻执行**</u> 等。

!!! note "基于硬件的前瞻执行"
    支持硬件前瞻执行（Speculation）的关键思想是允许指令乱序执行，但必须 <u>**顺序确认（Commit）**</u>，其核心硬件结构是 <u>**再定序缓冲器（ROB）**</u>。

### 向量流水处理机

!!! note "向量的处理方式"
    向量的处理方式主要有三种：<u>**横向（水平）处理方式**</u>、<u>**纵向（垂直）处理方式**</u> 和 <u>**纵横（分组）处理方式**</u>。

!!! note "向量处理机的典型结构"
    向量处理机的典型结构由其采用的处理方式决定，主要分为 <u>**存储器-存储器型结构（对应纵向处理方式）**</u> 和 <u>**寄存器-寄存器型结构（对应分组处理方式）**</u> 两类

!!! note "存储器-存储器结构"
    在“存储器-存储器”结构中，为满足极高的存储器带宽需求，一般通过采用 <u>**多体交叉并行存储器**</u> 和 <u>**缓冲器技术**</u> 来解决。

!!! note "存储器-存储器结构"
    为了消除存储器争用冲突，存储器-存储器结构的向量机采用 <u>**多模块**</u> 存储器，并在运算器输入和输出端增加 <u>**延迟缓冲器**</u>。

!!! note "寄存器-寄存器结构"
    在“寄存器-寄存器”结构中，运算部件的输入和输出直接与 <u>**向量寄存器**</u> 相连。

!!! note "提高向量处理机性能的技术"
    提高向量处理机性能的四种常用技术 include：<u>**设置多个功能部件**</u>、<u>**链接技术**</u>、<u>**循环开采技术**</u> 和 <u>**采用多处理机系统**</u>。

### 互连网络

!!! note "互连网络三大要素"
    互连网络是由网络元件按照一定的拓扑结构和控制方式构成的网络，其三大要素是 <u>**网络元件**</u>、<u>**互连结构**</u> 和 <u>**控制方式**</u>。

!!! note "静态互连网络 vs. 动态互连网络"
    互连网络通常分为两大类：各结点之间有固定连接通路且在运行中不能改变的称为静态互连网络；由 <u>**交换开关**</u> 构成、可按运行程序的要求动态改变连接状态的称为动态互连网络。

!!! note "互连网络通信中常用的四种消息传递寻径方式"
    互连网络通信中常用的四种消息传递寻径方式主要有 <u>**线路交换**</u>、<u>**存储转发**</u>、<u>**虚拟直通**</u> 和 <u>**虫蚀方式**</u>。

!!! note "等分宽度的定义"
    等分宽度是把由 $N$ 个结点构成的网络切成结点数近似相同（$N/2$）的两半（$N1 + N2$），在各种切法中，<u>**沿切口边数的最小值**</u>。该参数主要反映了 <u>**网络最大流量**</u>。

### 阵列处理机 SIMD

!!! note "什么是阵列处理机？"
    阵列处理机的核心是由 <u>**多个处理单元**</u> 构成的阵列，它采用 <u>**资源重复**</u> 的方法提高并行性，又称为 <u>**SIMD（单指令流多数据流）**</u> 计算机

!!! note "阵列处理机的操作模型"
    阵列处理机的操作模型可用五元组（N，C，I，M，R）表示，其中 N 代表 <u>**处理单元（PE）数**</u>，C 代表 <u>**控制部件 CU 直接执行的指令集**</u>，I代表 <u>**由 CU 广播至 PE 进行并行执行的指令集**</u>，M代表 <u>**屏蔽方案集**</u>，R代表 <u>**数据寻径功能集**</u>。

!!! note "阵列机系统的构成"
    实际的阵列机系统通常是由三部分构成的一个异构型多处理机系统，包括：<u>**PE（处理单元）**</u>、<u>**控制器**</u> 和 <u>**前端机**</u>。

!!! note "阵列处理机的分类"
    根据存储器的组织结构，阵列处理机主要分为 <u>**分布式存储器的阵列机**</u> 和 <u>**共享存储器的阵列机**</u>。

!!! note "共享存储器阵列机结构"
    在共享存储器的阵列机中，共享的多体并行存储器通过 <u>**对准网络**</u> 与各处理单元相连。

### 多处理机 MIMD

!!! note "并行处理机 vs. 多处理机"
    多处理机与并行处理机的本质差别在于并行性级别的不同：多处理机实现 <u>**任务一级**</u> 的并行，并行性存在于 <u>**指令外部**</u>。而并行处理机则实现同一指令多数据流的 <u>**操作一级**</u> 的并行。

!!! note "多处理机的并行性"
    多处理机实现 <u>**粗粒度**</u> 的并行性。一般来说，在同一时刻，不同的处理机执行着不同的 <u>**指令**</u>。

!!! note "MIMD 计算机的特点"
    MIMD，多处理机，具有 <u>**多个 CPU**</u> 的计算机系统。

!!! note "MIMD 计算机的分类"
    根据存储器的组织结构，MIMD机器可分为 <u>**集中式共享存储器结构**</u>（各处理器共享一个集中式的物理存储器） 和 <u>**分布式存储器结构**</u>（各处理器拥有各自的局部存储器） 两类。

    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260620111600590.png){ loading=lazy width="70%" } </figure>

!!! note "SMP（物理共享 + 逻辑共享）"
    集中式共享存储器多处理机常被称为 <u>**SMP机器**</u>，其所有处理器访问存储器所花时间相同，属于 <u>**UMA（均匀存储器访问）**</u> 结构。

!!! note "DSM（物理分离 + 逻辑共享）"
    分布式共享存储器系统（DSM）也称为 <u>**NUMA（非统一内存访问）**</u> 机器，其特点是物理分离的所有存储器作为一个 <u>**统一的共享逻辑空间**</u> 进行编址。

!!! note "分布式存储器多处理机的通信方式"
    两种主要的多处理机通信机制是：通过 load/store 指令操作的 <u>**共享存储器通信机制（适用于逻辑共享）**</u>，以及通过显式传递消息完成的 <u>**消息传递通信机制（适用于逻辑分离）**</u>。

!!! note "目录协议分类"
    在基于目录的协议中，目录的三种常见结构为：全映象目录、有限映象目录和链式目录。

## 简答题

### 系统结构基础知识相关概念

!!! note "计算机系统的层次结构"
    | 层数 | 语言             | 实现                                                   |
    | ---- | ---------------- | ------------------------------------------------------ |
    | 0    | 布尔语言（硬件） | |
    | 1    | 微程序指令       | 用微指令集编写微程序，固件、硬件来解释  |
    | 2    | 传统机器语言     | 传统机器语言程序有 L1 级微程序或 L0 级硬联逻辑进行解释 |
    | 3    | 操作系统         | 包括传统机器及操作系统级指令，由微程序解释 |
    | 4    | 汇编语言         | 翻译成 L3 和 L2 级语言执行 |
    | 5    | 高级语言         | 通过编译程序翻译到 L4 或 L3 级，或通过解释方法实现 |
    | 6    | 应用语言         | 由应用程序包翻译到 L5 |

!!! note "简述计算机系统结构、计算机组成与计算机实现的概念及其相互关系。"

    * **计算机系统结构**：是指机器语言程序员所看到的 <u>**传统机器级**</u> 所具有的属性，即 <u>**概念性结构与功能特性**</u>。其实质是确定计算机系统中软硬件的界面。
        * e.g. 指令系统是否有乘法指令、主存容量与编址方式
    * **计算机组成**：是指计算机系统结构的 <u>**逻辑实现**</u>，包含物理机器级中的数据流和控制流的组成以及逻辑设计等。
        * e.g. 专门的乘法器、加法器多步操作、主存速度、逻辑结构是否采用多体交叉
    * **计算机实现**：是指计算机组成的 <u>**物理实现**</u>，包括部件的物理结构、器件技术和微组装技术等。
        * e.g. 乘法器、加法器的物理实现、器件选定以及微组装技术、主存系统的物理实现
    * **相互关系**：具有相同系统结构的计算机可以采用不同的计算机组成；同一种计算机组成又可以采用多种不同的计算机实现

!!! note "术语解释：翻译和解释"
    * 翻译 (Translation)：先用转换程序把高一级机器上的程序转换为低一级机器上等效的程序，然后再运行该程序。
    * 解释 (Interpretation)：对于高一级机器上的每条指令，执行低一级机器上的一段等效程序，如此反复直至完成。

!!! info "翻译 vs. 解释 例题"
    汇编语⾔源程序变换成机器语⾔⽬标程序是经（   ）来实现的。
    
    A．编译程序解释 B．汇编程序解释 C．编译程序翻译 D．汇编程序翻译
    
    解答：D．汇编程序翻译，源程序 $\rightarrow$ 目标程序，因此是翻译，由汇编程序实现，编译程序负责的是高级语言 $\rightarrow$ 机器语言的翻译。

!!! note "简述模拟（Simulation）与仿真（Emulation）的异同。"
    两者都是为了实现软件的可移植性，使软件能在具有不同系统结构的机器之间运行的方法。

    * **模拟**：用 <u>**机器语言**</u> 解释执行，解释程序通常存放在 <u>**主存**</u> 中。它是用软件的方法在现有机器（宿主机）上实现另一台机器（虚拟机）的指令集，运行速度较慢。
    * **仿真**：用 <u>**微程序**</u> 解释执行，解释程序放在 <u>**控制存储器**</u> 中。它是用宿主机上的微程序去解释实现目标机的指令集，运行速度比模拟方法快，但通常只能在系统结构差距不大的机器之间使用。

!!! note "实现软件移植的途径有哪些？各受什么限制？"
    实现软件移植的途径有：<u>**统⼀⾼级语⾔**</u>，<u>**系列机⽅法**</u>，<u>**模拟**</u>和<u>**仿真**</u>。

    * **统⼀⾼级语⾔存在问题**：存在⼀定的困难，争取汇编语⾔或机器语⾔的统⼀。
    * **系列机⽅法存在问题**：在汇编语⾔兼容的前提下，系统结构的发展很有限，有时连突破性的组成技术都⽆法采⽤。
    * **模拟存在问题**：结构差异很⼤时，效率、速度会急剧下降。
    * **仿真存在问题**：实现不灵活，当两种机器结构差别很⼤时，效率低甚⾄难以仿真。

!!! note "术语解释：基准测试程序"
    为了更真实、全面地反映计算机在各个方面的处理性能，现代通常采用基准测试程序套件。它是由 <u>**各种不同的真实应用程序构成的集合**</u>。用于测试和比较性能的基准测试程序的最佳选择是真实应用程序。

!!! note "简述传统冯·诺依曼结构的主要特点。"
    * 计算机以运算器为中心。
    * 在存储器中，指令和数据同等对待。
    * 存储器是按地址访问、按顺序线性编址的一维结构，每个单元的位数是固定的。
    * 指令的执行是 <u>**顺序的**</u>。
    * 指令由操作码和地址码组成。
    * 指令和数据均以二进制编码表示，采用二进制运算。

!!! note "简述三大分类法（Flynn、冯氏、Handler）"
    * **Flynn分类法**：按照指令流和数据流的多倍性，把计算机系统的结构分为单指令流单数据流（SISD）、单指令流多数据流（SIMD）、多指令流单数据流（MISD）和多指令流多数据流（MIMD）四类。
    * **冯氏分类法**：用 <u>**最大并行度**</u>（$P_m$，计算机系统在单位时间内能处理的最大的二进制位数）来分类
        - 字串位串 WSBS：$n=1,m=1$，纯串行计算机
        - 字串位并 WSBP：$n>1,m=1$，单处理机，同时处理单个字的多个位
        - 字并位串 WPBS：$n=1,m>1$，单处理机，同时处理多个字的同一位
        - 字并位并 WPBP：$n>1,m>1$，多处理机，同时处理多个字的多个位
    * **Handler 分类法**：根据 <u>**并行度**</u> 和 <u>**流水线**</u> 对计算机进行分类。

!!! note "什么是并行性？它包含哪两个方面的含义？"
    * **并行性**：是指计算机系统在同一时刻或者同一时间间隔内进行多种运算或操作。只要在时间上相互重叠，就存在并行性。
    * 它包含两个方面的含义：
        * **同时性**：指两个或两个以上的事件在同一时刻发生。
        * **并发性**：指两个或两个以上的事件在同一时间间隔内发生。
    
!!! note "简叙 Amdahl 定律主要内容。"
    Amdahl 定律的核心内容是：加快系统某部件执行速度所能获得的系统总体性能加速比，受限于 <u>**该部件执行时间占系统总执行时间的百分比**</u>。

!!! note "简述目前流行的5类高性能并行计算机系统。"
    * **PVP（Parallel Vector Processor），并行向量处理机**；
    * **SMP（Symmetric Multiprocessor），对称式共享存储多处理机**；
    * **MPP（Massively Parallel Processor），大规模并行处理机**；
    * **DSM（Distributed Shared Memory），分布式共享存储多处理机**；
    * **COW（Cluster of Workstations），工作站集群**；


### 时间并行技术（流水线）

!!! note "简述 MIPS 指令集"
    MIPS 指令集在设计上采用了 <u>**固定字段译码技术**</u>，即 <u>**操作码（Opcode）字段以及寄存器操作数字段（rs、rt）都位于指令中固定的位置**</u>，这种设计使得指令的译码操作和读寄存器操作能够并行进行。包含 3 类指令：

    1. **I类指令（立即数指令）**：该类指令包含四个主要字段
        * 操作码（Opcode）
        * rs（源寄存器）
        * rt（目标或源寄存器）
        * 立即数（Immediate）
    2. **R类指令（寄存器指令）**：该类指令包含六个主要字段
        * 操作码（Opcode）
        * rs（源寄存器）
        * rt（源寄存器）
        * rd（目标寄存器）
        * sham（位移量）
        * funct（功能码）
    3. **J类指令（跳转指令）**：该类指令包含两个主要字段
        * 操作码（Opcode）
        * 与 PC 相加的偏移量

!!! note "什么是指令流水线？"
    指令流水线属于 <u>**处理机级流水线**</u>，它是指把指令的执行过程按照流水方式处理的技术。它的核心原理是把一条指令的解释或执行过程分解为 <u>**若干个子过程**</u>，并让这些子过程分别由 <u>**独立的专门功能部件**</u> 来实现。

!!! note "什么是流水线的通过时间？什么是排空时间？"
    * **通过时间**是指 <u>**第一个任务**</u> 从进入流水线到流出结果的时间段。
    * **排空时间**是指 <u>**最后一个任务**</u> 从进入流水线到流出结果的时间段。

!!! note "简述降低流⽔线分⽀损失的延迟分⽀⽅法及3种不同调度策略。"
    * **延迟分支方法**：从逻辑上“延⻓”分⽀指令的执⾏时间。所有顺序后继指令都处于<u>**“分⽀延迟槽”**</u>中，⽆论分⽀成功与否，流⽔线都会执⾏这些指令。
    * **3种不同调度策略**：
        1. **从前调度**：分支不依赖于被调度的指令。<u>**总是**</u>可以有效提⾼流⽔线性能。
        2. **从目标处调度**：如果分⽀转移失败，必须保证被调度的指令对程序的执⾏没有影响，可能需要复制被调度指令。<u>**分⽀转移成功时，可以提⾼流⽔线性能**</u>。但由于复制指令，可能加⼤程序空间。
        3. **从失败处调度**：如果分⽀转移成功，必须保证被调度的指令对程序的执⾏没有影响。<u>**分⽀转移失败时，可以提⾼流⽔线性能**</u>。


### 指令级并行技术

!!! note "术语解释：保持异常行为 (Exception Behavior)"
    指无论如何改变指令执行顺序，都不能改变程序中异常的发生情况。
    
!!! note "简述静态调度与动态调度的区别。"
    * **静态调度**：依靠编译器对代码进行静态调度，以减少相关和冲突。它在编译期间进行代码调度和优化，通过把相关的指令拉开距离来减少可能产生的停顿。
    * **动态调度**：在程序的执行过程中，依靠专门硬件对代码进行调度，减少数据相关导致的停顿。其优点是能处理编译时情况不明的相关，并使面向某一流水线优化的代码在其他流水线也能高效执行，缺点是增加了硬件复杂性。

!!! note "术语解释：乱序流水线"
    经典的流水线存在“按序流出”和“按序执行”的局限性，一旦某条指令因相关性受阻，其后的指令都将停顿。乱序流水线（通过指令的动态调度实现），允许指令
    
    * **乱序执行**：指指令的实际执行顺序与原本的程序顺序不相同；
    * **乱序完成**：指指令的完成顺序同样与程序顺序不相同；

    系统将经典5段流水线的译码阶段（ID）进一步细分为两个阶段：

    * 流出（Issue, IS）：负责指令译码，并检查是否存在结构冲突。在这个阶段，指令仍然是按序流出的；
    * 读操作数（Read Operands, RO）：等待数据冲突消失，然后读取操作数。在这个阶段，流出后的指令只要其操作数就绪，就可以立即开始乱序执行，而不需要等待前面的指令执行完毕；

    在传统按序执行的5段流水线中，不会发生 **WAR（反相关）** 和 **WAW（输出相关）** 冲突，但乱序执行使得这两种冲突可能发生，并且可能导致 **不精确异常**。两种典型硬件算法是 **记分牌（Scoreboard）** 算法（CDC 6600最早采用）和 **Tomasulo算法**（IBM 360/91首先采用）。

!!! note "简述精确异常和不精确异常的区别。"
    * **精确异常**：如果发生异常时，处理机的现场跟严格按程序顺序执行时指令的现场相同。
    * **不精确异常**：当执行某条指令导致发生异常时，处理机的现场与严格按程序顺序执行时指令的现场不同。发生的原因通常是流水线可能已经执行完了按程序顺序位于该指令之后的指令，或者还没完成该指令之前的指令。

!!! note "什么是Tomasulo算法？它具有哪些主要优点？"
    * Tomasulo算法是一种基于硬件的动态调度算法。其核心思想是记录和检测指令相关，<u>**操作数一旦就绪就立即执行**</u>（减小RAW冲突）；并通过保留站进行寄存器换名来消除WAR冲突和WAW冲突。
    * **主要优点**：
        * **冲突检测逻辑是分布的**：通过 <u>**保留站**</u> 和 <u>**CDB**</u> 实现，结果一产生就能通过 CDB 播送给所有需要的指令同时执行。
        * **消除了WAW冲突和WAR冲突导致的停顿**：使用保留站进行寄存器换名，且操作数一旦就绪就放入保留站。

!!! note "简述前瞻执行（Speculation）的基本思想及ROB的作用。"
    * **基本思想**：对分支指令的结果进行猜测，并假设猜测总是对的，然后按猜测结果继续取、流出和执行后续指令。
    * **ROB（再定序缓冲器）的作用**：前瞻执行指令的结果不直接写回寄存器或存储器，而是写入ROB中。等到相应的指令得到“确认”（即确实是应该执行的）之后，才将结果从ROB写入寄存器或存储器；如果猜测错误，则清空ROB并从另一条路径重新执行，从而保证了 <u>**精确异常**</u> 和正确的指令顺序。

!!! note "简述超标量（Superscalar）、超长指令字（VLIW）处理机和超流水线（Superpipeline）处理机的主要区别。"
    * **超标量（Superscalar）**：每个时钟周期流出的指令条数 <u>**不定**</u>（有上限），由硬件或编译器完成调度。其优点是<u>**对程序员透明**</u>，能够<u>**兼容旧代码**</u>，代码量较小。
        * 发射/流出策略：
            * 每个时钟周期流出的指令条数是不固定的，但受限于硬件设计的 <u>**最大流出上限**</u>（即n-流出）。
            * 指令通常是 <u>**按序流出的**</u>，在流出阶段由硬件实时检测指令包内以及与正在执行的指令之间是否存在结构冲突或数据冲突
        * 调度策略： 超标量处理机主要分为静态调度（编译器）和动态调度（专门的硬件，例如扩展的 Tomasulo 算法）两类；
    * **超长指令字（VLIW）**：每个时钟周期流出的指令条数是 <u>**固定的**</u>，由多个单操作指令构成一个超长指令包。指令间的并行性由 <u>**编译器**</u> 显式表示和调度，流出时 <u>**无需复杂的冲突检测，硬件设计较简单**</u>。但缺点是 <u>**目标代码兼容性差**</u>，且可能因操作槽填不满导致 <u>**编码效率低和代码膨胀**</u>。
    * **超流水线（Superpipeline）**：将每个流水段进一步细分，这样在一个时钟周期内能够分时流出多条指令。

### 向量流水处理机

!!! note "简述向量的三种处理方式，并指出哪种方式不适用于向量处理机的并行处理。"
    * **横向（水平）处理方式**：向量计算按 <u>**行**</u> 的方式从左到右横向进行。<u>**不适用于向量处理机的并行处理**</u>。
    * **纵向（垂直）处理方式**：向量计算按 <u>**列**</u> 的方式从上到下纵向进行，整个向量仅需1次数据相关和1次功能切换，适用于 <u>**存储器-存储器型**</u> 向量处理机。
    * **纵横（分组）处理方式**：把向量分成若干组，组内按纵向方式处理，依次处理各组。对向量长度无限制，适用于 <u>**寄存器-寄存器型**</u> 向量处理机。

!!! note "什么是向量流水线链接技术（Chaining）？能够成功进行向量链接的必要条件是什么？"
    * **链接技术**：具有 <u>**先写后读相关**</u> 的两条指令，在前一个向量功能部件产生第一个结果并送到结果寄存器入口时，立即将该结果送往下一个功能部件的入口，开始后续的向量操作，从而把功能部件链接起来进行流水处理，无需等待整个向量结果全部产生。其实质是把流水线定向的思想引入到向量执行过程。
    * **链接的必要条件**：
        * 无向量寄存器使用冲突和无功能部件使用冲突。
        * 只有在前一条指令的第一个结果元素送入结果向量寄存器的那一个时钟周期才可以进行链接。
        * 当一条向量指令的两个源操作数来自两条先行指令时，这 <u>**两条先行指令产生运算结果的时间（有关功能部件的通过时间）必须相等**</u>。
        * 进行链接执行的向量指令的向量长度必须相等。

!!! note "什么是分段开采技术（Strip Mining）？为什么需要这种技术？"
    * 概念：当 <u>**待处理的向量长度大于向量处理机内部向量寄存器的长度（MVL）**</u> 时，必须把长向量分成长度固定的段，然后循环分段处理，每一次循环只处理一个向量段。
    * 原因：在寄存器-寄存器型结构的向量机（如CRAY-1）中，每个向量寄存器能容纳的元素个数是固定的（如64个），对于超过此上限的任意长度向量，硬件无法一次性容纳，因此依赖分段开采技术将长向量切分为硬件能处理的小段进行循环计算。

!!! note " 什么是“编队”技术？它的执行时间由什么决定？同一个编队中的向量指令之间需要满足什么条件？"
    * **编队**：是指把能在同一个时钟周期内一起开始执行的几条向量指令组合在一起的集合。
    * **执行时间特征**：当一个编队由若干条指令组成时，该编队的执行时间由该编队中 <u>**各指令启动时间的最大值**</u> 来确定。整个指令序列的总执行时间等于 <u>**各个编队执行时间的总和**</u>。
    * 同一个编队中的向量指令之间一定不存在流水向量 <u>**功能部件的冲突**</u>、<u>**Vi冲突**</u> 或 <u>**数据的相关性**</u>

### 互连网络

!!! note "互连网络的主要特性参数，分别解释它们的概念及其意义"
    互连网络的主要特性参数有 <u>**网络规模N**</u>、<u>**结点度d（包括入度和出度）**</u>、<u>**结点距离**</u>、<u>**网络直径D**</u>、<u>**等分宽度b**</u> 和 <u>**对称性**</u> 等。

    * **网络规模 N**：网络中结点的个数，表示该网络所能连接的部件数量。
    * **结点度 d**：与结点相连接的边数（通道数），包括入度和出度。
    * **结点距离**：网络中任意两个结点间跨越边数的 <u>**最小值**</u>。
    * **网络直径 D**：网络中任意两个结点间的 <u>**最大结点距离**</u>。
    * **等分宽度 b**：指把由N个结点构成的网络切成结点数近似相同的两半，在各种切法中，沿切口边数的最小值。
    * **对称性**：从任何结点看到的拓扑结构都是相同的网络称为对称网络。

!!! info "超立方体网络例题"
    32个节点的立方体网络中，3号到6号节点的距离是( )。 

    解答：网络中节点的距离定义为其二进制编码之间的**海明距离（Hamming Distance）**。因此，3号节点的二进制编码为 00011，6号节点的二进制编码为 00110。它们在第 2 位和第 0 位上不同，因此距离为 2。

!!! note "动态互连网络"
    应该只需记忆几类典型：

    * **总线网络**
        * 每一次总线只能用于 <u>**一个源（主部件）到一个或多个目的（从部件）**</u> 之间的数据传送。
        * 多个请求时，<u>**仲裁逻辑**</u> 决定哪个请求被允许使用总线，并按分时原则轮流为多个请求服务。
        * 特点：结构简单、实现成本低、带宽较窄
    * **交叉开关网络**：一个 $n\times n$ 的交叉开关网络可以无阻塞地实现 $n!$ 种置换。
    * **多级互连网络 MIN**：通常在 $N$ 个结点的多级互连网络中，多级 ICN 由 $n = \log_2 N$ 级构成；
        * 对于通用的 $\times$ 开关模块：共有 <u>**$n^n$ 种合法状态**</u>，以及 <u>**$n!$ 种置换连接**</u>。
            * 开关模块允许“一对一”和“一对多”（广播）映射，但不允许“多对一”映射，因此对于 n 个输出端口，每个输出端口都可以独立地从 n 个输入端口中选择一个进行连接。因此，总组合数是
                $$
                n\times n \times \cdots \times n = n^n
                $$
            * 对于置换连接：要求严格的“一对一”无阻塞连接，因此当每个输出端口必须与一个且仅一个输入端口连接时，第一个输出端有 $n$ 个输入选择，第二个输出端剩下 $n−1$ 个选择，依此类推
                $$
                n\times(n−1)\times\cdots\times1=n!
                $$

!!! note "比较消息传递机制中“存储转发（Store and Forward）”、“虚拟直通（Virtual Cut-Through）”和“虫蚀方式（Wormhole）”的区别。"
    * **存储转发**：包到达中间结点时，<u>**必须全部存储在结点的缓冲器中**</u>，待出口链路和下个结点的缓冲器可用时再传递。缺点是要求包缓冲区大，网络时延大（与结点距离跳数成正比）。
    * **虚拟直通**：虚拟直通：不必等信息包全部接收完毕，<u>**只要接收到包头就可作路由判断**</u>。若输出链路空闲，包可立即传向下一结点；若输出忙，则仍需将整个包存入缓冲器。当寻径阻塞时要求结点有足够大的缓冲区。
    * **虫蚀方式**：将包切割成更小的 <u>**“片”（Flit）**</u>，各片按流水方式传送。一旦头片开始传送，后续数据片紧跟其后。若输出忙，只需将一片或几片存入缓冲器。其优点是极大地减小了缓冲器的容量需求，缩短了传送延迟时间，易于用 <u>**VLSI**</u> 实现。

!!! note "在消息传递机制中，什么是死锁？如何避免路由死锁？"
    * **死锁（Routing Deadlock）**：在消息寻径过程中，当多个数据包在缓冲区或通道上发生 <u>**循环等待**</u> 时，就会引起死锁，导致数据无法继续传输。
    * 避免方法：通常利用 <u>**增加虚拟通道**</u> 的方法来避免死锁。虚拟通道是两个结点间的逻辑链接，多条虚拟通道可以通过分时共享一条物理通道。通过引入额外的虚拟通道，可以打破通道间的循环依赖关系，从而有效避免死锁的发生.

### 阵列处理机 SIMD

!!! note "简述阵列处理机的主要特点。"

    * 以 <u>**单指令流多数据流（SIMD）**</u> 方式工作。
    * 通过设置多个相同的处理单元来开发并行性，利用的是并行性中的 <u>**同时性**</u>（而非并发性，并没有用到流水线）。
    * 是以某一类算法为背景的专用计算机，必须 <u>**与并行算法密切结合**</u>。

!!! note "简述共享存储器阵列机中“对准网络”的概念及其作用。"
    * **概念**：它是实现 <u>**处理单元（PE）**</u> 和所需访问的 <u>**存储模块（SM）**</u> 对准连接的互连网络。
    * **作用**：在读或写并行存储器时，使存储器中为保证无冲突访问而错开存放的操作数顺序，能够与算术单元并行处理所要求的正常顺序协调一致。

!!! note "什么是屏蔽方案集（M）？在阵列处理机中起什么作用？"
    * 屏蔽方案集是阵列机操作模型五元组之一。每种屏蔽可以将所有处理单元（PE）划分成 <u>**允许操作**</u> 和 <u>**禁止操作**</u> 两种工作模式。
    * 它主要用于在同一时钟周期内，通过屏蔽逻辑 <u>**动态控制某些PE是否参与当前广播指令的执行**</u>，以处理边界条件或数据相关的特殊操作。

### 多处理机 MIMD

!!! note "何谓机群系统？它的主要特点是什么？"
    机群系统（Cluster）是一类广泛被采用的 <u>**MIMD（多指令流多数据流）**</u> 机器。采用 <u>**超级结点（簇）结构**</u>：在分布式系统中，它常以“簇”的形式存在。每个结点内部包含少量处理器（例如2～8个），这些处理器通过另外的互连技术（如总线）连接成一个整体。

!!! note "简述共享存储器通信机制与消息传递通信机制的特点。"
    * **共享存储器通信**：处理器通过 load 和 store 指令对相同地址进行读写。优点是 <u>**与集中式多处理机兼容**</u>，<u>**易于编程**</u>，<u>**小数据量时通信开销低**</u>，<u>**可通过Cache技术减少通信频度**</u>。
    * **消息传递通信**：在多个独立地址空间之间通过 <u>**显式发送消息**</u> 来请求操作或传送数据。优点是 <u>**硬件较简单**</u>，<u>**显式的通信让编程者能更清楚地控制和优化通信开销**</u>。

!!! note "什么是缓存一致性？"
    缓存一致性问题是指，在多处理机系统中允许共享数据进入Cache时，<u>**多个处理器的Cache中可能会存在同一存储块的副本**</u>。如果某个处理器修改了自己Cache中的数据，就会导致 <u>**它的数据与其他Cache（或主存）中的数据不一致**</u>。

!!! note "导致 Cache不一致的主要原因有哪些？"
    <u>**可写数据的共享**</u>、<u>**I/O活动**</u>、<u>**进程迁移**</u>。

!!! note "Cache一致性协议的两大类"
    * **目录式协议**：通过设置一个称为 <u>**“目录”的集中数据结构**</u>，记录每个数据块的状态以及哪些Cache中有副本。它不需要在总线上广播，可扩展性更好，适合分布式共享存储器系统。
    * **监听式协议**：每个Cache除了包含物理存储器中块的数据副本之外，也 <u>**保存着各个块的共享状态信息**</u>。各个Cache控制器通过连接在共享存储器的总线上，一直 <u>**监听总线上的请求**</u>。当发现自己拥有总线请求的数据块副本时，就进行相应操作，适合较小规模的系统。

!!! note "比较解决Cache一致性的“写作废”和“写更新”协议。"
    * **写作废协议**：在处理器写入数据前，必须向其他拥有该数据副本的Cache发送信号，作废这些副本以保证唯一的访问权。其带宽占用较少，应用更广泛。
    * **写更新协议**：在处理器写入数据时，通过广播把新的数据发送给其他Cache，让它们更新对应的副本。虽然读取延迟小，但连续多次写操作会引发大量广播操作，浪费总线带宽。

!!! note "比较 Cache 更新后对存储器写策略。"
    * **写直达（Write Through）**：在处理器写入数据时，<u>**同时将数据写入Cache和主存**</u>。优点是保证了主存中数据的最新性，缺点是写操作频繁时会占用大量总线带宽。
    * **写回（Write Back）**：在处理器写入数据时，<u>**只更新Cache中的数据，而不立即更新主存**</u>。只有当该数据块被替换出Cache时，才将其写回主存。优点是减少了对总线的占用，提高了系统性能，但需要额外的机制来跟踪哪些数据块是“脏”的。

## 计算 / 解答题

### CPI / MIPS 计算

* 有效 CPI = 执行程序所需的时钟周期数 / 所执行的指令条数
* MIPS = 时钟频率 / CPI（一般时钟频率单位为 MHz，这边就不用 $10^6$ 了）

### Amdahl定律

* 加速比 $S_n = \frac{1}{(1 - Fe) + \frac{Fe}{S_e}}$，其中 $Fe$ 是可改进部分占总执行时间的比例，$Se$ 是可改进部分加速比。
* 多部件改进情况下的加速比 $S_n = \frac{1}{(1 - \sum_{i=1}^{n} Fe_i) + \sum_{i=1}^{n} \frac{Fe_i}{Se_i}}$，其中 $Fe_i$ 是第 $i$ 个改进部分占总执行时间的比例，$Se_i$ 是第 $i$ 个改进部分的加速比。

### 流水线时空图和性能指标计算

!!! note "流水线的三个重要性能指标（吞吐率、加速比、效率）的概念及公式"
    * **吞吐率（Throughput）**：是指在<u>**单位时间内流水线所完成的任务数量或输出结果的数量**</u>。其公式为（各段时间相等时）：
        $$
        TP = \frac{n}{T_k} = \frac{n}{(k + n - 1)\Delta t}
        $$
    * **加速比（Speedup）**：是指完成同样一批任务，<u>**不使用流水线（即顺序执行）所用的时间与使用流水线所用的时间之比**</u>。其公式为（各段时间相等时）：
        $$
        S = \frac{T_s}{T_k} = \frac{n k \Delta t}{(k + n - 1)\Delta t} = \frac{n k}{k + n - 1}
        $$
        * 最大加速比为 $S_max = k$
    * **效率（Efficiency）**：是指流水线中的 <u>**设备实际使用时间与整个运行时间的比值**</u>，即流水线设备的利用率。从时空图上看，效率就是n个任务占用的时空面积和k个段总的时空面积之比。其公式为：
        $$
        E = TP\cdot \Delta t = \frac{S}{k}
        $$
        即实际加速比与最大加速比 k 的比值。

### 链接技术

* 链接方式的总执行时间：

    $$
    \text{总执行时间}
    =
    \underbrace{\text{前写指令的通过时间}+\text{后读指令的通过时间}}_{\text{得到第一个结果所需时间}}
    +
    \underbrace{\text{向量长度}-1}_{\text{得到其余 }n-1\text{ 个结果所需时间}}
    $$

!!! info "例题 1"
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260618112434492.png){ loading=lazy width="70%" } </figure>

    解答：

    - 链接图：
        <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260618112451822.png){ loading=lazy width="70%" } </figure>

    - 如果全部串行执行，执行时间为 $(1 + 6 + 1 + N - 1) + (1 + 6 + 1 + N - 1) + (1 + 7 + 1 + N - 1) = 3N + 22$ 拍；
    - 如果前 2 条并行，第 3 条串行执行，执行时间为 $\max(1 + 6 + 1 + N - 1, 1 + 6 + 1 + N - 1) + (1 + 7 + 1 + N - 1) = 2N + 15$ 拍；
    - 如果前 2 条并行，并与第 3 条链接执行，执行时间为 $(1 + 6 + 1) + (1 + 7 + 1) + N - 1 = N + 16$ 拍。

!!! info "例题 2"
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260618143106691.png){ loading=lazy width="70%" } </figure>
    
    解：

    考虑链接技术，分为以下编队：

    * 编队 1：$LDV V3, M(A)$ 和 $ADDV V2, V4, V5$
    * 编队 2：$MULV V6, V3, V2$

    其中，第一个编队中，2 条指令可并行执行，且均需 $2 + 8 + 2 = 12$ 拍得到结果，因此可以和第二个编队中的指令链接执行，因此：
    $$
    \text{通过时间} = \text{编队 1 通过时间} + \text{编队 2 通过时间} = 12 + (2 + 12 + 2) = 28 \text{拍}
    $$

    总时间 = 通过时间 + 向量长度 - 1 = $28 + 20 - 1 = 47$ 拍。

    如果编队 1 中的 2 条指令的通过时间不相等，例如 $LDV$ 指令的通过时间为 9 拍，$ADDV$ 指令的通过时间为 8 拍，则无法链接执行，只能串行执行，因此
    
    * 编队 1 的通过时间 = $\max{(2 + 8 + 2), (2 + 9 + 2)} = 13$ 拍
    * 编队 2 的通过时间 = $2 + 12 + 2 = 16$ 拍
    * 串行总时间 = $13 + (20 - 1) + 16 + (20 - 1) = 67 $ 拍。

!!! tip
    * 上题中，第 3 条的源操作数来自前 2 条指令的结果，并且前 2 条指令产生运算结果的时间（有关功能部件的通过时间）相等，因此可以进行链接执行。
    * 注意链接执行只是允许产生第一个结果就可以进行后续的向量操作，而不是等到整个向量结果全部产生。

!!! info "例题 3（个人解答）"
    在 CRAY-1 型向量处机上，V 为向量寄存器，长度为 64；S 为标量寄存器。所用浮点功能部件的执行时间分别为：加法需6拍，乘法需7拍，从存储器读数需6拍，求倒数近似值需14拍，打入寄存器需1拍，启动功能部件（包括存储器）需1拍。问下列各指令组中的哪组指令可以链接？哪组可以并行执行？说明原因并分别计算各指令组全部完成所需的拍数。

    2. $V3\leftarrow\text{存储器}, V2\leftarrow V0\times V1, V4\leftarrow V2+V3$

    * 第一组可以并行执行，这三条指令（访存、向量加、向量乘）使用了不同的功能部件，且彼此之间没有使用相同的源寄存器或目的寄存器，不存在数据相关，因此它们完全可以分在一个编队中并行执行。
        * 全部完成所需的拍数 = $\max{(1 + 6 + 1, 1 + 6 + 1, 1 + 7 + 1)} + (64 - 1) = \max{(8, 8, 9)} + 63 = 9 + 63 = 72$ 拍。

        * 全部完成所需的拍数 = $\max{(1 + 6 + 1, 1 + 7 + 1)} + (64 - 1) + (1 + 6 + 1) + (64 - 1) = \max{(8, 9)} + 63 + 8 + 63 = 9 + 63 + 8 + 63 = 143$ 拍。

### 分段开采技术

* 单条指令执行：需 $T_{vp} = (T_{start} + n)$ 个时钟周期；其中 $T_{start}$ 是该指令启动时间。
* 一组指令执行：
    * 不分段开采：需 $T_{all} = T_{start} + m \cdot n$ 个时钟周期；
        - $m$ 是指令编队数；
        * $T_{start}$ 是各编队的启动时间之和，编队的启动时间一般取编队内指令启动时间的最大值。
        * 需要注意的是，如果编队内指令采用了链接技术，那么启动时间一般取链接指令的启动时间之和。
    * 分段开采：需 $T_{all} = \left\lceil \frac{n}{MVL} \right\rceil \cdot (T_{start} + T_{loop}) + m \cdot n$ 个时钟周期。

!!! info "例题 1"
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260618132905644.png){ loading=lazy width="70%" } </figure>
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260618132916250.png){ loading=lazy width="70%" } </figure>

    解：

    当不采用向量链接时，分编队如下：

    * 编队 1：$LV V1, Rx$
    * 编队 2：$MULTFV V2, F0, V1$ 和 $LV V3, Ry$
    * 编队 3：$ADDV V4, V2, V3$
    * 编队 4：$SV V4, Ry$

    因此，$T_{start} = 12 + \max{(12,7)} + 6 + 12 = 42$，$m = 4$，因此对 $n$ 个向量元素计算所需的总时间周期数为：
    $$
    T_{all} = \left\lceil \frac{n}{MVL} \right\rceil \cdot (T_{start} + T_{loop}) + m \cdot n = \left\lceil \frac{n}{64} \right\rceil \cdot (42 + 15) + 4n = \left\lceil \frac{n}{64} \right\rceil \cdot 57 + 4n
    $$

    采用向量链接时，分编队如下：

    * 编队 1：$LV V1, Rx$ 和 $MULTFV V2, F0, V1$
    * 编队 2：$LV V3, Ry$ 和 $ADDV V4, V2, V3$
    * 编队 3：$SV V4, Ry$

    由于前 2 个编队都采用了链接技术，因此各编队的启动时间分别为：

    * 编队 1：$T^{(1)}_{start} = 12 + 7 = 19$；
    * 编队 2：$T^{(2)}_{start} = 12 + 6 = 18$；
    * 编队 3：$T^{(3)}_{start} = 12$；

    因此对 $n$ 个向量元素计算所需的总时间周期数为：
    $$
    T_{all} = \left\lceil \frac{n}{MVL} \right\rceil \cdot (T_{start} + T_{loop}) + m \cdot n = \left\lceil \frac{n}{64} \right\rceil \cdot (19 + 18 + 12 + 15) + 3n = \left\lceil \frac{n}{64} \right\rceil \cdot 64 + 3n
    $$

    注意：**在链接的时候，编队的含义就不是并行了，而是编队内的指令可以连接，因此是相加而不是取最值**。

### 四大基本互连函数

!!! note "交换函数"
    二进制地址编码中 <u>**第 k 位互反**</u>：
    $$
    Cube_{(k)} = E(x_{n-1}x_{n-2}...x_{k+1}x_kx_{k-1}...x_0) = x_{n-1}x_{n-2}...x_{k+1}\overline{x_k}x_{k-1}...x_0
    $$
    又称立方体（Cube）置换，用于构造 <u>**立方体和超立方体**</u> 互连网络。

!!! note "均匀洗牌函数"
    把输入端的二进制编号 <u>**循环左移一位**</u>：
    $$
    \sigma(x_{n-1}x_{n-2}...x_1x_0) = x_{n-2}x_{n-3}...x_0x_{n-1}
    $$

!!! note "蝶式互连函数"
    把输入端的二进制编号的 <u>**最高位与最低位互换位置**</u>：
    $$
    \beta(x_{n-1}x_{n-2}...x_1x_0) = x_0x_{n-2}...x_1x_{n-1}
    $$

!!! note "PM2I互连函数（一种特殊移数函数）"
    $$
    \begin{aligned}
    PM2_{+i} &= (x + 2^i) \mod N \\
    PM2_{-i} &= (x - 2^i) \mod N
    \end{aligned}
    $$

### 阵列处理机 / 多处理机上的计算问题

!!! info "例题 1 SIMD"
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260620191850230.png){ loading=lazy width="70%" } </figure>

    解答：

    * 一个 PE 的 SISD 机需串行计算 32 次乘法操作和 31 次加法操作，总时间 = $32\times 4\Delta t + 31\times 2\Delta t = 190\Delta t$；
    * 一个 16 个 PE 连接成超立方体的阵列处理机：
        * 源操作数被分为 16 组分别位于 16 个 PE；
        * 每个 PE 先进行 2 次乘法操作和 1 次加法操作，总时间 = $2\times 4\Delta t + 1\times 2\Delta t = 10\Delta t$；
        * 在超立方体上，每次 PE 按照维度进行通信并减维，例如原本是 4 维超立方体，构成的 2 个 3 维超立方体之间直接连接的 PE 进行通信和加法操作，通信时间为 $1\Delta t$，加法操作时间为 $2\Delta t$，总时间 = $3\Delta t$；4 维 减到 0 维需要 4 次。
        * 因此总时间 = $10\Delta t + 4\times (1\Delta t + 2\Delta t) = 22\Delta t$；
