# 阵列处理机

## 基本概念

* 阵列处理机（Array Processor）：
    * 由多个处理单元组成，通过资源重复提高并行性；
    * 通过单一的控制部件来控制所有处理单元对各自数据进行相同的运算法和操作；
    * 又称 **SIMD（单指令多数据流）**计算机 / 并行处理机；
* 操作模型：
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260620142546471.png){ loading=lazy width="70%" } </figure>
    * 所有处理单元被动接收控制部件 CU 广播的同一条指令，操作对象为不同的数据；
    * 五元组表示 $(N, C, I, M, R)$
        * $N$：处理单元 PE 的数量；
        * $C$：控制部件 CU 直接执行的指令集；
        * $I$：由 CU 广播至 PE 进行并行执行的指令集；
        * $M$：屏幕方案集，每种屏蔽将所有PE划分成允许操作和禁止操作两种工作模式；
        * $R$：数据寻径功能集，说明互连网络中PE间通信所需要的各种设置模式；
* 特点：
    * SIMD
    * 通过设置多个相同的处理单元来开发并行性（利用同时性而非并发性，操作是相同的，没用流水线）
    * 与并行算法密切结合
    * 实际由 PE + 控制器 + 前端机 组成

## 分布式存储器的阵列处理机

* 每个 PE 有各自的本地存储器 LM
* PE 间通过数据寻径网络互连，控制部件通过执行程序控制数据寻径网络
    * 主要差异在于数据寻径网络不同
* 指令的执行顺序基本上是串行进行的
* PE 间的同步由控制部件的硬件实现
    * 可让所有 PE 在同一周期内执行同一条指令
    * 也可采用屏蔽逻辑来控制某些 PE 在某些周期内不参与执行指令
* 程序和数据是通过主机装入控制存储器

## 共享存储器的阵列处理机

* 集中设置存储器
    * 共享的多体并行存储器 SM —— 通过**对准网络** —— 与各 PE 相连。
        * **对准网络**：实现处理单元和所需访问的存储器对准的互连网络
    * 存储模块数 >= PE 数量
* 必须减少存储器访问冲突
* 适合 PE 较少的情况
* 所有阵列指令使用长度等于 PE 个数的向量操作数。
