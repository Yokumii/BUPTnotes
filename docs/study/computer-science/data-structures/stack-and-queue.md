# 栈与队列

## 栈

栈（Stack）
: 一种**后进先出**（LIFO, Last In First Out）的线性表，只允许在表的一端（栈顶）进行插入和删除操作。

### 顺序栈

顺序栈采用一组连续的存储单元依次存放自栈底到栈顶的数据元素。

- 非空栈中的栈顶指针 **top 指向栈顶元素的下一个位置**；
- 空栈时 `top = base`，栈中元素的数量为 $\text{top} - \text{base}$；

!!! note
    top 指向栈顶元素的"下一个位置"而非栈顶元素本身，这是为了简化入栈操作——入栈时直接写入 `top` 位置，然后 `top++` 即可，无需先移动指针再写入。

### 链栈

链栈采用链式存储结构，不需要预设存储空间，且不存在栈满上溢的问题。

- 链表指针方向是**从栈顶指向栈底**；

!!! abstract "顺序栈 vs 链栈"
    顺序栈需要预分配固定大小的连续空间，可能面临栈满上溢问题；链栈动态分配空间，不会上溢，但每个节点需额外存储指针域，空间开销略大。

### 应用

#### 括弧匹配检验

利用栈来检查表达式中的括弧是否匹配：遇到左括弧则入栈，遇到右括弧则与栈顶元素比较——若匹配则出栈，若不匹配则报错。表达式扫描结束后，栈应为空。

#### 中缀表达式优先级规则

在中缀表达式求值中，运算符优先级取决于其**位置**：

- 左括号在栈外时优先级最高，在栈内时优先级很低，仅高于栈外的右括号；
- 运算符入栈前，需将栈中优先级不低于它的运算符依次弹出并计算；

#### 后缀表达式

后缀表达式（逆波兰表达式）中，运算符紧跟在操作数之后，无需括弧即可唯一确定运算顺序。计算时从左到右扫描：遇到操作数入栈，遇到运算符弹出栈顶两个操作数进行计算，结果再入栈。

#### 尾递归优化

尾递归
: 递归调用出现在函数中的最后一行，并且没有任何局部变量参与最后一行代码的计算。

支持"尾递归优化"的编程语言在执行尾递归代码时**不进行入栈操作**，直接用新调用的参数替换当前帧，从而将递归转化为循环，避免栈溢出。

!!! example "尾递归示例"
    ```python
    # 尾递归形式
    def factorial(n, acc=1):
        if n == 0:
            return acc
        return factorial(n - 1, acc * n)  # 递归调用是最后一步，无后续计算
    ```

## 队列

队列（Queue）
: 一种**先进先出**（FIFO, First In First Out）的线性表，只允许在表的一端（队尾 rear）插入，在另一端（队头 front）删除。

### 顺序队列

顺序队列采用一组连续的存储单元存放队列元素：

- 队空时 `front = rear = 0`；
- 非空队列中，头指针 `front` 始终指向队列头元素，尾指针 `rear` 始终指向**队列尾元素的下一个位置**；

!!! warning "假溢出"
    顺序队列在反复入队和出队后，`rear` 可能已到达数组末尾，但数组前端仍有空闲空间，此时无法继续入队——这种现象称为**假溢出**。循环队列正是为解决此问题而引入。

### 循环队列

循环队列将顺序队列的首尾相连，形成逻辑上的环形结构：

- 判空：$front == rear$
- 判满：$(rear + 1) \ \% \ \text{MAXSIZE} == front$（少用一个元素空间，当队尾指针加 1 从后面赶上队头指针时判定为满）

!!! note
    循环队列牺牲一个存储单元来区分"队空"和"队满"状态。若不牺牲，则队空和队满时 $front == rear$，无法区分。

???+ info "循环队列的元素数量"
    循环队列中元素的数量为：

    $$\text{length} = (rear - front + \text{MAXSIZE}) \ \% \ \text{MAXSIZE}$$

    加 `MAXSIZE` 是为了处理 $\text{rear} < \text{front}$ 的情况。

### 链队

链队采用链式存储结构，由队头指针和队尾指针分别指向链表的头节点和尾节点：

- 入队操作在队尾追加节点，更新 `rear` 指针；
- 出队操作删除队头节点，更新 `front` 指针；
- 链队不存在假溢出和队满问题（除非内存耗尽）；

!!! abstract "顺序队列 vs 链队"
    顺序队列（含循环队列）适合队列长度可预估的场景，空间利用率高；链队适合队列长度变化较大的场景，动态分配空间，但每个节点需额外存储指针域。
