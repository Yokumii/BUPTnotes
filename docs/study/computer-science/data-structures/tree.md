# 树与二叉树

## 树的基本概念

树
: $n(n \geq 0)$ 个结点的有限集合。当 $n = 0$ 时称为空树；当 $n > 0$ 时，有且仅有一个称为**根**的结点，其余结点可分为 $m(m > 0)$ 个互不相交的有限集合，每个集合本身又是一棵树，称为根的**子树**。

结点的度
: 结点拥有的子树数

树的度
: 树中各结点度的最大值

叶子结点（终端结点）
: 度为 $0$ 的结点

分支结点（非终端结点）
: 度不为 $0$ 的结点

内部结点
: 除根结点外的分支结点

孩子与双亲
: 结点的子树的根称为该结点的**孩子**，该结点称为孩子的**双亲**

兄弟
: 同一双亲的孩子之间互为**兄弟**

结点的层次
: 从根开始定义，根为第 1 层，根的孩子为第 2 层，依次递推

树的深度（高度）
: 树中结点的最大层次

森林
: $m(m \geq 0)$ 棵互不相交的树的集合。对树中每个结点而言，其子树的集合即为森林

!!! abstract "树的关键性质"
    - 树中结点数等于所有结点的度数之和加 $1$：$n = \sum_{i=1}^{n} \text{degree}(v_i) + 1$
    - 度为 $k$ 的树中，第 $i$ 层上最多有 $k^{i-1}$ 个结点（$i \geq 1$）
    - 深度为 $h$ 的 $k$ 叉树最多有 $\frac{k^h - 1}{k - 1}$ 个结点

## 二叉树

二叉树
: 每个结点最多有两棵子树（左子树和右子树）的有序树。二叉树的子树有左右之分，次序不能颠倒。

满二叉树
: 深度为 $h$ 且含有 $2^h - 1$ 个结点的二叉树，即每层都含有最大结点数

完全二叉树
: 深度为 $h$、有 $n$ 个结点的二叉树，当且仅当其每个结点都与深度为 $h$ 的满二叉树中编号从 $1$ 到 $n$ 的结点一一对应时，称为完全二叉树

???+ info "二叉树的重要性质"
    1. 在二叉树的第 $i$ 层上最多有 $2^{i-1}$ 个结点（$i \geq 1$）
    2. 深度为 $h$ 的二叉树最多有 $2^h - 1$ 个结点（$h \geq 1$）
    3. 对任意二叉树，若叶子结点数为 $n_0$，度为 $2$ 的结点数为 $n_2$，则 $n_0 = n_2 + 1$
    4. 具有 $n$ 个结点的完全二叉树的深度为 $\lfloor \log_2 n \rfloor + 1$
    5. 对完全二叉树的结点按层序编号，结点 $i$：
        - 若 $i > 1$，则双亲编号为 $\lfloor i / 2 \rfloor$
        - 若 $2i \leq n$，则左孩子编号为 $2i$；否则无左孩子
        - 若 $2i + 1 \leq n$，则右孩子编号为 $2i + 1$；否则无右孩子

### 二叉树的遍历

遍历方式
: 按某种搜索路径访问二叉树的每个结点，使每个结点均被访问一次且仅被访问一次

    先序遍历（Preorder）
    : 根 → 左 → 右

    中序遍历（Inorder）
    : 左 → 根 → 右

    后序遍历（Postorder）
    : 左 → 右 → 根

    层序遍历
    : 按层次从上到下、每层从左到右依次访问

???+ tip "遍历的关键结论"
    - 由**先序 + 中序**或**后序 + 中序**可以唯一确定一棵二叉树
    - 仅由先序 + 后序**不能**唯一确定一棵二叉树（除非每个结点都只有左孩子或只有右孩子）
    - 先序遍历序列的第一个结点是根，后序遍历序列的最后一个结点是根

### 二叉树的存储结构

顺序存储
: 用一组地址连续的存储单元依次自上而下、自左至右存储完全二叉树的结点元素。适用于**完全二叉树**，对于一般二叉树会浪费大量空间。

链式存储
: 每个结点包含数据域、左指针域和右指针域。对于含 $n$ 个结点的二叉链表，有 $2n$ 个指针域，其中 $n - 1$ 个指向孩子，$n + 1$ 个为空指针。

## 线索二叉树

线索二叉树
: 利用二叉链表中的 $n + 1$ 个空指针域存放指向结点在某种遍历序列中的**直接前驱**或**直接后继**的指针，这些指针称为**线索**。

!!! abstract "线索化规则"
    - 若结点**无左孩子**，则左指针指向其**直接前驱**结点
    - 若结点**无右孩子**，则右指针指向其**直接后继**结点
    - 为区分指针指向孩子还是线索，每个结点需增加两个标志域 `ltag` 和 `rtag`：
        - `ltag = 0`：左指针指向左孩子；`ltag = 1`：左指针指向直接前驱
        - `rtag = 0`：右指针指向右孩子；`rtag = 1`：右指针指向直接后继

???+ info "线索二叉树的使用"
    线索化后，遍历二叉树无需递归或栈，可直接利用线索找到下一个结点，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

    - **先序线索二叉树**：利用先序遍历序列的线索关系
    - **中序线索二叉树**：利用中序遍历序列的线索关系
    - **后序线索二叉树**：利用后序遍历序列的线索关系

    其中中序线索二叉树最为常用，因为中序线索下找后继最为方便。

## 树和森林

### 孩子兄弟链表表示法

孩子兄弟链表表示法
: 一种将一般树转换为二叉链表存储的方法，规则为**左孩子，右兄弟**：

    - 每个结点的**左指针**指向其**第一个孩子**（长子）
    - 每个结点的**右指针**指向其**下一个兄弟**

???+ info "孩子兄弟表示法的意义"
    孩子兄弟链表表示法是树与二叉树之间转换的桥梁。通过"左孩子右兄弟"规则，任何一棵树都可以映射为一棵二叉树，从而利用二叉树的成熟算法来处理一般树的问题。

### 树转化为二叉树

!!! abstract "三步转换规则"
    1. **连线**：在所有兄弟结点之间加一条连线
    2. **删线**：对每个结点，除了保留与其长子的连线外，去掉该结点与其他孩子的连线
    3. **旋转**：以根为轴心将整棵树顺时针转 $45^{\circ}$

???+ tip "树转二叉树的特点"
    转换后的二叉树**无右子树**，左支代表孩子关系，右支代表兄弟关系。

### 森林转化为二叉树

!!! abstract "两步转换规则"
    1. **逐棵转换**：先将森林中的每一棵树转化为二叉树
    2. **依次合并**：从后一棵树开始，将后一棵树作为前一棵树的**右子树**，依次合并

???+ tip "森林转二叉树的理解"
    森林中各棵树的根结点被视为兄弟关系，因此在二叉树中依次出现在右支上：第一棵树的根为二叉树的根，第二棵树的根为其右孩子，第三棵树的根为其右孩子的右孩子……以此类推。

### 二叉树转化为树/森林

!!! abstract "两步转换规则"
    1. **连线**：把双亲结点的左孩子的右孩子、右孩子的右孩子、……（即左支上所有右链上的结点）和双亲结点连接起来
    2. **删线**：删除所有双亲结点与右孩子的连线

???+ tip "判断转化结果"
    若二叉树的根结点有右子树，则转化结果为**森林**；若根结点无右子树，则转化结果为**树**。

树的遍历方式
: 由于树不像二叉树有固定的左右子树之分，树的遍历主要分为以下两种：

    先序遍历
    : 先访问根结点，然后依次先序遍历根的每棵子树

    后序遍历
    : 先依次后序遍历根的每棵子树，最后访问根结点

???+ info "树与对应二叉树遍历的关系"
    - 树的**先序遍历** = 对应二叉树的**先序遍历**
    - 树的**后序遍历** = 对应二叉树的**中序遍历**

### 森林的遍历

森林的遍历方式
: 森林的遍历基于逐棵遍历每棵子树的思想：

    先序遍历
    : 逐棵先序遍历每棵子树，等同于对应二叉树的**先序遍历**

    中序遍历
    : 逐棵中序遍历每棵子树，等同于对应二叉树的**中序遍历**

!!! important "森林遍历与二叉树遍历的对应关系"
    | 森林遍历 | 对应二叉树遍历 |
    |----------|----------------|
    | 先序遍历 | 先序遍历 |
    | 中序遍历 | 中序遍历 |
