# 交换概论

## 通信网的组成（三要素）

<figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260624144543447.png){ loading=lazy width="70%" } </figure>

* **终端设备**：包括电话机、传真机等简单用户终端，负责信息的发送与接收。
* **传输设备**：包括用户线路、中继线路和信号转换设备（如双绞线、光缆、微波等），负责提供信息传输的物理通道。
* **交换设备**：包括各类交换机和交叉连接设备，负责在通信的源和目的终端之间建立通信信道传送通信信息的机制。

??? note "补充：通信网的分层结构与支撑网"
    * **分层结构**：通信网可划分为 <u>**应用层**</u>、<u>**业务层**</u>、<u>**传送层**</u>（包括接入网和骨干传送网）。
    * **支撑网**（极易考点）：除了业务网，现代电信网还包含三大支撑网络以保障运行：
        * **信令网**：通信网的“神经系统”
        * **数字同步网**：保证网络中的交换和传输等设备的时钟同步
        * **电信管理网**（TMN）：完成性能、配置、故障、计费、安全等管理（FCAPS）
    * **通信的基本问题**：包括编码（用什么格式传）、寻址（如何找到对方）、以及网络结构和带宽复用等额外要求。

## 通信网“三对”基本概念

### 信息传送

* **面向连接**：分为 <u>**物理连接**</u>（如电路交换）和 <u>**逻辑连接**</u>（如分组交换中的虚电路、ATM）。工作过程通常包含“<u>**连接建立、信息传送、连接释放**</u>”三个阶段。
* **无连接**：<u>**边选路（寻址）边传递信息**</u>，典型如数据报（IP网络），类似于Hop-by-hop（逐跳）转发。

### 时分复用

* **同步时分复用**：用于 <u>**电路交换**</u>。属于 <u>**位置化信道**</u>（依据信号在时间轴上的位置来区别每一路信号），无信息传送时也占用信道，<u>**子信道信息流速率恒定**</u>，适用于**实时、恒定速率的业务（如话音）**。
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260624150042977.png){ loading=lazy width="70%" } </figure>
* **统计（异步）时分复用**：用于<u>**分组交换、ATM交换等**</u>。属于 <u>**标志化信道**</u>（利用标志码标识哪路信息，与时间位置无关），<u>**分组长度可变或固定**</u>，通过统计复用**提高信道利用率**，适用于**速率可变**业务。
    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260624150053365.png){ loading=lazy width="70%" } </figure>

### 带宽分配

* **固定带宽分配**：对应同步时分复用（如电路交换）。
    * 适用于实时、恒定速率的业务（如话音）
    * 无差错控制，对通信信息不作处理（透明传输），无排队时延，通信延时小
    * 可靠性差，流量控制基于呼叫损失制（呼损制）
    * 带宽利用率低
* **动态带宽分配**：对应统计/异步时分复用（如分组交换、ATM）。


## 交换方式的技术特点

!!! note "从以下几方面来分析比较电路交换、分组交换（数据报和虚电路）、MPLS 主流交换技术的特点"
    * 支持的业务类型（话音/数据/图像/视频）和典型业务特征（实时性/突发性/可靠性/交互性等）
    * 信息传送单元和信息传送长度可变或固定
    * 适合的信息复用方式
    * 连接类型（面向连接/无连接，物理连接/逻辑连接）和信息传输时延特点 
    * 对业务冲突或过载的处理方式（呼损/等待/流控）
    * 信息可靠性或实时性

    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260624151731450.png){ loading=lazy width="70%" } </figure>

    几个核心要点：

    1. **电路交换 (Circuit Switching)**：
        * 面向物理连接
        * 同步时分复用（固定带宽分配）
        * 信息传送的最小单位是 <u>**时隙**</u>：每个时隙采样 8bit，采样率 8kHz，每路通信速率 64kbps
        * 无差错控制机制，对通信信息不作处理（<u>**透明传输**</u>）
            * 电路传送模式（CTM）具有 <u>**时间透明**</u> 性（无排队时延）
        * 流量控制基于呼叫损失制（呼损制）
        * 适用业务：<u>**实时**</u>、<u>**恒定速率**</u>的话音业务（如PSTN）
    2. **分组交换 (Packet Switching) **：
        * 采用“存储转发”机制，信息的最小传送单位是 <u>**分组**</u>（可变长或固定长）
        * 面向连接（逻辑连接，虚电路）或无连接（数据报）
        * 统计时分复用（动态分配带宽）
        * 有差错控制和信息处理
            * 分组传送模式（PTM）具有 <u>**语义透明**</u> 性（有差错控制保真）
        * 流量控制基于呼叫延迟制
    3. **MPLS 交换**：
        * 面向连接（逻辑连接）：在数据传输前，MPLS会通过标记分发协议（如LDP）建立一条逻辑连接路径，即标记交换路径（LSP）
        * 最小信息交换单元是 <u>**带标记的分组**</u>：协议数据单元允许变长，标记（Label）是固定长度的
        * 统计（异步）时分复用和动态带宽分配：通过分组头（或插入的标记层）中的标记来区分每一路逻辑信道
        * 具有更高的可靠性和实时性保障
    4. **ATM 交换**：
        * 最小单位是固定长度的 <u>**信元**</u>（由 5 个字节的信头（Header）+ 48 个字节的信息段（Payload）组成，**总长度为固定 53 个字节**）
        * 网络是通过信头中表明逻辑信道的 **标记（VPI/VCI标签）** 来区分每一个逻辑信道的
        * 融合了电路交换高速化（硬件交换、短排队时延）和分组交换灵活性（**面向连接**、**异步时分复用**、**动态分配带宽**）的优点
        * 交换节点不对信息进行流量和差错控制
        * 时间透明、语义透明

    <figure markdown="span">   ![](https://webp-pic.yokumi.cn/2026/06/20260624165055861.png){ loading=lazy width="70%" } </figure>

!!! note "虚电路 vs. 数据报"
    | | 虚电路 | 数据报 |
    | - | --- | --- |
    | 分组头 | 简单（逻辑信道号） | 复杂（详细的选路信息） |
    | 选路 | 虚连接表 | 每个分组独立选路 |
    | 分组顺序 | 有序 | 可能失序 |
    | 故障敏感性 | 敏感 | 可靠性高 |
    | 应用 | 连续数据流 | 询问/响应 |

## 各种常用网络的交换方式

| 业务网 | 交换方式 
| --- | --- |
| PSTN 电话交换网 | 电路交换（模拟电话） |
| GSM / CDMA（2G网络）| 电路交换（电话、低速数据）|
| GPRS / EDGE（2.5G网络）| 电路交换 & 分组交换 |
| 3G / 4G / 5G网络 | 分组交换 |
| Internet | 分组交换 |
| X.25网络 | 分组交换（中低速数据）|
| N-ISDN  窄带综合业务数字网 | 电路交换 & 分组交换（多速率或中高速数据）|
| DDN 数字数据网 | 电路交换 |
| FRN（帧中继网）| 帧中继 |
| B-ISDN 宽带综合业务数字网 | ATM交换（多媒体、宽带综合业务）|
| NGN（下一代网络）| 软交换、IMS |
