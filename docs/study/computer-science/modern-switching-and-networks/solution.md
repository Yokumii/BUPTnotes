# 题解

## 填空题

!!! note "通信网三要素"
    构成通信网的三个基本要素是 <u>**交换设备**</u>、<u>**传输设备**</u> 和 <u>**终端设备**</u>。

!!! note "通信网的支撑网"
    通信网的支撑网是 <u>**信令网**</u>、<u>**数字同步网**</u> 和 <u>**电信管理网（TMN）**</u>。

!!! note "电信交换系统的基本结构"
    程控数字交换系统由 <u>**信息传送子系统**</u>、<u>**控制子系统**</u> 构成。

!!! note "信息传送至系统的基本结构"
    信息传送子系统由 <u>**网络接口**</u> 和 <u>**交换网络**</u> 构成。

!!! note "空分方式 vs. 时分方式"
    构成交换节点的交换网络的基本交换单元可以分为空分方式与时分方式，其中 <u>**共享存储器型（T 接线器）**</u> 和 <u>**共享总线型（DSE 数字交换单元）**</u> 属于时分方式，而 <u>**空间接线器（S 接线器） / 开关阵列**</u> 属于空分方式。

### 移动通信系统总结

| 移动通信代际 | 网络部分 | 网元设备名称 | 主要功能说明 |
| :--- | :--- | :--- | :--- |
| **2G (GSM)**<br>及**2.5G (GPRS)** | **无线接入网 (RAN)** | **BTS** (基站收发信机) / **BSC** (基站控制器) <br> **PCU** (分组控制单元，2.5G新增)| 负责无线信号的收发与无线资源的控制管理。<br> 在原有2G的BSC上增加了PCU，以支持分组数据包在无线侧的接入 |
| | **核心网 (CN)**<br>*(电路域 CS)* | **MSC** (移动交换中心) | 负责电路交换业务的呼叫控制与路由。 |
| | | **HLR / VLR** (归属/拜访位置寄存器) <br> **AUC / EIR** | 负责用户永久签约数据存储与当前位置信息管理。<br> AUC 对接入 GSM 网络的用户进行认证，EIR 对接入 GSM 网络的移动终端设备进行认证 |
| | **核心网 (CN)**<br>*(分组域 PS)* | **SGSN** (服务GPRS支持节点) / **GGSN** (网关节点) | 2.5G叠加引入分组域，SGSN负责分组业务的移动性管理与路由，GGSN负责与固定电话网互联互通（分配IP地址） |
| **3G (UMTS)**<br>*(含R99/R4/R5)* | **无线接入网 (RAN)** | **Node B** (基站) / **RNC** (无线网络控制器) | 3G的无线接入设备，负责基带处理与无线资源控制。 |
| | **核心网 (CN)**<br>*(CS域 - R4演进)* | **MSC Server** (MSS) / **MGW** (媒体网关) | R4版本引入软交换思想，实现**控制与承载分离**。MSC拆分为MSC Server（负责呼叫控制）和MGW（负责媒体承载）。 |
| | **核心网 (CN)**<br>*(PS域)* | **SGSN / GGSN** | 延续分组域功能，处理数据业务。 |
| | **核心网 (CN)**<br>*(IMS域 - R5引入)* | **CSCF** (呼叫会话控制功能) / **HSS** (归属用户服务器) | R5版本提出全IP承载，引入IMS处理IP多媒体业务（语音、视频等），HSS替代HLR作为集中数据库。 |
| **4G (LTE)** | **无线接入网 (RAN)** | **eNodeB** (演进型基站) | **架构扁平化**，取消了原有的RNC控制器，eNodeB直接接入核心网。 |
| | **核心网 (EPC)**<br>*(控制面)* | **MME** (移动性管理实体) | 专职负责控制面的**移动性管理**、会话建立**信令控制**等。 |
| | **核心网 (EPC)**<br>*(用户面)* | **S-GW** (服务网关) / **P-GW** (PDN网关) | 负责用户面数据报文的路由和转发，连接外部数据网络（DN）。 |
| | **核心网 (EPC)**<br>*(其他)* | **HSS / PCRF** | HSS存储用户数据；PCRF负责策略控制与计费规则。 |
| **5G (NR/SBA)** | **无线接入网 (RAN)** | **gNB** (5G基站：分为 **CU** / **DU** / **AAU**) | 基站功能重构。**CU**（集中式单元）处理非实时高层协议；**DU**（分布式单元）处理物理层和实时性层2功能；**AAU**（有源天线单元）负责射频。 |
| | **核心网 (5GC)**<br>*(控制面)* | **AMF** (接入和移动性管理功能) | 负责用户的注册、连接、可达性以及移动性管理。 |
| | | **SMF** (会话管理功能) | 负责PDU会话的建立与管理、UPF的选择和控制、IP分配及计费。 |
| | | **UDM** (统一数据管理) | 负责用户的签约信息管理及接入授权。 |
| | | **PCF** (策略控制功能) | 负责提供策略规则管理和基于切片的策略。 |
| | | **AUSF / NSSF / NRF** | AUSF负责鉴权；NSSF负责网络切片选择；NRF负责网络功能的自动化发现与注册管理。 |
| | **核心网 (5GC)**<br>*(用户面)* | **UPF** (用户平面功能) | 作为用户面唯一的核心网元，担任移动性锚点，负责报文的路由、转发以及连接外部数据网络（代替了4G的SGW/PGW）。 |

!!! info "对比 4G 与 5G 核心网架构，简述核心区别"
    * “刚性网络” vs. “柔性网络”：
        * 4G核心网是刚性网络，基于传统物理网元设备实体，固定连接、功能、信令交互，可扩展性差；
        * 5G核心网是柔性网络，采用了基于服务的架构（SBA），实现了柔性网络，网络功能被解耦和微服务化，并通过软件定义来实现网络功能和连接。
    * “物理网元实体” vs. “虚拟化与云化”
        * 4G 核心网主要由专用的物理网元实体构成
        * 5G 核心网全面采用了云化分布式部署架构，通过 SDN（软件定义网络）和 NFV（网络功能虚拟化）技术对网元进行虚拟化处理；
    * “点对点架构” vs. “服务化架构”
    * “单体式构架” vs. “微服务化构架”
    * “单一网络” vs. “网络切片”
        * 4G 采用单一的网络来承载所有类型的业务
        * 5G 则原生支持网络切片技术，能够基于统一的基础设施按需构建出多个逻辑隔离的端到端专用网络，从而为不同垂直行业（如 eMBB、uRLLC、mMTC）提供定制化、差异化的服务质量保障
    * 控制面与用户面的彻底分离

!!! note "简述 5G 接入网 gNB 采用 CU/DU 分离架构 的核心原因，并说明 CU 与 DU 各自负责的功能范围。"
    * 核心原因：
        * 增强小区间深度协作
        * 满足 5G 多样化业务差异化需求
        * 增加组网灵活性
    * CU：处理非实时的无线高层协议栈功能；
    * DU：处理实时的物理层和低层协议栈功能。

### SIP 协议

!!! note "2016-2017"
    某视频监控系统使用了 SIP 信令来完成多媒体通信；视频监控的网管平台是一个 UA，可以注册到 SIP 服务器；摄像头也是一个 UA，同样注册到 SIP 服务器；在网管平台需要查看实时视频时，就是两个 UA 之间的 SIP 会话。
    
    1. 在下图中，画出当视频监控网管平台在实时查看摄像头视频时，对应的 SIP 消息流；
    2. 其中，网管发出的 SDP 信息中，携带内容包括：
        `c=IN IP4 172.16.106.31  m=video 60003 RTP/AVP 98 99`
        而摄像头发出的 SDP 信息中，携带内容包括：
        `c=IN IP4 172.16.105.86  m=video 16000 RTP/AVP 98 99`
        请问网管平台应该在哪个 IP 地址准备接收视频流？在视频传输中使用的是什么传输协议？
    
    ```
    视频监控网管平台          SIP服务器              摄像头
      |                     |                    |
      |------ INVITE ------>|                    |
      |  SDP: 网管接收地址    |                    |
      |                     |------ INVITE ----->|
      |                     |  SDP: 网管接收地址   |
      |<---- 100 Trying ----|                    |
      |                     |<---- 100 Trying ---|
      |                     |                    |
      |                     |<--- 180 Ringing ---|
      |<---- 180 Ringing ---|                    |
      |                     |                    |
      |                     |<----- 200 OK ------|
      |                     |  SDP: 摄像头媒体地址 |
      |<----- 200 OK -------|                    |
      |  SDP: 摄像头媒体地址  |                    |
      |                     |                    |
      |-------- ACK ------->|                    |
      |                     |-------- ACK ------>|
      |                     |                    |
      |<========= RTP 视频流 =====================|
      |        摄像头向网管平台发送实时视频           |
      |                     |                    |
    ```

    网管应该在 `172.16.106.31` 地址准备接收视频流，使用的是 RTP 传输协议。
