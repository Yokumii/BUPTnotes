# 编译概述

## 翻译和解释

编译
: 把高级语言程序转换成等价的低级语言程序的过程

程序设计语言
: 按抽象层次可分为低级语言与高级语言两大类

    - 低级语言
        - 机器语言
        - 符号语言/汇编语言
    - 高级语言

翻译程序
: 扫描所输入的源程序，并将其转换为目标程序，或直接输出执行结果（源程序 $\xrightarrow{翻译程序}$ 目标程序或执行结果）

    编译程序（编译器）
    : 把源程序翻译成目标程序

    解释程序（解释器）
    : 直接执行源程序

!!! abstract "阶段划分"
    编译可分为**分析阶段**和**综合阶段**：分析阶段根据源语言定义分析源程序，综合阶段根据分析结果构造目标程序。此外还包括符号表管理与错误处理。

### 分析阶段

词法分析
: 线性分析 & 扫描。词法分析程序进行扫描，对构成源程序的字符串进行分解，识别出每个具有独立意义的单词（lexeme），将其转换成记号（token），并组织成记号流。

    **工作依据：** 构词规则（aka. 词法, 模式）

语法分析
: 层次结构（通常由递归的规则表示）分析。把记号流按语言的语法结构层次地分组，形成语法短语；源程序的语法短语常用分析树表示。

    **工作依据：** 语法规则

语义分析
: 对**语法成份（语法分析确定的层次结构）**的意义进行检查分析，收集必要的信息，包括类型、作用域等。重要任务之一是**类型检查**。

    **工作依据：** 语义规则

### 综合阶段

中间代码生成
: **中间代码**是一种抽象的机器程序，易于产生且易于翻译为目标程序，e.g. 三地址代码

代码优化
: 对代码进行改进：占用空间少、运行速度快。首先在中间代码上进行。

目标代码生成
: 目标代码是**可重定位的机器代码**，一般就是**汇编语言代码**。涉及到两个重要的问题：

    - 对程序中使用的每个变量要指定存储单元
    - 对变量进行寄存器分配

### 符号表管理与错误处理

符号表管理
: 记录源程序使用的标识符，并收集标识符的有关属性

错误处理
: 在编译的每个阶段都可能检测到源程序中存在的错误，需要进行处理和恢复，包括判断错误位置和性质、进行适当的修复

## 编译的有关其他概念

### 前端和后端

!!! abstract "前端与后端的关键区别"
    **前端**与源程序有关、与目标程序无关；**后端**与目标机器有关。通过划分前后端，有利于编译程序的移植和构造。

前端
: 与源程序有关，与目标程序无关

    - 词法分析、语法分析、符号表的建立、语义分析和中间代码生成
    - 与机器无关的代码优化工作
    - 相应的错误处理工作和符号表操作

后端
: 与目标机器有关的部分

    - 目标代码的生成、与机器有关的代码优化
    - 相应的错误处理和符号表操作

### 遍

一遍
: 对源程序或其中间形式从头到尾扫描一遍，并作相关的加工处理，生成新的中间形式或目标程序。

???+ info "遍对编译程序结构的影响"
    编译程序的结构会受到"遍"的安排影响。不同的遍数划分会导致编译程序在内存使用、编译速度和代码优化能力上的差异。

<figure markdown="span">
  ![编译程序的伙伴工具](https://webp-pic.yokumi.cn/2025/09/20250910084017134.png){ loading=lazy width="70%" }

预处理器
: 负责编译前的预处理工作，主要包括：

    - 宏处理
    - 文件包含
    - 语言扩充

汇编程序
: 用助记符表示操作码，用标识符表示存储地址

???+ info "汇编程序的两遍扫描"
    最简单的汇编程序对输入作**两遍**扫描：

    **第一遍**

    - 找出标志存储单元的所有标识符，并将它们写入汇编符号表（独立于编译程序的符号表）中
    - 在符号表中记录该标识符所对应的存储单元地址，此地址是在首次遇到该标识符时确定的

    **第二遍**

    - 把每个用助记符表示的操作码翻译为二进制表示的机器代码
    - 把用标识符表示的存储地址翻译为汇编符号表中该标识符对应的地址
    - 输出**可重定位的机器代码**，同时要对那些需要重定位的指令做出标记

连接装配程序
: 把多个经过编译或汇编的目标模块连接装配成一个完整的可执行程序，包括：

    连接编辑程序
    : 扫描外部符号表，寻找所连接的程序段，根据重定位信息表解决外部引用和重定位，最终将整个程序涉及到的目标模块逐个调入内存并连接在一起，组合成一个待装入的程序

    重定位装配程序
    : 将目标模块的相对地址转换为绝对地址
