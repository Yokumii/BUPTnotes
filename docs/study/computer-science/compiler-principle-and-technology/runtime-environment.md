# 运行环境

## 程序运行时的存储组织

### 过程与活动

**过程**：一个声明语句，分为：

* 过程：无返回值
* 函数：有返回值

**活动**：一个过程的每次执行。

**活动的生存期**：过程体的执行中，第一步和最后一步之间的一系列步骤的执行时间，包括执行 P 所调用过程的时间，以及这些过程所调用的过程的时间。

### 活动记录与控制栈

**活动记录的内容**：

<figure markdown="span">
  ![活动记录内容](https://webp-pic.yokumi.cn/2025/12/20251207205231588.png){ loading=lazy width="70%" }
</figure>

返回值域
: 存放被调用过程的返回值

参数域
: 存放调用过程提供给被调用过程的实参

控制链域
: 指向调用者活动记录，用于返回时恢复调用者环境

访问链域
: 用于访问非局部名：指向"直接外层过程"的最新活动记录

机器状态域
: 寄存器/PSW/断点等

局部数据区
: 存放局部变量

临时数据区
: 存放临时变量

!!! note
    对于允许递归调用的语言，过程块的活动空间不能静态分配，因此通常采用栈式存储分配策略。

**控制栈**：记录活动的生存踪迹及活动的运行环境（当前活着的所有活动的活动记录）。

栈空间的分配和回收：

* 调用过程时，被调用过程的一次新的活动开始，在栈顶为该活动创建一个新的活动记录来保存其环境信息
* 活动结束时，控制从被调用过程返回，释放其活动记录，恢复调用过程的执行环境，使调用过程的活动记录成为栈顶活动记录

## 参数传递机制

### 传值调用

原则
: 先计算出实参的值，然后将其右值传递给被调用过程

特性
: 参数值在被调用过程执行时如同常数；用相应的实参的值替代过程体中出现的所有形参

以 `max(5, 3+4)` 为例，先计算出实参的值，然后将 5 和 7 传递给调用过程并替换过程体中的所有形参，即相当于执行 `5>7?5:7`。

???+ info "传值调用的执行过程"
    1. 调用过程先对实参求值，发生过程调用时，由调用序列把实参的右值写入被调用过程活动记录的参数域中
    2. 被调用过程执行时，对形参的操作在其活动记录的参数域上进行

!!! warning
    传值调用并不意味着参数的使用一定不会影响过程体外变量的值，例如如果参数是指针类型。

### 引用调用

原则
: 原则上要求实参必须是已经分配了存储空间的变量

特性
: 调用过程把**实参存储单元的地址**传递给被调用过程的相应形参（即一个指向实参存储单元的指针）；被调用过程执行时，通过形参间接地引用实参

### 复制恢复

性质
: 传值调用和引用调用的一种混合形式

Copy in
: 过程调用时，调用过程对实参求值，**将实参的右值传递给被调用过程**，写入其活动记录的参数域中，并记录与形参相应的实参的左值

执行过程
: 被调用过程执行时，对形参的操作在自己的活动记录的参数域空间上进行，不修改其引用的左值的值

Copy out
: 控制返回时，被调用过程根据所记录的实参的左值把形参的当前值复制到相应实参的存储空间中。当然，只有具有左值的那些实参的值被复制出来

### 传名调用

原则
: 把过程当作"宏"处理

特性
: 在调用出现的地方，用被调用过程的过程体替换调用语句，并用实参的名字替换相应的形参；这种文字替换称为宏扩展；被调用过程中的局部名字不能与调用过程中的名字重名
