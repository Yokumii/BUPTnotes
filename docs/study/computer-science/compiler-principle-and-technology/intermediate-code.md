### 赋值语句的翻译

```pascal
x := a * b + y
```

假定 x 和 y 的类型为real，a 和 b 的类型为integer，对应三地址代码：

```pascal
t1 := a int* b
t3 := inttoreal t1
t2 := t3 real+ y
x := t2
```

```pascal
x := a + b * y
```

假定 x 和 y 的类型为real，a 和 b 的类型为integer，对应三地址代码：

```pascal
t2 := inttoreal b
t1 := t2 real* y
t4 := inttoreal a
t3 := t4 real+ t1
x := t3
```

### 涉及数组元素的翻译

假设数组空间起始地址为 `base`，每个元素的域宽 `w`，数组下界为 `low`。

对于一维数组，数组元素 `a[i]` 的位置为 `base + (i - low) * w = base + i * w - low * w`，其中 `low * w` 为常数。

对于二维数组 `a[m][n]`，每维的下界为 `low1` 和 `low2`，若按照行优先存放，数组元素 `a[i][j] = base + (i - low1) * w * n + (j - low2) * w = (i * n + j) * w + base - (low1 * n + low2) * w`，其中 `(low1 * n + low2) * w` 为常数。

```pascal
x := A[y, z]
```

其中，`A: array[1..10, 1..20] of integer`。

因此，`A[y, z]` 的位置为 `A + (y - 1) * 4 * 20 + (z - 1) * 4 = A + 80 * y + 4 * z -84`。

对应的三地址代码为：

```pascal
t1 := y * 20
t1 := t1 + z
t2 := A - 84
t3 := 4 * t1
t4 := t2[t3]
x := t4
```

### 记录结构中域的访问

```pascal
x := p.info + A[y][z]
```

其中，`p.info` 对应的三地址代码为：

```pascal
t1 := p[info]
```

### 布尔表达式的翻译

布尔表达式的求值与算术表达式求值类似，以 `a or not b and c` 为例：

```pascal
t1 := not b
t2 := t1 and c
t3 := a or t1
```

关系表达式 `x > y` 等价于

```pascal
if x>y
then 1
else 0
```

对应的三地址代码为：

```pascal
100: if x > y goto 103
101: t := 0
102: goto 104
103: t := 1
104:
```

布尔表达式被翻译为一系列条件转移和无条件转移三地址语句。

**回填技术**：先产生没有填写目标标号的转移指令，建立一个链表，把转向此位置的所有转移指令的标号填入该链表，目标地址确定后，再把目标地址填入该链表中记录的所有指令中。

## 中间代码优化

### 概述

#### 基本块

**基本块**：具有原子性的一组连续语句序列。要求控制从第一条语句（入口语句）流入，从最后一条语句（出口语句）流出，**中途没有停止或分支**。

**划分方法**：

1. 确定入口语句：
    1. 三地址代码的第一条语句
    2. `goto` 语句转移到的目标语句
    3. 紧跟在 `goto` 语句后的语句
2. 确定基本块：
    1. 从一个入口语句（含该语句）到下一个入口语句（不含）之间的语句序列
    2. 从一个入口语句（含该语句）到停止语句（含该语句）之间的语句序列

#### 流图

把控制信息加到基本块集合中，形成程序的有向图，称为流图（控制流图）。

* 结点：基本块
* 首结点：第一条语句开始的基本块
* 边：如果块 B2 紧跟在块 B1 后执行，则 B1 -> B2 有一条有向边

### 基本块优化

#### 1. 常数合并及常数传播

常数合并
: 将在编译时可计算出值的表达式用其值替代；e.g.

```c
x = 2 + 3 + y
->
x = 5 + y
```

常数传播
: 用在编译时已知的变量值代替程序正文中对这些变量的引用；e.g.

```pascal
PI := 3.14
D-to-R := PI/180
->
D-to-R := 0.01744
```

!!! warning
    不能跨越基本块。

???+ info "实现方法"
    通过在符号表加入 2 个信息域 —— 标志域（指示当前变量的值是否存在）和常数域（该变量的当前值）。

    合并时，注意：

    * 浮点表达式不能应用交换律和结合律
    * 不应将任何附加的错误引入

#### 2. 删除公共表达式

在一个基本块中，当第一次对表达式 E 求值之后，如果 E 中的运算对象都没有改变，再次对 E 求值，则除 E 的第一次出现之外，其余的都是冗余的公共表达式。

**方法**：删除冗余的公共表达式，用第一次出现时的求值结果代替之。

#### 3. 复制传播

在复制语句 `f := g` 之后，尽可能用 g 代替 f。即当一个变量只是另一个变量的"拷贝"时，直接用原变量替换它，从而消除多余的变量和赋值语句。

死代码
: 如果对一个变量 x 求值之后却不引用它的值，则称对 x 求值的代码为死代码。

死块
: 控制流不可到达的块称为死块。

??? info "死块的判定"
    * 如果一个基本块是在某一条件为真时进入执行的，经数据流分析的结果知该条件恒为假，则此块是死块
    * 如果一个基本块是在某个条件为假时才进入执行，而该条件却恒为真，则这个块也是死块

    在确定一个基本块是死块之前，需要检查转移到该块的所有转移语句的条件。

    死块的删除，可能使其后继块成为无控制转入的块，这样的块也成为死块，同样应该删除。

#### 4. 削弱计算强度

对基本块的代数变换：对表达式中的求值计算用代数上等价的形式替换，以便使复杂的运算变换成为简单的运算。e.g.

```pascal
x := y ** 2
->
x := y * y

x := x + 0
x := x * 1
-> 没有任何意义，直接删除
```

#### 5. 改变计算次序

```pascal
t1 := b + c
t2 := x + y
```

两语句互不依赖，即 x, y 均不为 t1，b, c 均不为 t2，则交换这两个语句的位置不影响基本块的执行结果。

!!! note
    对基本块中的临时变量重新命名不会改变基本块的执行结果。

### 循环优化

初始化部分
: 对循环控制变量及其他变量赋初值

测试部分
: 测试循环控制变量是否满足循环终止条件

循环体
: 由需要重复执行的语句构成的一个或多个基本块组成

调节部分
: 根据步长对循环控制变量进行调节

#### 1. 循环展开

以空间换时间的优化过程。

* 循环次数在编译时可以确定
* 针对每次循环生成循环体(不包括调节部分和测试部分) 的一个副本

进行循环展开的条件:

* 识别出循环结构，而且编译时可以确定循环控制变量的初值、终值、以及变化步长
* 用空间换时间的权衡结果是可以接受的

!!! note
    在重复产生代码时，必须确保每次重复产生时，都对循环控制变量进行了正确的合并。

#### 2. 代码外提/频度削弱

降低计算频度的优化方法，将循环结构中的循环无关代码提到循环结构的外面 (通常提到循环结构的前面)，从而减少循环中的代码总数。

#### 3. 削弱计算强度

将当前运算类型代之以需要较少执行时间的运算类型的优化方法。大多数计算机上乘法运算比加法运算需要更多的执行时间。如可用 `+` 代替 `*`，则可节省许多时间，特别是当这种替代发生在循环中时更是如此。

#### 4. 删除归纳变量

基本归纳变量
: 如果循环中对变量 i 只有唯一的形如 `i := i + c` 的赋值，并且 c 为循环不变量，则称 i 为循环中的基本归纳变量。

同族归纳变量
: 如果 i 是循环中的一个基本归纳变量，j 在循环中的定值总可以化归为 i 的同一线性函数，即 `j := c1 * i + c2`，这里 c1 和 c2都是循环不变量，则称 j 是归纳变量，并称 j 与 i 同族。
