    回溯法

    基本思想

    问题的解表示为解向量：\(x = (x_0, x_1, \dots, x_{n-1}), \quad x_i \in S_i\)。

    解空间 (Solution space)
    所有可能解向量组成的集合
    解空间树 (Solution space tree)

    用树结构表示解空间：

    • 根节点：空解
    • 每一层：一次决策（一个分量 \(x_i\)）
    • 叶子节点：完整解（可行解或最优解）

    问题类型

    • 求所有解：只要满足约束即可，如 n 皇后所有解、图的 m 着色方案数
    • 求最优解：约束条件 + 目标函数，如 0-1 背包最大价值、TSP 最短路径

    回溯法从根结点出发，按照深度优先搜索（DFS）策略遍历解空间树，搜索满足约束条件的解。搜索过程中通过剪枝策略提早终止某些分支的无效搜索，减少搜索的结点个数但不影响最终结果，从而提高算法的时间性能。

    结点类型

    活结点 (Live node)
    已生成但未扩展完的结点
    扩展结点 (E-node)
    当前正在生成子结点的结点
    死结点 (Dead node)
    子结点全部处理完、需要回溯的结点

    三种剪枝策略

    可行性剪枝 (Feasibility pruning)
    不满足约束条件直接剪掉。如：背包重量超限、皇后冲突
    最优性剪枝 / 限界函数 (Bound pruning)
    当前分支不可能优于已有最优解时剪掉。如 0-1 背包中的分数背包上界
    搜索顺序优化 (Search order optimization)
    调整搜索顺序以尽早触发剪枝。如背包问题按 \(v/w\) 递减排序

    一般步骤

    1. 确定解空间（至少包含一个解或最优解）
    2. 确定结点扩展规则
    3. DFS 搜索解空间 + 尽量剪枝

    两类典型解空间树

    子集树

    • 每个元素只有选 / 不选两种决策
    • 分支数固定（通常为二叉树）
    • 寻找满足某一特定目标的解
    • 最坏情况下，遍历子集树需要 \(O(2^n)\) 的复杂度
    • 适用：0-1 背包问题、n 皇后问题

void backtrack(int i) {
    if (i > n)
        output(x); // 输出解
    else {
        for (j = 下界; j <= 上界; j++) { // j 为 x[i] 所有候选值
            x[i] = j; // 产生一个可能的解分量
            if (constraint(i, j) && bound(i, j)) // 不满足则剪枝
                backtrack(i + 1); // 满足条件，继续下一个分量
            回溯 x[i]
            ...
        }
    }
}

    排列树

    • 当你要找的是 n 个元素的某种排列，并在所有排列中筛选（求所有解 / 求最优解）
    • 第 \(i\) 层决定"第 \(i\) 个位置放哪个元素"，剩下的元素继续排列
    • 通过交换 swap 实现
    • 分支数逐层递减
    • 适用：全排列问题、TSP

    int x[n]; // x 为解向量
void backtrack(int i) {
    if (i > n)
        output(x); // 输出解
    else {
        for (int j = i; j <= n; j++) {
            swap(x[i], x[j]);
            if (constraint && bound)
                backtrack(i + 1);
            swap(x[i], x[j]); // 回溯
        }
    }
}

    解空间共有 \(n + 1\) 层：根节点为第 0 层，叶子节点为第 \(n\) 层；第 1 层有 \(n\) 个节点，对应第一个位置元素的选择，每个节点有 \(n - 1\) 个子节点，以此类推，共有 \(n!\) 个叶子节点，因此时间复杂度为 \(O(n!)\)。

    0-1 背包问题（子集树 + 限界函数）

    原理

    子集树中：

    • 左子树：选第 \(i\) 件物品
    • 右子树：不选第 \(i\) 件物品

    解向量设计

    解向量
    \(x = (x_0, x_1, \dots, x_{n-1}),\quad x_i \in \{0,1\}\)，其中 \(x_i = 1\) 表示选择该物品

    辅助变量： - bestx：记录最优解向量 - bestv：记录最大价值 - cw：当前重量和 - cv：当前价值和

    剪枝函数设计

    左剪枝：容量约束
    在遍历到第 \(i\) 层节点时，决定物品 \(i\) 是否放入取决于 \(cw + w[i] \le W\)，不满足则左孩子（选）直接剪掉
    右剪枝：限界函数
    在遍历到第 \(i\) 层节点时，如果继续拓展能得到的最大价值小于 bestv，则右子树无需继续计算。由于初始时已将物品按 \(v/w\) 排序，只需逐层都选择"装入"直到装不下为止，得到最大价值上界。定义上界函数 \(\text{bound}(cw, cv, i+1)\)，表示不选择 \(x_i\)（即 \(x_i = 0\)）时继续走下去能达到的最大价值。

    算法步骤

    1. 先按 \(v/w\) 递减排序
    2. 从第 0 件物品开始 DFS
    3. 先尝试选择（若不超容量）
    4. 再计算 bound 决定是否"不选"
    5. 到叶子结点更新最优解
    6. 回溯继续搜索

    最坏时间复杂度：\(O(2^n)\)，即生成并走完树的每一个节点。

    struct Goods {
    int no;
    int w;
    int v;

    Goods(int no1, int w1, int v1) {
        no = no1; w = w1; v = v1;
    }

    bool operator<(const Goods& s) const { // 按 v/w 递减排序
        return (double)v / w > (double)s.v / s.w;
    }
};

double bound(int cw, int cv, int i) {
    int rw = W - cw;
    double b = cv;
    int j = i;
    while (j < n && g[j].w <= rw) {
        rw -= g[j].w;
        b += g[j].v;
        j++;
    }
    if (j < n) { // 部分装入最后一个物品
        b += (double)g[j].v / g[j].w * rw;
    }
    return b;
}

void dfs(int cw, int cv, vector<int>& x, int i) {
    if (i >= n) { // 叶子节点
        if (cw <= W && cv > bestv) { // 找到更优解
            bestv = cv;
            bestx = x;
        }
    } else {
        if (cw + g[i].w <= W) { // 左剪枝：容量约束
            x[i] = 1; // 选择
            dfs(cw + g[i].w, cv + g[i].v, x, i + 1);
        }
        double b = bound(cw, cv, i + 1);
        if (b > bestv) { // 右剪枝：限界函数
            x[i] = 0; // 不选择
            dfs(cw, cv, x, i + 1);
        }
    }
}

    解题示例

    已知有 \(n = 4\) 件物品，背包容量 \(W = 10\)。重量和价值如下表：

    物品编号 \(i\) 重量 \(w[i]\) 价值 \(v[i]\)
    0 2 6
    1 2 3
    2 6 5
    3 5 4
    （1）说明基本原理，指出解空间树类型

    把 0-1 背包表示为一个决策序列：对第 \(i\) 件物品只有两种选择——装入或不装入。回溯法用 DFS 在解空间中枚举所有可能的 0/1 组合；在搜索过程中利用剪枝：

    • 可行性剪枝：一旦当前重量超出容量，当前结点及其子树不可能产生可行解，直接回退
    • 最优性剪枝（限界）：计算当前结点"继续往下最多还能达到的价值上界"，若上界都不可能超过当前最优解，则剪掉该子树

    解空间树为子集树，每层对应一个物品，左/右分支代表"选/不选"。

    （2）给出解向量设计，说明每个分量的含义

    解向量：\(\mathbf{x} = (x_0, x_1, x_2, x_3),\quad x_i \in \{0, 1\}\)

    • \(x_i = 1\)：第 \(i\) 件物品装入背包
    • \(x_i = 0\)：第 \(i\) 件物品不装入背包
    （3）设计剪枝函数，包括可行性剪枝和最优性剪枝
    • 可行性剪枝（容量约束）：直接排除所有超重的分支，减少搜索
    • 最优性剪枝：常用"分数背包上界"（允许把剩余物品按单位价值贪心"分装"来估计上界），大量砍掉"再怎么选也不可能超过当前最优"的子树
    （4）画出解空间树搜索与剪枝过程示意图

    （5）给出时间复杂度

    最坏情况时间复杂度：\(O(2^n)\)

    理由：解空间树是二叉树，最坏情况下剪枝不起作用，需要枚举全部 \(2^n\) 个 0/1 组合（每层做常数级判断与上界计算可视为常数或 \(O(n)\)，但主导项仍是指数级）。

    n 皇后问题（子集树）

    原理

    问题描述：在 \(n \times n\;(n \ge 4)\) 的方格棋盘上放置 \(n\) 个皇后，并且每个皇后不同行、不同列、不同左右对角线（否则称为有冲突）。要求给出 \(n\) 个皇后的全部解。

    解向量设计

    由于前提已经要求皇后不同行，假设第 \(1 \sim n\) 个皇后分别放在第 \(1 \sim n\) 行，并且由于不同列，设皇后 \(i\) 对应的列号为 \(x_i\)。因此解向量即为 \(x = (x_1, x_2, \dots, x_n)\)，满足约束条件（不处于对角线），分量取值为 \(1 \le x_i \le n\)。

    冲突判断（可行性剪枝）

    冲突条件：

    C
    1
    (j == q[k]) || (abs(i - k) == abs(j - q[k]))

    其中 \(k = 1 \sim i - 1\)，即与前 \(i - 1\) 个已放好的皇后分别进行判断。这里判断冲突过程就相当于可行性剪枝。

    算法步骤

    1. 从第 1 行开始尝试放皇后
    2. 在当前行依次尝试所有列
    3. 若与前面皇后不冲突，则放置
    4. 递归处理下一行
    5. 若无合法列，回溯到上一行
    6. 放满 \(n\) 行，得到一个解

    时间复杂度：最坏情况下每个节点都尝试 \(n\) 种子节点，即 \(O(n^n)\)；经过可行性剪枝（同列方案舍去），时间复杂度为 \(O(n!)\)。

    bool place(int i, int j) {   // 测试 (i, j) 位置能否放置皇后
    if (i == 1)
        return true;  // 第一个皇后总是可以放置

    int k = 1;
    while (k < i) { // k = 1~i-1 是已放置了皇后的行
        if ((q[k] == j) || (abs(q[k] - j) == abs(i - k)))
            return false;
        k++;
    }
    return true;
}

int q[MAXN];  // 存放各皇后所在的列号
int cnt = 0;  // 累计解个数

void queen11(int n, int i) {  // 回溯算法
    if (i > n)
        disp(n);  // 所有皇后放置结束
    else {
        for (int j = 1; j <= n; j++) { // 在第 i 行上试探每一个列 j
            if (place(i, j)) { // 在第 i 行上找到合适位置 (i, j)
                q[i] = j;
                queen11(n, i + 1);
                q[i] = 0;  // 回溯
            }
        }
    }
}

void queen1(int n) { // 递归法求解 n 皇后问题
    queen11(n, 1);
}

    解题示例

    取 \(n = 4\)，求解 4 皇后问题。

    （1）说明为什么适合回溯法，指出解空间树类型

    4 皇后问题可看成一串决策：第 1 行皇后放哪一列、第 2 行放哪一列……直到第 4 行。回溯法按 DFS 在解空间树中搜索，当某一步选择导致冲突时立即剪枝并回溯到最近的活结点继续试探。

    逐行放置，每一行有 \(1 \sim n\) 个列可选，因此解空间树是子集树。

    （2）设计解向量，说明分量含义

    \(q[i]\) = 第 \(i\) 行皇后所在的列号（\(1 \le q[i] \le n\)）

    因为每行恰好一个皇后，所以一个完整解可写成：\((q[1], q[2], q[3], q[4])\)

    （3）给出剪枝函数设计

    属于可行性剪枝（不满足约束的分支直接剪掉）。若在第 \(i\) 行第 \(j\) 列放皇后，检查与已放置的前 \(i - 1\) 个皇后 \((k, q[k])\) 是否冲突：

    冲突当且仅当存在 \(k\;(1 \le k \le i - 1)\) 使得：

    • 同列冲突：\(q[k] = j\)
    • 同对角线冲突：\(|q[k] - j| = |i - k|\)

    合法条件：对所有 \(k = 1 \sim i - 1\)，上述两条都不成立。

    （4）画出 4 皇后回溯搜索与剪枝过程示意图

    （5）给出时间复杂度

    n 皇后回溯法最坏情况下每一行最多尝试 \(n\) 个位置，共 \(n\) 行，最坏时间复杂度为 \(O(n^n)\)；若按照列唯一性作为生成规则，则为 \(O(n!)\)。

    旅行商问题 TSP（排列树）

    原理

    问题描述：假设有一个货郎担要拜访 \(n\) 个城市，记为 \(1 \sim n\)，他必须选择所要走的路径，路径的限制是每个城市只能拜访一次，而且最后要回到原来出发的城市，要求路径长度最短的路径。

    用邻接矩阵 \(A\) 存储带权图，并以编号为 1 的城市为起点，记为 \(x_0\)，原问题的解可以描述为 \(1, x_1, x_2, \dots, x_{n-1}, 1\)，事实上就是求 \(n - 1\) 个数的全排列，因此对应回溯法的排列树，解空间大小为 \((n - 1)!\)。

    解向量设计

    解向量
    \(x = (x_0, x_1, \dots, x_{n-1})\)，其中 \(x_0\) 为起点，也是终点
    优化目标
    \(\min\left(\sum_{i=1}^{n-1} A[x[i-1]][x[i]] + A[x[n-1]][0]\right)\)

    对于解空间树，第 0 层为起点 \(x_0\)，第 \(i\) 层为对第 \(i\) 个目的地的选择，解的分量表示目的地编号。当搜索达到叶子节点时，需加上回到起点的距离。

    剪枝函数设计

    可行性剪枝
    即当前位置和目的地是否连通。例如如果 \(A[x[i-1]][x[i]] = +\infty\)，则剪枝
    最优性剪枝
    由于需要寻找路程最短的 bestd，如果此时要决策 \(x[i]\) 的取值，若 \(d + A[x[i-1]][x[i]] \ge \text{bestd}\)，则直接剪枝

    时间复杂度

    解空间是一棵排列树，从第 1 层开始搜索，树的高度为 \(n\)，最坏时间复杂度为 \(O((n - 1)!)\)。

    解题示例

    已知 \(n = 4\) 个城市的带权完全图，城市编号 \(\{0, 1, 2, 3\}\)，路程如下表：

    0 1 2 3
    0 0 8 5 9
    1 8 0 6 7
    2 5 6 0 4
    3 9 7 4 0

    旅行商从城市 0 出发，要求恰好访问每个城市一次并最终返回城市 0，使得总路径长度最短。

    （1）说明为什么适合回溯法，指出解空间树类型

    TSP 要在"访问每个城市一次并回到起点"的所有可能路径中找最短回路。把"访问顺序"看成一个排列，使用回溯法（DFS）在解空间树中搜索，并在搜索过程中用"当前路径长度与当前最优长度 bestd"进行剪枝。

    由于要枚举除起点外其余城市的所有排列，解空间是一棵排列树。

    （2）设计解向量，说明分量含义

    \(x = (x_0, x_1, x_2, x_3)\)，其中固定 \(x_0 = s = 0\)，而 \(x_1, x_2, x_3\) 为其余城市 \(\{1, 2, 3\}\) 的一个排列。

    （3）说明剪枝策略

    在第 \(i\) 层试探把 \(x_i\) 取为某个候选城市 \(x_j\)（通过 swap 实现）时，若边存在，则新长度为 \(d' = d + A[x_{i-1}][x_j]\)，仅当 \(d' < \text{bestd}\) 才继续向下扩展；否则剪去该分支。

    （4）画出解空间树搜索与剪枝过程示意图

    （5）给出时间复杂度

    TSP 的解空间是排列树，固定起点后需要枚举其余 \(n - 1\) 个城市的排列，树的高度为 \(n\)，最坏时间复杂度：\(O((n - 1)!)\)。

    图的 m 着色问题（子集树）

    原理

    问题描述：给定无向连通图 \(G\) 和 \(m\) 种不同的颜色。用这些颜色为图 \(G\) 的各顶点着色，每个顶点着一种颜色。如果有一种着色法使 \(G\) 中每条边的两个顶点着不同颜色，则称这个图是 m 可着色的。图的 m 着色问题是对于给定图 \(G\) 和 \(m\) 种颜色，找出所有不同的着色法。

    解向量设计

    含 \(n\) 个顶点的无向连通图 \(G\)，顶点编号 \(0 \sim n - 1\)。采用 vector<int> 数组的邻接表 \(A\) 存储，其中 A[i] 向量为顶点 \(i\) 的所有相邻顶点。

    \(m\) 种颜色编号为 \(0 \sim m - 1\)，每层解的分量有 \(m\) 种取值，需要满足约束条件（相邻节点颜色不同），解空间为子集树（m 叉）。

    解向量
    \(x = (x_0, x_1, \dots, x_{n-1})\)，\(x_i\) 表示顶点 \(i\) 的着色，\(0 \le x_j \le m - 1\)，初始均为 \(-1\)

    目标：累计解个数 cnt

    剪枝函数设计

    可行性剪枝
    两个相邻节点不能同色。如果 \(x[i] = j\)，并且 \(\forall v \in A[i],\; x[v] \ne j\)，则可行，否则剪枝

bool judge(int i, int j) {  // 判断顶点 i 是否可以着颜色 j
    for (int k = 0; k < A[i].size(); k++) {

    void dfs(int m, int i) {
    if (i >= n) {
        cnt++;  // 满足约束的已被剪掉，直接计数
    } else {
        for (int j = 0; j < m; j++) {
            x[i] = j;
            if (judge(i, j))
                dfs(m, i + 1);
            x[i] = -1;
        }
    }
}

    时间复杂度

    子集树是 m 叉树，共有 \(n\) 个顶点，对应 \(n + 1\) 层，因此时间复杂度为 \(O(m^n)\)。实际实现中还需检查是否可以扩展子结点（检查所有邻居），也有说法为 \(O(nm^n)\)。

    解题示例

    给定无向连通图 \(G = (V, E)\)，其中 \(V = \{0, 1, 2, 3\}\)，\(E = \{(0,1),(0,2),(0,3),(1,2),(2,3)\}\)，\(m = 3\) 种颜色编号 \(\{0, 1, 2\}\)。要求任意一条边的两个端点颜色不同。

    （1）说明为什么适合回溯法，指出解空间树类型

    对每个顶点依次选择一种颜色（\(0 \sim m - 1\)），形成解向量 \(x = (x_0, x_1, x_2, x_3)\)。用回溯法按 DFS 搜索所有可能着色，若某顶点选的颜色与已着色的相邻顶点冲突，则该分支不可能产生合法解，立即剪枝并回溯。

    每个顶点有 \(m\) 种颜色可选，因此解空间树为 m 叉子集树。

    （2）设计解向量，说明分量含义

    \(x = (x_0, x_1, x_2, x_3),\quad 0 \le x_i \le m - 1\)

    • \(x_i\)：顶点 \(i\) 的颜色编号
    • 初始化：所有 \(x_i = -1\)（表示未着色）
    • cnt：合法着色方案计数（初值 0）
    （3）给出剪枝函数设计

    若给顶点 \(i\) 染颜色 \(j\)，需要满足：对所有邻接点 \(v \in A[i]\)，\(x_v \ne j\)。

    属于可行性剪枝（不满足约束条件就剪去该分支），避免继续扩展必然冲突的着色，减少搜索结点数，但不影响最终计数结果。

    （4）给出全部合法着色方案

    \(\text{cnt} = 6\)：

    1. \((0, 2, 1, 2)\)
    2. \((0, 1, 2, 1)\)
    3. \((1, 2, 0, 2)\)
    4. \((1, 0, 2, 0)\)
    5. \((2, 1, 0, 1)\)
    6. \((2, 0, 1, 0)\)
    （5）给出时间复杂度

    每个顶点最多试探 \(m\) 种颜色，共 \(n\) 个顶点，对应 m 叉子集树，最坏时间复杂度：\(O(m^n)\)。如果考虑到检查邻居点，对于稠密图最坏为 \(O(nm^n)\)。
