    动态规划

    动态规划是一种用于解决多阶段决策过程最优化问题的方法，各阶段的决策只与当前状态有关，与到达该状态的具体路径无关。

    核心思想

    原问题的最优解包含其子问题的最优解（最优子结构性质），即原问题可以由子问题的最优解组合而成，这就使得问题可以拆分成若干个子问题。与分治法的区别在于，分治法的子问题会大量重复计算，而动态规划用"表"把每个子问题只算一次。

    基本步骤

    1. 刻画最优解结构（定义子问题/状态）
    2. 递归定义最优值（推导递推/状态方程）
    3. 自底向上计算最优值（说明填表顺序）
    4. 根据表中信息构造最优解（若要求输出方案）

    最优子结构性质

    最优子结构性质是动态规划适用问题的基础。其含义为：原问题的最优解包含其子问题的最优解。

    每个具体问题都需要单独证明其具有最优子结构性质，通用证法为反证法：

    1. 假设原问题的最优解所包含的某个子问题的解不是最优的；
    2. 则存在该子问题的更优解 \(Z'\)；
    3. 将 \(Z'\) 替换原最优解中的子问题解，得到的新解优于原最优解；
    4. 与"原问题的解是最优解"矛盾，故子问题的解一定也是最优的。

    矩阵连乘

    问题描述

    给定矩阵链 \(A_1A_2\cdots A_n\)，选择加括号方式使数乘次数最少。

    完全加括号的矩阵连乘积定义：

    单个矩阵 \(A_i\) 是完全加括号的；矩阵连乘积 \(A\) 是完全加括号的 \(\Leftrightarrow\) \(A=(BC)\)，其中 \(B\)、\(C\) 均为完全加括号的矩阵连乘积。

    对于 \(A_i\cdots A_j\)，假设在 \(A_k\) 和 \(A_{k+1}\) 之间断开，即 \((A_i\cdots A_k)(A_{k+1}\cdots A_j)\)，原问题的数乘次数可分解为两个子问题的数乘次数加上两者相乘的计算量。

    最优子结构性质证明
    1. 采用反证法，假设 \(A[i:j]\) 的最优计算次序所包含的子链 \(A[i:k]\) 和 \(A[k+1:j]\) 中，\(A[i:k]\) 不是 \(A_i\cdots A_k\) 的最优计算次序；
    2. 即存在一个最优计算次序 \(A'[i:k]\) 优于 \(A[i:k]\)；
    3. 那么替换 \(A[i:k]\)，使用 \((A'[i:k])(A[k+1:j])\) 得到的计算次数一定少于原问题的最优计算次序，这与 \(A[i:j]\) 是最优计算次序矛盾；

    因此，\(A[i:k]\) 一定是最优子结构。

    状态方程与递推式

    设 \(m[i][j]\) 表示 \(A[i:j]\) 所需的最少数乘次数，则原问题最优值为 \(m[1][n]\)。

    边界条件：当 \(i=j\) 时，\(m[i][j]=0\)，即 \(m[i][i]=0\)。

    转移方程：当 \(i<j\) 时，

    \[m[i][j]=\min_{i\le k<j}\Big(m[i][k]+m[k+1][j]+p_{i-1}p_kp_j\Big)\]

    其中 \(k\) 的位置有 \(i\) 到 \(j-1\)，共 \(j-i\) 种可能。

    填表步骤

    按"链长"从小到大填：

    1. 先填长度 1（对角线）：\(m[i][i]=0\)
    2. 再填长度 2、3、...、\(n\)，每个格 \(m[i][j]\) 需枚举 \(k\in[i,j-1]\)

    void MatrixChain(int *p, int n, int **m, int **s) {
    for (int i = 1; i <= n; i++)
        m[i][i] = 0;
    for (int r = 2; r <= n; r++) {
        for (int i = 1; i <= n-r+1; i++) {
            int j = i+r-1;
            m[i][j] = m[i+1][j] + p[i-1]*p[i]*p[j];
            s[i][j] = i;
            for (int k = i+1; k < j; k++) {
                int t = m[i][k] + m[k+1][j] + p[i-1]*p[k]*p[j];
                if (t < m[i][j]) {
                    m[i][j] = t;
                    s[i][j] = k;
                }
            }
        }
    }
}

    其中 \(s[i][j]\) 即为 \(A[i:j]\) 对应的最优分割方案 \(A[i:k]\) 和 \(A[k+1:j]\)。

    反推最优解

    对于 \(A[1][n]\)，先找到 \(s[1][n]=k\)，然后给 \(A_1\cdots A_k\) 和 \(A_{k+1}\cdots A_n\) 加括号，得到 \((A_1\cdots A_k)(A_{k+1}\cdots A_n)\)，再找到两个子问题的分割方案，直到长度为 1。

    时间复杂度

    三重循环（链长 \(r\)、起点 \(i\)、分割点 \(k\)），时间复杂度为 \(O(n^3)\)；状态表大小 \(n^2\)，空间复杂度为 \(O(n^2)\)。

    解题示例

    以 \(A_1=10\times100,\;A_2=100\times5,\;A_3=5\times50,\;A_4=50\times30\) 为例，维数 \(p=[10,100,5,50,30]\)。

    m 表：

    i\j 1 2 3 4
    1 0 5000 7500 14000
    2 — 0 25000 22500
    3 — — 0 7500
    4 — — — 0

    s 表：

    i\j 1 2 3 4
    1 — 1 2 2
    2 — — 2 2
    3 — — — 3
    4 — — — —

    最优括号化：\((A_1A_2)(A_3A_4)\)，对应 \(m[1,4]=14000,\;s[1,4]=2\)。

    最长公共子序列（LCS）

    问题描述

    给定序列 \(X=\{x_1,\dots,x_m\},\;Y=\{y_1,\dots,y_n\}\)，求最长公共子序列的长度（不要求连续）。

    注意

    注意题目是求长度还是求满足的最长公共子序列（可能有多个，都要写出）。

    最优子结构性质证明

    设两者的最长公共子序列为 \(Z=\{z_1,\cdots,z_k\}\)，有以下几种可能结构：

    1. \(x_m=y_n\)，则 \(z_k=x_m=y_n\)，且 \(Z_{k-1}\) 是 \(X_{m-1}\) 和 \(Y_{n-1}\) 的最长公共子序列；
    2. \(x_m\ne y_n\) 且 \(x_m\ne z_k\)，则 \(Z\) 是 \(X_{m-1}\) 和 \(Y\) 的最长公共子序列；
    3. \(x_m\ne y_n\) 且 \(y_n\ne z_k\)，则 \(Z\) 是 \(X\) 和 \(Y_{n-1}\) 的最长公共子序列。

    亦可按反证法严格证明：设 \(z_k\) 分别位于 \(x_i\) 和 \(y_j\) 处，假设 \(Z\) 不是 \(X_i\) 和 \(Y_j\) 的最长公共子序列；则存在 \(X_i\) 和 \(Y_j\) 的更长的公共子序列 \(Z'\)，它同时也是 \(X\) 和 \(Y\) 的公共子序列，与 \(Z\) 是最长公共子序列矛盾。

    状态方程与递推式

    设 \(c[i][j]\) 为 \(X[1:i]\) 和 \(Y[1:j]\) 的最长公共子序列长度。

    边界条件：\(c[i][0]=0,\;c[0][j]=0\)。

    递推式：

    \[c[i][j]=\begin{cases}c[i-1][j-1]+1 & x_i=y_j \\ \max(c[i-1][j],\;c[i][j-1]) & x_i\ne y_j\end{cases}\]

    填表步骤

    双重循环自底向上：从 \(i=1..m,\;j=1..n\) 逐格填；每格只依赖左、上、左上三个格。

    时间复杂度

    子问题数 \(\Theta(mn)\)，每格 \(O(1)\)，时间复杂度为 \(O(mn)\)；空间复杂度为 \(O(mn)\)（若只求长度，可压缩到 2 行甚至 \(O(\min(m,n))\)）。

    解题示例

    以 \(X=ABCBDAB\)（\(m=7\)）和 \(Y=BDCABA\)（\(n=6\)）为例：

    最大子段和（Kadane 算法）

    问题描述

    给定数组 \(a[0..n-1]\)，求连续子数组和的最大值。

    最优子结构性质证明

    令 \(b[j]\) 表示"以 \(j\) 结尾"的最大子段和，则最优结构为：要么把 \(a[j]\) 接到"以 \(j-1\) 结尾的最优子段"后面（如果那段是正贡献），要么从 \(a[j]\) 重新开始。

    对于数组 \(a[1:j]\)，其最优子段只能为 \(a[i:j]\) 或 \(a[i:k]\)（\(i\le k<j\)）：

    • 若为 \(a[i:j]\)：
      • \(i=j\) 时，最大子段和即为 \(a[j]\), 前面 \(a[1:j-1]\) 的最大子段和 < 0（全是负数），子问题最优子段为空集；
      • \(i<j\) 时，\(b[j-1]>0,\;b[j]=b[j-1]+a[j]\)。需证明 \(a[i:j-1]\) 同样是 \(a[1:j-1]\) 的最优子段。反证法：假设存在更优子段 \(B\)，由于 \(b[j-1]>0\)，将其与 \(a[j]\) 相加得到的子段和大于原最优子段和，矛盾；
    • 若为 \(a[i:k]\)：说明 \(a[k+1]<0\)，且 \(a[k+1:j]\) 部分的最优子段和 < \(a[i:k]\) 段之和。反证法：假设 \(a[i:k]\) 不是子问题最优子段，则存在更优子段 \(B\)，它也是 \(a[1:j]\) 上的最优子段，与 \(a[i:k]\) 是原问题最优子段矛盾。

    状态方程与递推式

    边界条件：\(b[0]=\max(0,\;a[0])\)。

    递推式：

    \[b[j]=\max(b[j-1]+a[j],\;a[j]),\quad j\ge 1\]

    填表步骤

    从左到右一次扫描，逐个算 \(b[j]\)，同时维护全局最大值 \(\max_j b[j]\) 即为最终答案。若需求最优解的具体结构，倒着找即可。

    时间复杂度

    只一层循环，时间复杂度为 \(O(n)\)；空间复杂度一般为 \(O(n)\)，用常数变量替代数组可优化为 \(O(1)\)。

    解题示例

    以数组 \((-2,\;11,\;-4,\;13,\;-5,\;-2)\) 为例：

    正向扫描：

    • 初始化：\(b=0,\;\max=0\)
    • \(j=0\)：\(b=a[0]=-2,\;\max=0\)
    • \(j=1\)：\(b=\max(-2+11,\;11)=11,\;\max=11\)
    • \(j=2\)：\(b=\max(11-4,\;-4)=7,\;\max=11\)
    • \(j=3\)：\(b=\max(7+13,\;13)=20,\;\max=20\)
    • \(j=4\)：\(b=\max(20-5,\;-5)=15,\;\max=20\)
    • \(j=5\)：\(b=\max(15-2,\;-2)=13,\;\max=20\)

    逆向求最优子段：

    • 初始化：\(B=E=5,\;b=\max=a[5]=-2\)
    • \(j=4\)：\(b<0\;\rightarrow\;b=a[4]=-5\)
    • \(j=3\)：\(b<0\;\rightarrow\;b=a[3]=13>0\;\rightarrow\;\max=13,\;B=E=3\)
    • \(j=2\)：\(b>0\;\rightarrow\;b+=a[2]=9<13\)
    • \(j=1\)：\(b>0\;\rightarrow\;b+=a[1]=20>13\;\rightarrow\;\max=20,\;B=1,\;E=3\)
    • \(j=0\)：\(b>0\;\rightarrow\;b+=a[0]=18<20\)

    一个最优子段为 \((11,\;-4,\;13)\)。

    0-1 背包问题

    问题描述

    给定 \(n\) 种物品和 1 个背包，物品 \(i\) 的重量为 \(w_i\)，价值为 \(v_i\)，背包容量为 \(C\)。在选择物品装入背包时，只能全部装入或不装入，求装入背包中物品的总价值最大。

    最优子结构性质证明

    假设 \((y_1,y_2,\cdots,y_n)\) 是原问题的一个最优解，若满足最优子结构性质，则 \((y_2,y_3,\cdots,y_n)\) 是以下子问题的最优解：

    \[\max\sum_{i=2}^n v_i y_i\]
    约束条件：

    \(\sum_{i=2}^n w_i y_i \le C - w_1 y_1\)；\(y_i\in\{0,1\},\;i=2,3,\dots\)

    反证法：假设 \((y_2,y_3,\cdots,y_n)\) 不是子问题的最优解，即存在 \((z_2,z_3,\cdots,z_n)\) 使得 \(\sum_{i=2}^n v_i z_i > \sum_{i=2}^n v_i y_i\)。将其与 \(y_1\) 拼装为 \((y_1,z_2,z_3,\cdots,z_n)\)，显然 \(w_1y_1 + \sum_{i=2}^n w_i z_i \le C\)，且 \(v_1y_1 + \sum_{i=2}^n v_i z_i > \sum_{i=1}^n v_i y_i\)，与 \((y_1,y_2,\cdots,y_n)\) 是原问题的最优解矛盾！

    状态方程与递推式

    状态定义：\(dp[i][j]\) 表示在前 \(i\) 个物品中选择，背包容量为 \(j\) 时所能获得的最大价值。

    边界条件：\(dp[0][j]=0,\;dp[i][0]=0\)。

    递推式：

    \[dp[i][j]=\begin{cases}dp[i-1][j] & w_i>j \\ \max(dp[i-1][j],\;dp[i-1][j-w_i]+v_i) & w_i\le j\end{cases}\]

    解向量回溯

    由 \(dp[n][C]\) 回溯求出解向量：

    • 若 \(dp[i][C]=dp[i-1][C]\)：最优解未选物品 \(i-1\)，移动到 \(dp[i-1][C]\)；
    • 若 \(dp[i][C]\ne dp[i-1][C]\)：最优解选了物品 \(i-1\)，移动到 \(dp[i-1][C-w_{i-1}]\)。

    def knapsack(weights, values, capacity):
    n = len(weights)
    if n == 0 or capacity == 0:
        return 0

    # 初始化 DP 表
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]

    # 填充 DP 表
    for i in range(1, n + 1):
        w = weights[i-1]  # 当前物品重量
        v = values[i-1]   # 当前物品价值

        for j in range(1, capacity + 1):
            if w > j:
                dp[i][j] = dp[i-1][j]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-w] + v)

    # 回溯求出解向量
    x = []
    w_idx, c_idx = n, capacity
    while w_idx > 0 and c_idx > 0:
        if dp[w_idx][c_idx] != dp[w_idx-1][c_idx]:
            item_index = w_idx - 1
            x.append(item_index)
            c_idx -= weights[item_index]
        w_idx -= 1

    return dp[n][capacity], x

    时间复杂度

    时间复杂度为 \(O(nC)\)；\(dp\) 数组大小为 \((n+1)\times(C+1)\)，空间复杂度为 \(O(n\cdot C)\)。

    空间优化：滚动数组

    计算 \(dp[i][j]\) 时只需 \(dp[i-1]\) 这一行数据（\(dp[i-1][j]\) 和 \(dp[i-1][j-w_{i-1}]\)），因此可将二维数组压缩为一维数组 \(dp[j]\)。

    更新时需从后往前遍历（\(j\) 从 \(C\) 到 \(w_i\)），因为计算 \(dp[j]\) 时需要用到 \(dp[j-w_{i-1}]\)，若顺序遍历则 \(dp[j-w_{i-1}]\) 已被更新，含义变为"前 \(i\) 个物品"，导致一个物品被多次放入。

    def knapsack_optimized(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)

    for i in range(n):
        w = weights[i]
        v = values[i]

        # 逆序遍历
        for j in range(capacity, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)

    return dp[capacity]

    空间复杂度优化为 \(O(C)\)。

    从 \(dp[5][10]=15\) 回溯：

    1. \(b[5][10]=↖\) → 选第 5 件（重量 4，价值 6）
    2. 剩余容量 \(10-4=6\)
    3. \(b[4][6]=↑\) → 不选第 4 件
    4. \(b[3][6]=↑\) → 不选第 3 件
    5. \(b[2][6]=↖\) → 选第 2 件（重量 2，价值 3）
    6. 剩余容量 \(6-2=4\)
    7. \(b[1][4]=↖\) → 选第 1 件（重量 2，价值 6）

    最大价值：15；对应物品：第 1、2、5 件。

    拓展：其他背包问题

    完全背包问题

    有 \(n\) 种重量和价值分别为 \(w_i,v_i\) 的物品，从这些物品中挑选总重量不超过 \(W\) 的物品，每种物品可以挑选任意多件，求最大价值。

    递推式变为对 \(k\) 的枚举：

    \[dp[i][j]=\max_{k\cdot w_{i-1}\le j}\{dp[i-1][j-k\cdot w_{i-1}]+k\cdot v_{i-1}\}\]

    其中 \(fk[i][j]=k\) 表示物品 \(i-1\) 选取的件数。

    优化思路

    对 \(k\) 的循环遍历完全可以看作有 \(k\) 件重量和价值相同但不同种类的物品，问题转变为 0-1 背包问题，不过物品数 \(n\) 增加了。包含三重循环，最坏情况下时间复杂度为 \(O(nW^2)\)。

    若用一维滚动数组且顺序遍历（而非逆序），即可在 \(O(nW)\) 时间内解决完全背包问题——顺序遍历使得 \(dp[j-w_i]\) 已被更新为"前 \(i\) 个物品"的值，恰好允许同一物品多次选取。

    def complete_knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]

    for i in range(1, n + 1):
        w = weights[i-1]
        v = values[i-1]

        for j in range(1, capacity + 1):
            k = 0
            while k * w <= j:
                if dp[i][j] < dp[i-1][j-k*w] + k*v:
                    dp[i][j] = dp[i-1][j-k*w] + k*v
                k += 1

    return dp[n][capacity]

    多重背包问题

    有 \(n\) 种重量和价值分别为 \(w_i,v_i\) 的物品，物品 \(i\) 有 \(s_i\) 件，从这些物品中挑选总重量不超过 \(W\) 的物品，每种物品可以挑选多件但不能超过 \(s_i\) 件，求最大价值。

    与完全背包类似，但 \(k\) 在遍历时不仅不能超重，也不能超出 \(s_i\)：

    \[dp[i][j]=\max_{0\le k\le s_{i-1},\;k\cdot w_{i-1}\le j}\{dp[i-1][j-k\cdot w_{i-1}]+k\cdot v_{i-1}\}\]
