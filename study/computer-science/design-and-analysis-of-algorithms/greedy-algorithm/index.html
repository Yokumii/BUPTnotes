    贪心法

    基本思想

    贪心法在解决问题时，不从整体最优上加以考虑，而是每一步都做出在当前看来是最好的选择。

    • 它做出的仅是某种意义上的局部最优解。
    • 关键点：这种局部最优解必须能保证最终导致全局最优解，算法才算正确（需要证明）。

    贪心法能够求得全局最优解，依赖两个重要性质：

    1. 最优子结构性质：问题的最优解包含了其子问题的最优解。
    2. 贪心选择性质：整体最优解可以通过一系列局部最优选择（贪心选择）来得到。

    贪心选择性质的证明方法

    一般按照数学归纳法进行证明：首先证明第 1 步贪心选择"安全"，假设前 \(k\) 步正确，推出第 \(k+1\) 步也必须按贪心选，否则会导致更差（矛盾）。

    证明第 1 步贪心选择"安全"事实上也是证明最优子结构性质的第一步，可用交换法证明。

    贪心法的基本框架

    贪心算法的每一步操作包含三个环节：

    • Select：从候选集合中选取当前最优选择
    • Feasible：判断该选择是否满足可行性约束
    • Union：将可行选择合并进解

    SolutionType Greedy(SType a[], int n)
{
    SolutionType x = {};      // 解向量
    for (int i = 0; i < n; i++) {
        SType xi = Select(a); // 当前最优选择

            x = Union(xi);    // 合并进解
    }
    return x;
}

    活动安排问题

    问题描述

    假设有 \(n\) 个活动 \(S=(1, 2, \cdots, n)\)，有一个资源，每个活动执行时都要占用该资源，并且该资源任何时刻只能被一个活动所占用，一旦某个活动开始执行，中间不能被打断，直到其执行完毕。每个活动 \(i\) 有一个开始时间 \(b\) 和结束时间 \(e(b < e)\)，它是一个半开时间区间 \([b, e)\)，假设最早活动执行时间为 0。

    求一种最优活动安排方案，使得安排的活动个数最多。

    贪心策略

    对于上图的活动 \(i\) 和 \(j\)，如果它们不重叠，则称其为兼容活动。问题等价于在 \(n\) 个活动中选择最多的兼容活动，即求最多兼容活动的个数。

    贪心法的直觉是：要在有限的时间里塞进尽可能多的活动，在选择第一个活动时，应该选择结束时间最早的活动。最早结束的活动给后面留下最大空余时间，使"剩余可选活动数"尽可能多。

    贪心策略：按结束时间 \(e_i\) 递增排序，然后从前往后依次选择与已选集合兼容（开始时间 \(\ge\) 上一个结束时间）的活动。

    贪心选择性质证明（交换法 + 反证法）
    1. 首先，假设存在一个最优解；
    2. 需要证明：存在一个以贪心选择开始的最优解；
    3. 进一步，在第一步做了贪心选择后，子问题也是通过贪心选择得到的最优解。

    设 \(A=\{1,2,\cdots,n\}\) 是给定活动的集合，且已经按照结束时间递增排序，即活动 1 是结束时间最早的。等价于证明存在一个最优解 \(X\) 总是包含活动 1。

    交换法证明第 1 步贪心选择安全：

    1. 假设存在一个以活动 \(k(k\ne 1)\) 开始的最优解 \(Y\)（\(Y\) 中也按照结束时间递增排序）；
    2. \(k=1\)，显然成立；
    3. \(k > 1\)，令 \(Y' = Y - \{k\} + \{1\}\)。因为 \(e_k \ge e_1\)，因此 \(Y'\) 中包含的所有活动也互相兼容，且活动数量与 \(Y\) 相等；
    4. 因为 \(Y\) 是最优解，那么 \(Y'\) 也是最优解，即 \(Y'\) 是一个以活动 1 开始的最优活动安排。

    反证法证明最优子结构：

    在第一步做了贪心选择后，子问题 \(A' = \{i\in A, b_i \ge e_1\}\)，如果 \(X\) 是原问题的最优解，那么 \(X'\) 也是子问题 \(A'\) 的最优解。

    1. 应用反证法，假设 \(X'\) 不是最优解，即存在另一个最优解 \(Y'\)，活动数量大于 \(X'\)；
    2. 将活动 1 加入到 \(Y'\) 中，显然其中的活动也相互兼容，并且是原问题的一个解 \(Y\)；
    3. \(Y\) 的活动数量大于 \(X\)，这与 \(X\) 是原问题的最优解矛盾。

    struct Action {
    int b; // 活动开始时间
    int e; // 活动结束时间
    bool operator<(const Action &s) const {
        return e <= s.e; // 按活动结束时间递增排序
    }
};

bool flag[MAX]; // 标记已选择的活动

void greedy(vector<Action> &a) {
    int n = a.size();
    memset(flag, 0, sizeof(flag));
    sort(a.begin(), a.end());

    int preend = 0; // 前一个活动的结束时间
    for (int i = 0; i < n; i++) {
        if (a[i].b >= preend) { // 晚于前一个活动的结束时间
            flag[i] = true;     // 贪心选择该活动
            preend = a[i].e;
        }
    }
}

    时间复杂度

    算法主体的遍历过程时间复杂度为 \(O(n)\)，排序复杂度为 \(O(n\log n)\)，因此总体时间复杂度为 \(O(n\log n)\)。

    解题示例

    设有 \(n = 8\) 个活动 \(A=\{1,2,\dots,8\}\)，每个活动在执行时独占一份资源，活动一旦开始不能中断。活动 \(i\) 的执行时间为半开区间 \([b_i, e_i)\)，最早开始时间为 0。活动时间如下表所示：

    活动编号 \(i\) 1 2 3 4 5 6 7 8
    开始时间 \(b_i\) 1 3 0 5 3 5 6 8
    结束时间 \(e_i\) 4 5 6 7 8 9 10 11
    求解过程

    数据已按结束时间递增排序完成。

    1. \(i = 1\)：\(preend = 0\)，\(b_1 = 1 \ge 0\)，选择，\(preend = e_1 = 4\)，\(B = \{1\}\)；
    2. \(i = 2\)：\(b_2 = 3 < 4\)，不选择；
    3. \(i = 3\)：\(b_3 = 0 < 4\)，不选择；
    4. \(i = 4\)：\(b_4 = 5 \ge 4\)，选择，\(preend = e_4 = 7\)，\(B = \{1, 4\}\)；
    5. \(i = 5\)：\(b_5 = 3 < 7\)，不选择；
    6. \(i = 6\)：\(b_6 = 5 < 7\)，不选择；
    7. \(i = 7\)：\(b_7 = 6 < 7\)，不选择；
    8. \(i = 8\)：\(b_8 = 8 \ge 7\)，选择，\(preend = e_8 = 11\)，\(B = \{1, 4, 8\}\)。

    最大兼容活动集 \(B = \{1, 4, 8\}\)。

    分数背包问题

    问题描述

    给定 \(n\) 种物品和 1 个背包，其中物品 \(i\) 的重量是 \(w_i\)，其价值为 \(v_i\)，背包的容量为 \(C\)。在选择物品 \(i\) 装入背包时，可以选择物品 \(i\) 的一部分（区别于 0-1 背包问题），请问应如何选择装入背包的物品，使得装入背包中物品的总价值最大？

    问题形式化描述：

    • 决策变量：\(x_i\)，表示物品 \(i\) 装入背包的比例
    • 优化目标：\(\max \sum_{i=1}^n v_i x_i\)
    • 约束条件：\(\sum_{i=1}^n w_i x_i \le C\)，\(0 \le x_i \le 1\)

    贪心策略

    性价比优先，即优先选择单位重量价值最大的物品装入。

    具体步骤：

    1. 计算密度：对于每一个物品 \(i\)，计算其单位重量的价值 \(r_i = \dfrac{v_i}{w_i}\)。
    2. 排序：将所有物品按照 \(r_i\) 从大到小进行降序排列。
    3. 贪心选择：依次考察排序后的物品：
      • 如果背包当前剩余容量足以装下该物品的全部（\(w_i \le C\)），则选择该物品的全部（\(x_i = 1\)），并更新剩余容量 \(C = C - w_i\)；
      • 如果背包当前剩余容量不足以装下该物品的全部，则将背包填满，即取该物品的一部分（\(x_i = \dfrac{C}{w_i}\)），此时背包已满，算法结束。
    贪心选择性质证明（反证法）

    需要证明存在一个最优解，其中包含单位价值（密度）最高的物品（或尽可能多地包含）。等价于证明优先选择的物品就是密度最大的那件（即贪心的第一个选择是安全的）。

    设物品已经按照密度从大到小排序完毕，其中物品 \(i\) 是密度最大的那一件，密度为 \(r_i\)。

    1. 应用反证法，假设存在一个最优解 \(Y\) 不包含密度最大的那件物品，或者在容量足够大情况下只取了部分而不是尽可能的全装入；即对于 \(Y\)，\(0 \le x_i < 1\)；
    2. 不妨设物品 \(j(j\ne i)\) 是最优解 \(Y\) 包含的一个物品，显然 \(r_j < r_i\)。取物品 \(j\) 的一小部分 \(\delta(\delta \le x_j w_j)\)，替换为物品 \(i\)，因为物品 \(i\) 并没有取满，因此 \(x_i\) 增加了 \(\dfrac{\delta}{w_i}\)；
    3. 执行上述操作后，背包总价值变化为 \(-(\delta \cdot r_j) + (\delta \cdot r_i) = \delta \cdot (r_i - r_j) > 0\)，即总价值增加，高于最优解 \(Y\) 的总价值，这与 \(Y\) 是最优解矛盾。

    void knap() {
    double bestv = 0;
    double rw = W;  // 背包中能装下的剩余物品容量
    memset(x, 0, sizeof(x));
    int i = 0;
    while (i < n && A[i].w < rw) {  // A 已按性价比从高到低排好序
        x[i] = 1;    // 表示全装
        rw -= A[i].w;
        bestv += A[i].v;
        i++;
    }
    if (i < n && rw > 0) {  // 只能装部分了
        x[i] = rw / A[i].w;
        bestv += A[i].v * x[i];
    }
}

    时间复杂度

    排序占据主导地位，总体时间复杂度为 \(O(n\log n)\)。

    解题示例

    给定 4 种物品重量分别为 \(\{10, 40, 55, 20\}\)，价值分别为 \(\{20, 120, 55, 100\}\)，背包容量是 100，求背包的最大价值以及对应的放入背包的物品重量。

    求解过程

    不难求出价值密度分别为 \(2, 3, 1, 5\)。按密度降序排列后，物品编号映射为 \(\{4, 2, 1, 3\}\)。

    1. \(i = 1\)（物品 4）：\(rw = 100, w_4 = 20 < rw\)，\(x_4 = 1\)，\(rw = 100 - 20 = 80\)；
    2. \(i = 2\)（物品 2）：\(w_2 = 40 < rw\)，\(x_2 = 1\)，\(rw = 80 - 40 = 40\)；
    3. \(i = 3\)（物品 1）：\(w_1 = 10 < rw\)，\(x_1 = 1\)，\(rw = 40 - 10 = 30\)；
    4. \(i = 4\)（物品 3）：\(w_3 = 55 > rw\)，\(x_3 = \dfrac{30}{55}\)。

    总价值 \(= 100 + 120 + 20 + 55 \times \dfrac{30}{55} = 270\)。

    最优装载问题

    问题描述

    有 \(n\) 个集装箱要装上一艘载重量为 \(c\) 的轮船，其中集装箱 \(i\) 的重量为 \(w_i\)。

    要求：在装载体积不受限制的情况下，将尽可能多的集装箱装上轮船，且装载的集装箱总重量不超过 \(c\)。

    问题形式化描述：

    • 决策变量：\(x_i\)，表示集装箱 \(i\) 是否选择装入，\(x_i \in \{0, 1\}\)
    • 优化目标：\(\max \sum_{i=1}^{n} x_i\)
    • 约束条件：\(\sum_{i=1}^{n} x_i w_i \le c\)，\(x_i \in \{0, 1\}\)

    与 0-1 背包问题的区别

    最优装载问题是 0-1 背包问题的特例，但每种物品的价值都一样（当作 1），因此价值密度变为 \(\dfrac{1}{w_i}\)，重量越小等价于价值密度越高。

    虽然属于 0-1 背包问题的特例，但该问题能用贪心法求解而 0-1 背包问题不能，因为 0-1 背包问题中每个物品的价值不同，而本题中每个物品的价值是一致的，可以证明贪心选择是安全的。

    贪心策略

    优先选择重量轻的集装箱装入（最轻优先）。

    贪心选择性质证明（交换法）

    假设集装箱已经按照重量递增排序完成，即物品 1 为最轻的集装箱。

    设该问题的一个最优解为 \(X=\{x_1,x_2,\cdots,x_n\}\)，设最先被装入的且最轻的物品为 \(k\)，即 \(x_k = 1\)，且 \(x_1,\cdots,x_{k-1} = 0\)。

    1. 如果 \(k=1\)，即所有集装箱中最轻的那个优先被装入，与贪心策略描述一致，因此 \(X\) 是符合贪心选择性质的一个最优解；
    2. 如果 \(k>1\)，则构造一个新的解 \(Y = \{y_1,\cdots,y_n\}\)，其中 \(y_1 = 1, y_k = 0\)，其他 \(y_i = x_i\)（\(i=2,\cdots,k-1,k+1,\cdots,n\)），相当于用集装箱 1 替换 \(k\)；
    3. 新解 \(Y\) 的总重量 \(= \sum_{i=1}^n y_i w_i = \sum_{i=1}^n x_i w_i - w_k + w_1\)，因为 \(w_k \ge w_1\)，且原方案 \(X\) 满足容量约束，所以 \(\sum_{i=1}^n y_i w_i \le \sum_{i=1}^n x_i w_i \le c\)，即新解 \(Y\) 也满足容量约束；
    4. 并且 \(Y\) 和 \(X\) 装载数量相同，因此 \(Y\) 也是原问题的一个最优解，即优先将最轻的第 1 个集装箱装入可以使得装载的总箱数最大化。

    单源最短路径（Dijkstra 算法）

    问题描述

    设带权有向图 \(G=(V, E)\)，边权为正，给定源点 \(v\)，求 \(v\) 到其它顶点最短路径长度。

    贪心策略

    基本思想是把顶点集 \(V\) 分为两组：

    • \(S\)：已确定最短路径的顶点集合（初始只有源点 \(v\)）
    • \(U\)：其余顶点

    对于 \(G\) 中的一个顶点 \(u\)，把 \(v, \cdots, u\) 并且途径点也属于 \(S\) 的路径作为源到 \(u\) 的特殊路径，用数组 \(\text{dist}\) 记录当前每个顶点对应的最短特殊路径长度。

    特殊路径

    特殊路径指的是从源点 \(v\) 到 \(u\)，且所有中间途经点都属于 \(S\) 的路径。初始时，\(\text{dist}\) 数组中每个顶点对应的最短特殊路径长度即为顶点和源的直连路径长度（无边则为 \(+\infty\)）。

    每次操作，选择 \(U = V - S\) 中最短特殊路径长度最小的那个顶点，将其加入 \(S\)，同时更新 \(\text{dist}\)。一旦 \(S\) 包含了所有 \(V\) 中顶点，\(\text{dist}\) 就记录了从源到所有其它顶点之间的最短路径长度。

    贪心策略：每一步从 \(U\) 中选取当前 \(\text{dist}\) 最小的顶点 \(u\) 加入 \(S\)，并对从 \(u\) 出发的边做"松弛"操作，即更新 \(\text{dist}\)：

    \[\text{dist}[i] = \min(\text{dist}[i], \text{dist}[u] + A[u][i])\]
    贪心选择性质证明（反证法）

    贪心策略要求，当一个顶点 \(u\) 加入 \(S\) 时，源到该点的最短路径长度就等于 \(\text{dist}[u]\)。因此，证明贪心选择性质等价于证明：不存在另一条 \(v\) 到 \(u\) 的路径，该路径的某些中间点还在 \(U=V-S\) 中，且该路径长度 \(d(v,u) < \text{dist}[u]\)。

    1. 应用反证法，假设存在一条 \(v\) 到 \(u\) 的普通路径，该路径长度 \(d(v,u) < \text{dist}[u]\)，并且正要添加 \(u\) 到 \(S\) 中；
    2. 由于是普通路径，不妨设该路径上第一个不在 \(S\) 中的顶点为 \(z\)，\(z\) 的前一个顶点为 \(y\)，例如下图：

    1. 显然，由于现在要添加 \(u\) 到 \(S\) 中，因此 \(\text{dist}[u] \le \text{dist}[z]\)；
    2. 最短路径的子路径也是最短路径（否则就会走另一条路到 \(z\)，再从 \(z\) 到 \(u\)），且 \(\text{dist}[z] = D[v,z]\)，\(\text{dist}[y] = D[v,y]\)（因为 \(y\) 和 \(z\) 都是正确的），所以 \(D[v,u] = D[v,z] + D[z,u] \ge D[v,z]\)（边权非负）；
    3. \(\text{dist}[u] \le \text{dist}[z] = D[v,z] \le D[v,u]\)，与 \(\text{dist}[u] > D[v,u]\) 矛盾。

    因此，这样的顶点 \(u\) 不存在。原命题成立，贪心选择正确。

    vector<int> Dijkstra(vector<vector<int>>& A, int v) {
    // A 为邻接矩阵，v 为源点编号，返回 dist 数组
    int n = A.size();
    vector<int> dist(n);
    vector<bool> S(n, false); // false 表示不在 S 数组中

    S[v] = true; // 把源点加入 S
    for (int i = 0; i < n; i++) {
        dist[i] = A[v][i]; // 初始化为和源点的直线距离
    }

    for (int i = 0; i < n-1; i++) { // 每次迭代把一个点加入 S，共 n-1 次
        int u = -1;      // 用于记录候选顶点
        int mindist = INF; // 从所有 dist 中找最小值
        for (int j = 0; j < n; j++) {
            if (S[j] == false && dist[j] < mindist) {
                u = j;
                mindist = dist[j];
            }
        }
        if (u == -1) break; // 啥都没更新，说明已经做完了
        S[u] = true;
        for (int j = 0; j < n; j++) {
            if (S[j] == false && A[u][j] != 0 && A[u][j] < INF) {
                // u 和 j 之间连通，做松弛操作
                dist[j] = min(dist[j], dist[u] + A[u][j]);
            }
        }
    }
    return dist;
}

    贪心法与动态规划的关系

    贪心法 vs 动态规划

    贪心法和动态规划都要求问题具有最优子结构性质，但两者有一个关键区别：

    • 动态规划：每一步的选择依赖于子问题的解，需要先求解子问题，再做出选择（自底向上）。
    • 贪心法：每一步做出当前看来最优的选择，然后求解由此产生的子问题（自顶向下），不需要等到子问题求解完再做选择。

    贪心法的贪心选择性质保证了自顶向下的策略能产生全局最优解。如果一个问题不具备贪心选择性质（如 0-1 背包问题），贪心法就不能保证得到最优解，此时应使用动态规划。

    能否使用贪心法的判断

    判断一个问题能否用贪心法求解，关键在于验证其是否同时满足：

    1. 最优子结构性质
    2. 贪心选择性质

    只有两者都满足时，贪心法才能保证全局最优。典型例子：

    问题 最优子结构 贪心选择性质 适用算法
    活动安排 满足 满足 贪心法
    分数背包 满足 满足 贪心法
    最优装载 满足 满足 贪心法
    单源最短路径（Dijkstra） 满足 满足 贪心法
    0-1 背包 满足 不满足 动态规划
