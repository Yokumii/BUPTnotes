    数组与广义表

    数组是线性表的推广——数据元素本身也可以是线性表。本章围绕数组的定义、矩阵的压缩存储策略以及广义表的基本概念展开。

    数组

    数组 (Array)
    线性表的扩展，其数据元素本身也是线性表。数组中各元素具有统一的类型。

    一维数组是线性表的直接映射。二维数组可以看作"每个元素是一维数组的一维数组"，即 \(n \times m\) 的二维数组 \(A\) 由 \(n\) 个行向量组成，每个行向量是长度为 \(m\) 的一维数组。

    数组与线性表的关系

    线性表是数组的一种特例——当数组中每个元素都是原子（不可再分解）时，数组退化为普通的线性表。反之，数组是线性表在"元素本身亦为线性表"方向上的推广。

    数组的顺序存储

    数组通常采用顺序存储方式。对于二维数组，存在两种映射策略：

    行优先顺序 (Row-major)
    将元素按行依次存放：\(a_{11}, a_{12}, \dots, a_{1m}, a_{21}, \dots, a_{nm}\)。地址计算公式为：
    \[\mathrm{LOC}(a_{ij}) = \mathrm{LOC}(a_{11}) + [(i-1) \times m + (j-1)] \times L\]
    列优先顺序 (Column-major)
    将元素按列依次存放：\(a_{11}, a_{21}, \dots, a_{n1}, a_{12}, \dots, a_{nm}\)。地址计算公式为：
    \[\mathrm{LOC}(a_{ij}) = \mathrm{LOC}(a_{11}) + [(j-1) \times n + (i-1)] \times L\]

    其中 \(L\) 为每个元素占用的存储单元数。

    矩阵的压缩存储

    压缩存储的目的在于节省空间：当矩阵中存在大量重复或零元素时，只存储有意义的部分，同时保证能快速定位任意元素。

    对称矩阵

    对称矩阵 (Symmetric Matrix)
    满足 \(a_{ij} = a_{ji}\) 的 \(n\) 阶方阵。只需存储下三角（含主对角线）的 \(\frac{n(n+1)}{2}\) 个元素即可还原整个矩阵。

    将下三角元素按行优先顺序存入一维数组 sa[]，则 \(a_{ij}\) 的存储位置为：

    • 当 \(i \geq j\)（下三角区域）：
    \[k = \frac{i(i-1)}{2} + j - 1\]
    • 当 \(i < j\)（上三角区域）：利用对称性，\(a_{ij} = a_{ji}\)，查找 \(a_{ji}\) 的存储位置即可。

    带状矩阵

    带状矩阵 (Band Matrix)
    所有非零元素集中分布在以主对角线为中心的带状区域内的矩阵。例如三对角矩阵中，非零元素仅出现在 \(a_{i,i-1}, a_{i,i}, a_{i,i+1}\) 位置。

    对于 \(n\) 阶三对角矩阵，共 \(3n - 2\) 个非零元素。按行优先压缩存储到一维数组后，\(a_{ij}\) 对应的下标为：

    \[k = 2i + j - 3\]

    （其中 \(|i - j| \leq 1\)）

    随机稀疏矩阵

    随机稀疏矩阵 (Random Sparse Matrix)
    非零元素个数远少于矩阵总元素数，且分布没有规律。

    三元表法（顺序存储）

    三元表法 (Triple Table)
    将每个非零元素用三元组 \((i, j, v)\) 表示——行号、列号、值，然后按行优先顺序将所有三元组存入一维数组。
    三元表法的局限

    三元表法适合非零元素位置和个数相对固定的场景。当矩阵在运算过程中非零元素的位置或个数经常变动（如矩阵加法产生新的非零元素、矩阵乘法改变非零元素分布），三元表法需要大量移动元素，效率较低。

    十字链表法（链式存储）

    十字链表法 (Cross-linked List)
    在行、列两个方向上分别将非零元素链接成链表。每个非零元素节点包含五个域：行号 row、列号 col、值 val、行链后继 right、列链后继 down。

    同时维护两个指针数组：

    • rhead[]：每行的行链表头指针
    • chead[]：每列的列链表头指针

    十字链表法的优势

    十字链表法克服了三元表法在矩阵非零元素位置或个数经常变动时的使用不便——插入和删除非零元素只需修改对应行链和列链的指针，无需移动大量数据。

    广义表

    广义表 (Generalized List / List)
    由零个或多个原子或者子表组成的有限序列。
    原子 (Atom)
    逻辑上不能再分解的元素。
    子表 (Sublist)
    作为广义表中元素的广义表。

    广义表与线性表

    当广义表中的元素全部为原子时，即为线性表。因此线性表是广义表的特例，广义表是线性表的推广。

    约定用大写字母表示广义表的名称，小写字母表示原子。例如：

    \[D = (A, B, c)\]

    其中 \(A = (x, y, z)\) 是子表，\(B = (d)\) 是子表，\(c\) 是原子。

    基本术语

    长度 (Length)
    广义表中第一层元素的个数。
    深度 (Depth)
    广义表中元素的最深嵌套层数（括号的重数）。原子深度为 \(0\)，空表深度为 \(1\)。

    以上面的 \(D\) 为例：

    • 长度 = \(3\)（三个第一层元素：\(A, B, c\)）
    • 深度 = \(2\)（\(A\) 的嵌套深度为 \(1\)，再嵌套一层到 \(x\) 等，所以 \(D\) 深度为 \(2\)）
    表头 (Head)
    广义表中的第一个元素。
    表尾 (Tail)
    除第一个元素外，剩余元素构成的广义表。

    表尾必定是广义表

    任何一个非空广义表的表尾必定仍为广义表。取表尾操作 tail() 总是返回一个用括号括起来的列表。

    以 \(D = (A, B, c)\) 为例：

    • \(\mathrm{head}(D) = A\)
    • \(\mathrm{tail}(D) = (B, c)\)（注意：不是 \(B, c\)，而是由 \(B, c\) 构成的广义表）
    表头与表尾的计算

    对 \(L = (a, (b, c, d))\)：

    • \(\mathrm{head}(L) = a\)（原子）
    • \(\mathrm{tail}(L) = ((b, c, d))\)（子表构成的广义表）
    • \(\mathrm{head}(\mathrm{tail}(L)) = (b, c, d)\)（子表）
    • \(\mathrm{tail}(\mathrm{tail}(L)) = ()\)（空表）
