    线性表

    基本概念

    线性表（Linear List）
    由 \(n\)（\(n \geq 0\)）个具有相同特性的数据元素组成的有限序列。当 \(n = 0\) 时称为空表。

    对于非空线性表 \(L = (a_1, a_2, \ldots, a_n)\)，其结构特征为：

    • 唯一首元素：\(a_1\) 无前驱
    • 唯一尾元素：\(a_n\) 无后继
    • 中间元素：\(a_i\)（\(2 \leq i \leq n-1\)）有且仅有一个前驱 \(a_{i-1}\) 和一个后继 \(a_{i+1}\)

    线性表的本质

    线性表是一种逻辑结构，描述了数据元素之间一对一的线性关系。同一个逻辑结构可以采用不同的存储结构来实现——顺序存储或链式存储。

    线性表的基本运算包括：

    运算 说明
    InitList 初始化空表
    ListLength 返回表中元素个数
    GetElem 返回第 \(i\) 个元素的值
    LocateElem 返回第一个满足条件的元素位序
    ListInsert 在第 \(i\) 个位置插入新元素
    ListDelete 删除第 \(i\) 个元素

    顺序存储——顺序表

    顺序表采用一段连续的物理存储单元依次存储线性表中的数据元素。元素之间的逻辑关系通过存储位置的相邻性来体现。

    特点

    • 存储密度高：每个节点只存储数据元素本身，无额外指针开销
    • 随机存取：通过元素位序可直接计算物理地址，存取时间为 \(O(1)\)
    \[ \text{LOC}(a_i) = \text{LOC}(a_1) + (i - 1) \times c \]

    其中 \(c\) 为每个元素占用的存储单元数。

    插入与删除

    插入：在第 \(i\) 个位置插入新元素，需将第 \(i\) 到第 \(n\) 个元素依次后移一位。

    • 平均移动次数：\(\dfrac{n}{2}\)
    • 时间复杂度：\(O(n)\)

    删除：删除第 \(i\) 个元素，需将第 \(i+1\) 到第 \(n\) 个元素依次前移一位。

    • 平均移动次数：\(\dfrac{n - 1}{2}\)
    • 时间复杂度：\(O(n)\)

    顺序表的不足

    顺序表的插入和删除操作需要大量移动元素，效率较低。此外，顺序表需要预先分配连续存储空间，容量难以动态扩展，容易造成空间浪费或溢出。

    链式存储——链表

    链表通过指针来表示数据元素之间的逻辑关系，各元素的存储位置可以任意分散。每个节点包含两部分：

    数据域（data）
    存储数据元素本身的信息
    指针域（next）
    存储直接后继节点的地址

    单链表

    单链表中，每个节点只含一个指向后继的指针。整个链表的访问必须从头指针开始，顺着指针链依次遍历。

    头节点的使用

    头节点（Head Node）
    在单链表的第一个数据节点之前附加的一个辅助节点，其数据域可以不存储任何信息（或存储表长等辅助信息），指针域指向第一个数据节点的地址。

    引入头节点的好处：

    1. 统一空表与非空表的处理：无头节点时，空表的头指针为 NULL，插入/删除第一个位置需要特殊处理；有头节点后，无论表是否为空，头指针始终指向头节点，操作逻辑统一。
    2. 简化首元素位置的操作：在第一个位置插入或删除元素时，无需修改头指针，只需修改头节点的指针域，与其他位置的操作完全一致。

    头节点 vs 头指针

    • 头指针：指向链表第一个节点（无论是否为头节点）的指针，是链表的唯一标识和访问入口。
    • 头节点：附加在首元素之前的辅助节点，是为了操作方便而引入的，并非链表所必需。

    其他链表形式

    循环链表

    循环链表将单链表的尾节点指针域由 NULL 改为指向头节点（或头指针所指节点），使整个链表形成环。从任一节点出发均可遍历全表。

    双向链表

    双向链表的每个节点设有两个指针：

    前驱指针（prior）
    指向直接前驱节点
    后继指针（next）
    指向直接后继节点

    双向链表支持双向遍历，在插入和删除时无需定位前驱节点，但每个节点需额外存储一个指针，空间开销增大。

    双向循环链表

    将双向链表的头节点的前驱指针指向尾节点、尾节点的后继指针指向头节点，即可构成双向循环链表，兼具双向遍历和循环访问的优点。

    顺序表与链表的比较

    比较维度 顺序表 链表
    存储方式 连续存储，预分配空间 离散存储，动态分配
    存储密度 \(1\)（无额外指针开销） \(< 1\)（需存储指针）
    存取方式 随机存取，\(O(1)\) 顺序存取，\(O(n)\)
    插入删除 需移动元素，\(O(n)\) 修改指针，\(O(1)\)（定位后）
    空间利用 需预估计容量，可能溢出或浪费 按需分配，无溢出风险
    适用场景 表长可预估、查询多、增删少 表长不确定、增删频繁

    选择依据

    • 频繁按位序查找、较少插入删除 → 顺序表
    • 频繁插入删除、表长动态变化 → 链表
