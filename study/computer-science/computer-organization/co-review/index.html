    计算机组成原理期末复习

    期末复习速查，聚焦比较表、关键公式、易错点和 Q&A。详细内容参见各章节笔记。

    复习范围

    本文覆盖教材全部 8 章：计算机概述、运算方法与运算器、存储系统、指令系统、CPU、总线系统、外围设备、输入输出系统。以比较对照 + 公式速记 + 易错辨析为主线，不重复章节笔记中的展开论述。

    冯·诺依曼机五大原则

    1. 采用存储程序工作方式
    2. 硬件系统由运算器、存储器、控制器、输入设备、输出设备 5 大部件组成
    3. 指令和数据以同等地位存储在存储器中，形式上无区别，但计算机应能区分
    4. 指令和数据均用二进制代码表示
    5. 指令由操作码和地址码组成
    关键辨析
    • 基本工作方式：控制流驱动；基本特点：按地址访问并顺序执行指令
    • "存储程序"思想：程序和原始数据送入主存后才能执行，一旦启动则自动逐条执行至结束，无须人工干预
    • CPU 如何区分指令和数据？控制器根据指令周期的不同阶段区分——取指阶段取出的是指令，执行阶段访存取出的是数据

    性能指标速记

    指标 定义 / 公式 备注
    主频 CPU 时钟频率 单位 MHz / GHz
    时钟周期 主频倒数
    CPI \(\text{CPI} = \dfrac{\text{时钟周期总数}}{\text{指令总数}}\) 平均值
    CPU 执行时间 \(T = \text{指令数} \times \text{CPI} \times \text{时钟周期长度}\) 核心公式
    MIPS \(\text{MIPS} = \dfrac{\text{指令总数}}{\text{执行时间} \times 10^{-6}}\) 每秒百万指令
    机器字长 一次定点整数运算能处理的二进制位数 = 通用寄存器位数 / ALU 宽度
    数据通路带宽 数据总线一次并行传送信息的位数

    定点数表示对比

    表示法 正数 负数 0 的表示 范围（\(n\) 位）
    原码 符号位 0 号位 1 两种 \((+0/-0)\) \(-(2^{n-1}-1) \sim 2^{n-1}-1\)
    补码 不变 模 \(2^n\)，即按位取反+1 唯一 \(-2^{n-1} \sim 2^{n-1}-1\)
    反码 不变 除符号位各位取反 两种 同原码
    移码 真值 \(+2^{n-1}\) 同 唯一 与补码相同，仅符号位不同
    溢出标志易错
    • OF（溢出标志）：判断有符号数运算溢出——参与运算两数符号相同，但结果符号不同则 OF=1
    • CF（进位/借位标志）：判断无符号数运算溢出——转成减法，小-大则 CF=1
    • 溢出判断方法：\(C_f \oplus C_0\)（符号位进位与最高数值位进位的异或）

    浮点数核心

    \[N = (-1)^S \times M \times R^E\]
    • 尾数 \(M\)（定点小数，原码）→ 决定精度
    • 阶码 \(E\)（整数）→ 决定范围
    • 基数 \(R\) 一般为 2、8、16

    规格化要求

    \[ \frac{1}{R} \le \lvert M\rvert < 1 \]

    负数补码规格化特例

    负数补码规格化范围 \(-1 \le M < -\frac{1}{2}\)，特例：\(-\frac{1}{2}\) 是规格化数。

    IEEE 754 速查

    要素 规则
    阶码 移码表示，偏置值 \(= 2^{n-1} - 1\)（单精度 127，双精度 1023）
    尾数 原码表示，规格化隐含整数位 1，实际尾数 \(= 1.\text{Frac}\)
    非规格化 阶码全 0，实际阶码 \(= 1 - \text{Bias}\)，实际尾数 \(= 0.\text{Frac}\)
    最大阶码 \(2^n - 2\)（全 0 和全 1 作特殊值保留）

    浮点加减运算步骤

    1. 对阶：小阶向大阶看齐，小阶尾数右移、阶码增大
    2. 尾数加减
    3. 尾数规格化（左规/右规）
    4. 舍入（向偶数舍入）
    5. 溢出判断（阶码上溢）
    Tip

    "对阶/右规时可能发生舍入"

    原码乘除速记

    两个 \(n\) 位无符号数相乘：\(n\) 次加法 + \(n\) 次移位。

    加减交替法：先减，结果 < 0 则商 0 左移加 Y；结果 > 0 则商 1 左移减 Y。

    SRAM vs DRAM

    对比项 SRAM DRAM
    速度 快（10ns 级） 慢（几十 ns）
    集成度 低 高（适合大容量）
    功耗 高 低
    成本 高 低
    送地址 行列同时送 行列分两次送（分时复用）
    破坏性读出 非破坏性 破坏性
    刷新 无需 定期按行刷新
    结构 6 个晶体管 1 个晶体管 + 1 个电容
    用途 Cache、寄存器 主存、显存
    DRAM 刷新方式
    • 集中式刷新：前段读写，后段逐行刷新；刷新时 CPU 无法访存
    • 分布式刷新：均匀分配，e.g. 1024 行 / 8ms → 每隔 7.8μs 刷新一行

    存储器技术指标

    指标 定义
    访问时间 \(T_A\) 启动操作到操作完成的时间
    存取周期 \(T_m\) CPU 连续两次独立访问存储器的最小时间间隔

    多模块交叉存储器

    • 地址码高位确定存储字，低位选择模块
    • 同一模块内地址不连续
    • 连续传送可实现流水线并行存取

    公式速记（模块数 \(m = \dfrac{T}{\tau}\)）：

    项目 公式
    交叉存取连续 \(m\) 字 \(t_1 = T + (m-1)\tau\)
    顺序存取 \(m\) 字 \(t_2 = mT\)

    （思路与流水线一致）

    Cache 速查

    • 由 SRAM 组成，完全由硬件调度，对用户透明
    • 局部性原理：时间局部性 + 空间局部性

    地址映射对比

    映射方式 主存块定位规则 地址结构 比较器 冲突概率 空间利用率
    全相联 任意行 Tag + Block Offset 全部行 最低 最高
    直接映射 \(j \% m = i\) Tag + Line Index + Block Offset 1 最高 最低
    v 路组相联 组号 \(q = j \% u\)，组内任意行 Tag + Set Index + Block Offset \(v\) 中 中
    CAM（相联存储器）

    内容可寻址存储器，既能按内容寻址，也能按地址读写。用于 Cache Tag 匹配。

    替换算法

    算法 策略 需要的硬件
    LFU 替换最近一段时间访问次数最少的块 访问计数器
    LRU 替换最久未被访问的块 计时器（被访问则清零）

    写策略组合

    组合 写命中 写缺失
    直写 + 非写分配 同时更新 Cache 和主存 只更新主存
    回写 + 写分配 先写 Cache，修改时才写回主存 更新主存并加载到 Cache

    虚存与 TLB

    • 虚存：主存 + 辅存统一编址，由软件（OS）+ 硬件实现，对应用程序员透明
    • TLB 是页表的 Cache，同时查 TLB 和页表
    不可能事件证明（易考）

    "TLB 命中 + 页表缺失"不可能：

    • TLB 是页表的缓存
    • TLB 中的信息必须来自页表
    • 若页表中都没有该项（或页不在内存），TLB 根本不可能提前装到该项

    "Cache 命中 + 页表缺失"不可能：

    • Cache 使用物理地址访问
    • 若页表都还没得到物理地址，根本没法查 Cache

    存储管理方式对比

    方式 划分方式 优点 缺点
    段式 按逻辑功能，大小不等 利于信息共享和内存保护 易产生碎块
    页式 大小相同的页 页表简单，调入方便 处理/保护/共享不如段式
    段页式 先分段再分页 可按段共享和保护 需多次查表（段表 + 页表），开销大

    寻址方式汇总表

    寻址方式 有效地址 访存次数 备注
    立即寻址 A 即是操作数 0
    直接寻址 \(\text{EA} = A\) 1
    一次间接寻址 \(\text{EA} = (A)\) 2
    寄存器寻址 \(\text{EA} = R_i\) 0
    寄存器间接一次寻址 \(\text{EA} = (R_i)\) 1
    相对寻址 \(\text{EA} = (\text{PC}) + A\) 1
    基址寻址 \(\text{EA} = (\text{BR}) + A\) 1
    变址寻址 \(\text{EA} = (\text{IX}) + A\) 1
    寻址易错点
    • 数组访问适合用变址寻址
    • 主存地址不能为负数！ 但偏移量可以为负——注意直接寻址中的地址范围
    • 寄存器堆栈 = 硬堆栈；主存堆栈空间 = 软堆栈

    CISC vs RISC

    特性 CISC RISC
    指令数量 多、复杂（上百种） 少、简单（几十种）
    指令长度 不固定 固定
    执行时间 不确定 一般1 个机器周期
    寻址方式 多种 较少
    操作对象 内存和寄存器都可 只操作寄存器（Load/Store 访存）
    通用寄存器 较少 多
    控制器 微程序控制 硬布线控制
    流水线 不利 适合流水线
    编译优化 困难 编译器优化
    RISC 代价

    RISC 每条指令功能简单，复杂功能需组合实现，编译器设计难度增大，兼容性差于 CISC。

    CPU 概念速查

    周期层次

    周期 含义
    指令周期 取出并执行一条指令的全部时间
    CPU/机器周期 完成一个基本操作的时间（如取指、间址、执行、中断）
    时钟周期 最小时间单位

    指令周期四阶段

    1. 取指周期：从主存取出指令，更新 PC
    2. 间址周期（如有）：计算操作数有效地址
    3. 执行周期：取操作数、执行运算、存结果
    4. 中断周期：检查中断请求
    公操作

    一条指令执行完毕后，CPU 进行的公共操作（如中断处理）。

    硬布线 vs 微程序控制器

    特性 硬布线控制器 微程序控制器
    控制信号产生 组合逻辑电路直接生成 微指令存于控制存储器
    本质 固定逻辑电路 存储程序 + 微程序解释器
    速度 快 较慢（需读微指令）
    修改灵活性 差（要改电路） 好（改微程序即可）
    结构复杂度 高 低（程序驱动）
    适用 高速处理器、简单控制器 多功能、通用处理器
    设计成本 一次性高 长期维护简单
    典例 RISC（MIPS 硬件控制） CISC（Intel 早期 x86）

    微程序控制器核心概念链

    \[\text{程序} \xrightarrow{1:\text{many}} \text{指令} \xrightarrow{1:1} \text{微程序} \xrightarrow{1:\text{many}} \text{微指令} \xrightarrow{1:\text{many}} \text{微命令/微操作}\]
    • 微命令 → 控制信号；微操作 → 执行结果（一一对应）
    • 微周期 = 从控存取出一条微指令并执行的全部时间 ≈ 1 个时钟周期
    • 相容性微操作可并行；相斥性微操作不可并行

    微指令格式

    • 操作控制字段 → 微命令
    • 顺序控制字段 → 产生下一条微指令地址

    水平型 vs 垂直型微指令

    特性 水平型微指令 垂直型微指令
    微指令长度 较长（几十位以上） 较短（十几位）
    控制信号表达 每一位直接对应一个控制信号（位控） 字段译码，类似机器指令
    并行性 高 低
    执行速度 快 慢
    灵活性 强 弱
    编程难度 用户难掌握 用户易掌握

    微命令编码方法

    方法 原理 特点
    直接表示法 每一位对应一个微命令 简直观，无需译码，但字段过长
    编码表示法 相斥微命令合并为小组，字段译码 \(n\) 位 → \(2^n - 1\) 个微命令（全 0 = 无操作）
    混合表示法 前两者混合
    编码表示法为什么 \(2^n - 1\)？

    全 0 表示"没有任何微操作"，所以可用微命令数为 \(2^n - 1\)。

    微地址形成方法

    方法 顺序执行 分支执行 优点 缺点
    计数器方式 微地址 + 增量 转移方式产生 顺序控制字段少 多路并行转移弱，慢
    多路转移方式 顺序控制字段直接给出 P 字段 + 状态条件 → \(2^n\) 路转移 多路并行转移强，快 需复杂组合逻辑

    流水线公式速记

    设 \(k\) 级流水线完成 \(n\) 个任务，时钟周期 \(\tau = \max\{\tau_i\} + \tau_l\)：

    指标 公式 极限
    流水线用时 \(T_k = (k + n - 1)\tau\)
    非流水线用时 \(T_0 = n \cdot k \cdot \tau\)
    加速比 \(S = \dfrac{n \cdot k}{k + n - 1}\) \(n \gg k\) 时 \(S_{\max} = k\)
    吞吐率 \(\text{TP} = \dfrac{n}{(k+n-1)\tau}\) \(\text{TP}_{\max} = \dfrac{1}{\tau}\)
    频率 \(f = \dfrac{1}{\tau}\)

    流水线冒险

    冒险类型 原因 解决方法
    结构冒险（资源相关） 同一时钟周期争用同一资源 暂停一拍；指令和数据分存不同存储器
    数据冒险 依赖流水线中未完成指令的结果 前推/旁路（Forwarding/Bypassing）
    控制冒险 条件转移指令导致取指不确定 分支预测（静态/动态）
    数据冒险细分
    • RAW（写后读）：最常见
    • WAR（读后写）：反相关
    • WAW（写后写）：输出相关
    分支预测
    • 静态：直接预测分支发生/不发生；编译器重排指令填入延迟槽
    • 动态：硬件维护分支历史表 BHT，按历史行为预测

    总线系统速查

    总线分类

    类型 连接对象 子类型
    内部总线 CPU 内部寄存器/ALU
    系统总线 CPU 与其他部件 数据总线（双向）、地址总线（单向）、控制总线
    设备总线 计算机与慢速 I/O

    总线结构

    结构 优点 缺点
    单总线 简单、成本低、易扩展 带宽低、不支持并发
    双总线（主存+I/O） 分离低速设备 增加硬件
    三总线 降低处理器-主存负载 更复杂

    仲裁方式对比

    方式 类型 机制 优点 缺点
    链式查询 集中 菊花链传递 Bus Grant 简单，易增删设备 对故障敏感，速度慢，低优先级可能饿死
    计数器定时查询 集中 计时器值 = 设备地址则授权 可动态改变优先级 需调整地址线数
    独立请求 集中 并行仲裁 速度快，优先级灵活，对故障不敏感 电路复杂，线路多
    分布式仲裁 分布 各设备发仲裁号到总线，最大者获得 无中央仲裁器 比较逻辑分散

    总线数据传输五阶段

    1. 请求阶段：主设备发出总线传输请求
    2. 仲裁阶段：决定下一个传输周期的总线使用权
    3. 寻址阶段：主设备发出命令和地址
    4. 传输阶段：主从设备间数据传输（同步/异步/半同步/分离方式）
    5. 释放阶段：撤消请求，释放总线
    传输阶段子方式
    • 同步方式：统一时钟控制
    • 异步方式：应答方式，无公共时钟
    • 半同步方式：同步+异步结合
    • 分离方式：分成两个子周期

    PCI vs PCIe

    对比项 PCI PCIe
    通信方式 并行 串行、点对点
    时钟方式 同步 嵌入式时钟、异步
    传输速率 133MB/s PCIe 3.0 ×16 ≈ 16GB/s
    带宽共享 总线共享 每设备独享链路
    仲裁 集中仲裁（REQ#/GNT#） 无需仲裁
    热插拔 不支持 支持

    PCIe 使用差分传输，实现全双工端到端连接。

    外围设备核心公式

    磁盘存储

    概念 公式/说明
    柱面 所有磁盘面上相同编号磁道的集合
    非格式化容量 磁头数 × 磁道(柱面)数 × 每道扇区数 × 每道扇区字节数
    格式化容量 ≈ 非格式化容量的 60%~70%
    平均存取时间 \(T_a = T_{\text{avg\_seek}} + T_{\text{avg\_rotation}} + T_{\text{avg\_trans}}\)
    平均旋转等待 \(T_{\text{avg\_rotation}} = \dfrac{1}{2} \times \dfrac{60}{\text{RPM}}\)
    数据传输率 每转传输数据 × 转速
    地址格式 组号 + 柱面号 + 记录面号 + 扇区号；最小寻址单位 = 扇区
    RAID 速记
    • RAID 0：条带方式，无冗余无校验
    • RAID 1：镜像，100% 数据冗余，空间利用率低
    • 更高级别均有校验码功能

    中断 vs DMA

    比较项 程序中断方式 DMA 方式
    保护现场 需要保护和恢复 无需
    CPU 参与度 高（逐字节读写） 低（仅预处理和后处理）
    传送方式 中断服务程序（软件） DMA 控制器硬件
    响应时机 每条指令执行完毕 每个总线周期结束
    效率 中（适合低速/间歇设备） 高（适合高速成组传送）
    传输粒度 一个或少量字节 多字节/整块
    中断频率 多次 一次（传送完毕后通知）
    优先级 低于 DMA 高于中断
    典型应用 键盘、鼠标、串口 硬盘、显卡、网卡

    中断处理流程

    中断周期（硬件自动完成，即中断隐指令）

    1. 关中断（中断屏蔽）
    2. 找出中断源，保存至 PC
    3. 根据 PC 跳转至中断服务程序

    中断服务程序（软件执行）

    1. 保护 CPU 现场
    2. 中断事件处理
    3. 恢复 CPU 现场
    4. 开中断
    5. 中断返回
    中断易错点
    • 中断隐指令是硬件操作，不是软件指令
    • 多级中断：\(n\) 级中断 → CPU 有 \(n\) 个 IM 和 IR
    • 响应某级中断时，本级和低于本级的 IM 置 1（屏蔽本级及更低级），但允许更高级中断
    • 使用堆栈保护现场（包括 IM）

    DMA 数据传送方式

    方式 机制 优缺点
    成组传送 一次传完整个数据块 简单，适合高速；但 CPU 无法访存
    周期窃取 每传一个数据窃取一个 CPU 周期 灵活；总线申请/归还开销大
    交替访存（透明 DMA） 分时访存 CPU 不感知 DMA
    DMA 关键设备
    • 内存地址计数器：指向缓冲区首地址，每次 +1
    • 字计数器：传送长度，每次 -1，溢出 → 传送结束
    • 中断机构：字计数器溢出时向 CPU 发出传送结束请求
