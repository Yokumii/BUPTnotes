    总线系统

    总线概念

    定义与特性

    总线
    在功能部件和功能部件之间、或设备和设备之间的一组进行互联和传输的信号线

    总线的基本特性是分时与共享：

    • 分时：同一时刻只允许一个设备向总线发送信息
    • 共享：多个设备可以同时从总线上接收信息

    总线的优点

    • 解决外部设备"杂"的问题，统一互联标准
    • 降低系统成本，减少连线数量
    • 简化系统设计，易于扩充新设备

    总线的缺点

    • 总线容易成为信息通道的瓶颈，制约整体性能
    • 总线速度受总线本身性能和所连接设备中最慢设备的限制

    总线分类

    按功能层次分类：

    内部总线
    CPU 内部各寄存器之间及寄存器与 ALU 之间的连接信号线
    系统总线

    CPU 和计算机其他部件之间的连接信号线，包含以下三类：

    • 数据总线：双向，位数与机器字长、存储字长有关
    • 地址总线：单向，位数与存储地址、I/O 地址有关
    • 控制总线：有出有入，一般单向
    设备总线（通信总线 / 外总线）
    计算机与慢速 I/O 设备之间的连接信号线

    性能指标

    总线宽度
    指数据总线的宽度（位数），决定了单次数据传输的最大信息量
    总线带宽 / 传输率
    每秒传输的字节数，即总线的数据传输速率
    总线定时协定
    总线传输数据的定时方式（同步 / 异步等）
    信号线数
    地址总线、数据总线和控制总线线数的总和
    总线负载能力
    总线上能连接的设备数量上限

    总线结构

    单总线结构

    所有部件均由一组系统总线连接。

    单总线的优点

    各部件之间可直接进行通信，系统易于扩充。

    单总线的缺点

    总线负载重；若系统中存在慢速设备，则会产生较大的时间延迟，降低系统工作效率；多个部件只能争用唯一的总线，不支持并发传送操作。

    双总线结构

    系统总线连接 CPU、主存和 I/O 接口，另外在 CPU 和主存之间增设一组高速的存储总线（处理器 - 主存总线）。

    双总线的优点

    简单，易于扩充；减轻了系统总线的工作负担，使 CPU 工作效率有所提高。

    双总线的缺点

    增加了硬件成本。

    三总线结构

    系统总线连接 CPU、主存和 I/O 通道，存储总线连接 CPU 与主存，I/O 总线连接各个 I/O 适配器。通过引入通道对外设进行统一管理。

    三总线的优点

    设置了通道对外设统一管理，分担了 CPU 的负担；提高了 CPU 的工作效率，最大限度提高了外设的工作速度。

    三总线的缺点

    硬件成本进一步增加。

    另一种三总线结构

    按期末复习 PPT 的描述，三总线结构还可以是在双总线基础上增加一条主板总线，连接到主存总线上，进一步降低处理器 - 主存总线的负载。

    总线仲裁

    总线上的主从模块

    • 主模块（主设备）：拥有总线控制权，能发起数据传输请求（如 CPU、DMA 控制器）
    • 从模块（从设备）：只能响应主模块的命令，被动参与数据传输（如存储器、I/O 设备）

    当多个主模块同时请求使用总线时，需要通过总线仲裁决定优先权。

    集中式仲裁

    集中式仲裁由唯一的总线仲裁器进行指挥，分为以下三种方式。

    链式查询方式

    设备按优先级从高到低连成一个"菊花链"，总线授权信号（Bus Grant）沿着链依次传递，直到被某个请求设备接收，接收后该设备对授权信号进行拦截，获得总线使用权。

    链式查询的优点

    结构简单，便于增删总线上的设备。

    链式查询的缺点

    对电路故障敏感；仲裁速度慢；优先级低的设备可能"饿死"。

    计数器定时查询方式

    增加了一个计数器，当接收到总线请求时启动计数。若计数器的值等于请求总线的设备地址，则将该设备授予总线使用权。

    计数起点对优先级的影响
    • 从"0"开始每次计数：等价于链式查询，优先级固定
    • 从上次停止的计数点开始：每个设备优先级相同，公平轮转

    计数器定时查询的优点

    能动态改变优先次序。

    计数器定时查询的缺点

    需要额外的地址线数，电路比链式查询复杂。

    独立请求方式

    每个主模块都有独立的总线请求信号线和总线授权信号线，由仲裁器直接判断优先级并给出授权，属于并行仲裁。

    独立请求的优点

    判优速度快，且与模块数无关；对优先级的控制灵活；对故障不敏感。

    独立请求的缺点

    电路复杂，需要的控制线路较多，不易增加新设备。

    分布式仲裁

    每个潜在的主模块都有独立的仲裁器和唯一的仲裁号。当某设备需要使用总线时，将其仲裁号 CN 发送到仲裁总线上，各设备通过仲裁总线相互比较仲裁号的大小，仲裁号最大的设备获得总线使用权。

    集中仲裁 vs. 分布仲裁

    对比项 集中式仲裁 分布式仲裁
    仲裁器 唯一的中央仲裁器 每个设备内置仲裁器
    灵活性 优先级策略集中控制 仲裁号固定，优先级由编号决定
    可扩展性 受限于控制线路 较好

    总线数据传输

    串行传送方式

    数据在单根信号线上逐位传送，适用于长距离通信和高速串行总线（如 PCIe）。

    总线事务的传输阶段

    总线事务（从请求总线到完成总线操作的完整过程）一般包括以下五个阶段：

    1. 请求 / 申请阶段：主设备（CPU / DMA）发出总线传输请求
    2. 仲裁阶段：总线仲裁机构决定将下一个传输周期的总线使用权授予某个申请者，解决多个主设备同时申请总线的问题
    3. 寻址阶段：主设备通过总线发出命令和目标地址
    4. 传输阶段：主设备和从设备之间进行数据交换，按定时方式可分为：
      • 同步方式：由统一时钟控制数据传送
      • 异步方式：采用应答方式，没有公共时钟
      • 半同步方式：同步与异步方式的结合
      • 分离方式：分成两个子周期完成传送
    5. 释放阶段：主设备放弃总线使用权

    同步方式 vs. 异步方式

    对比项 同步定时 异步定时
    时钟 统一公共时钟 无公共时钟，依赖应答信号
    速度 高（无需等待应答） 较低（需握手确认）
    适用场景 速率一致、距离短的模块 速率差异大、距离远的模块
    可靠性 时钟偏移影响通信 应答机制保证可靠

    PCI 总线

    PCI 特点

    PCI（Peripheral Component Interconnect，总线式部件互联标准）的主要特点如下：

    特性 说明
    设备独立性 独立于处理器，不依赖特定处理器架构（x86、MIPS、PowerPC 均可使用）
    总线时钟频率 33.3MHz（V2.0）/ 66.6MHz（V2.1）
    总线宽度 数据线 32 位（可扩展至 64 位），数据并行传输
    数据传输速率 133MB/s（266MB/s）
    突发传输 支持连续传送多个数据，提升效率
    同步操作 支持同步操作
    总线主从机制 除了 CPU，其他设备也可成为"总线主控方"（支持总线主控转移）
    即插即用（PnP） 自动识别外设，自动分配地址和中断资源
    总线仲裁 集中式仲裁方式
    引脚复用 地址线和数据线多路复用，减少引脚数
    电压 5V 或 3.3V（有键槽区分）

    PCI vs. PCI Express

    对比项 PCI PCI Express (PCIe)
    通信方式 并行通信（Parallel） 串行通信（Serial）、点对点
    时钟方式 同步时钟 嵌入式时钟、异步传输
    传输速率 32bit@33MHz \(\approx\) 133MB/s PCIe 3.0 \(\times\)16 \(\approx\) 16GB/s（双向）
    带宽共享 总线共享，多设备竞争 每设备独享点对点链路
    仲裁机制 显式集中仲裁（REQ#/GNT#） 无需仲裁，点对点
    热插拔 不支持 支持（如 PCIe 热插拔 NVMe SSD）

    PCIe 使用差分传输，实现了全双工端到端连接。
