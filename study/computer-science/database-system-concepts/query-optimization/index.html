    查询优化

    优化方法

    基于代价的优化（Cost-based Optimization）
    生成等价的表达式，为每个执行计划标注代价估计，选择代价最小的计划作为最终执行方案。
    启发式优化（Heuristic Optimization）

    使用经验规则重写查询，不依赖代价估计。核心原则：

    • 尽早执行选择（select）操作——减少中间结果规模
    • 尽早执行投影（project）操作——减少中间结果属性数
    • 将选择与连接合并执行——避免先做笛卡尔积再筛选

    等价规则

    关系代数表达式的等价变换是查询优化的理论基础。以下列出全部 13 条规则，\(E\) 表示任意关系代数表达式，\(\sigma\) 为选择，\(\pi\) 为投影，\(\bowtie\) 为连接，\(\times\) 为笛卡尔积。

    规则 1：选择的级联（Select Cascade）

    \[\sigma_{c_1 \wedge c_2 \wedge \cdots \wedge c_n}(E) = \sigma_{c_1}(\sigma_{c_2}(\cdots \sigma_{c_n}(E) \cdots))\]

    复合选择条件可分解为多个选择的级联，便于逐条下推。

    规则 2：选择的交换律（Select Commutativity）

    \[\sigma_{\theta_1}(\sigma_{\theta_2}(E)) = \sigma_{\theta_2}(\sigma_{\theta_1}(E))\]

    选择操作的顺序不影响最终结果，可根据代价自由调整执行顺序。

    规则 3：投影的级联（Project Cascade）

    \[\pi_{L_1}(\pi_{L_2}(\cdots \pi_{L_n}(E) \cdots)) = \pi_{L_1}(E)\]

    其中 \(L_1 \subseteq L_n\)。多层投影可合并为仅保留最终所需属性的一层投影；中间层多余的属性可直接省略。

    规则 4：选择与笛卡尔积/连接的组合

    \[\sigma_{\theta}(E_1 \times E_2) = E_1 \bowtie_{\theta} E_2\]

    将笛卡尔积上的选择条件转化为等值/条件连接，避免先产生巨大中间结果。

    更一般的形式：

    \[\sigma_{\theta_1}(E_1 \bowtie_{\theta_2} E_2) = E_1 \bowtie_{\theta_1 \wedge \theta_2} E_2\]

    已有连接上的额外选择条件可合并到连接条件中。

    规则 5：连接的交换律（Join Commutativity）

    \[E_1 \bowtie_{\theta} E_2 = E_2 \bowtie_{\theta} E_1\]

    自然连接和条件连接均满足交换律，可用于调整连接顺序以使小关系先参与连接。

    规则 6：连接的结合律（Join Associativity）

    自然连接：

    \[(E_1 \bowtie E_2) \bowtie E_3 = E_1 \bowtie (E_2 \bowtie E_3)\]

    一般条件连接要求 \(\theta\) 条件作用于特定实体对：

    \[((E_1 \bowtie_{\theta_1} E_2) \bowtie_{\theta_2 \wedge \theta_3} E_3) = (E_1 \bowtie_{\theta_1 \wedge \theta_3} (E_2 \bowtie_{\theta_2} E_3))\]

    其中 \(\theta_1\) 仅涉及 \(E_1\) 与 \(E_2\) 的属性，\(\theta_2\) 仅涉及 \(E_2\) 与 \(E_3\) 的属性，\(\theta_3\) 仅涉及 \(E_1\) 与 \(E_3\) 的属性。结合律允许灵活选择连接的分组方式。

    规则 7：选择对连接的分配律

    当 \(\theta_1\) 仅涉及 \(E_1\) 的属性，\(\theta_2\) 仅涉及 \(E_2\) 的属性时：

    \[\sigma_{\theta_1 \wedge \theta_2}(E_1 \bowtie_{\theta} E_2) = (\sigma_{\theta_1}(E_1)) \bowtie_{\theta} (\sigma_{\theta_2}(E_2))\]

    更一般的形式（当 \(\theta_1\) 仅涉及 \(E_1\)）：

    \[\sigma_{\theta_1}(E_1 \bowtie_{\theta} E_2) = (\sigma_{\theta_1}(E_1)) \bowtie_{\theta} E_2\]

    选择下推到连接的子表达式中，先过滤再连接，大幅减少中间结果。

    规则 8：投影对连接的分配律

    当投影属性集 \(L_1\) 包含 \(E_1\) 的属性子集 \(L_{E_1}\) 和 \(E_2\) 的属性子集 \(L_{E_2}\)，且连接属性 \(\theta\) 所引用的属性也在 \(L_{E_1} \cup L_{E_2}\) 中时：

    \[\pi_{L_1}(E_1 \bowtie_{\theta} E_2) = \pi_{L_1}(\pi_{L_{E_1}}(E_1) \bowtie_{\theta} \pi_{L_{E_2}}(E_2))\]

    投影可下推到连接的子表达式中，先去除无用属性再连接。

    规则 9：并/交的交换律

    \[E_1 \cup E_2 = E_2 \cup E_1\]
    \[E_1 \cap E_2 = E_2 \cap E_1\]

    规则 10：并/交的结合律

    \[(E_1 \cup E_2) \cup E_3 = E_1 \cup (E_2 \cup E_3)\]
    \[(E_1 \cap E_2) \cap E_3 = E_1 \cap (E_2 \cap E_3)\]

    规则 11：选择对集差/交的分配律

    选择对集差的分配律：

    \[\sigma_{\theta}(E_1 - E_2) = \sigma_{\theta}(E_1) - \sigma_{\theta}(E_2)\]

    简化形式（差集无需对 \(E_2\) 施加选择）：

    \[\sigma_{\theta}(E_1 - E_2) = \sigma_{\theta}(E_1) - E_2\]

    选择对交集的分配律：

    \[\sigma_{\theta}(E_1 \cap E_2) = \sigma_{\theta}(E_1) \cap \sigma_{\theta}(E_2)\]

    规则 12：投影对并的分配律

    \[\pi_{L}(E_1 \cup E_2) = \pi_{L}(E_1) \cup \pi_{L}(E_2)\]

    投影可下推到并集的各子表达式中分别执行。注意：投影不能对集差分配。

    规则 13：投影与选择的交换律

    当选择条件 \(\theta\) 所涉及的属性全部包含在投影属性集 \(L\) 中时：

    \[\pi_{L}(\sigma_{\theta}(E)) = \sigma_{\theta}(\pi_{L}(E))\]

    投影与选择可交换执行顺序；若投影属性集不含选择条件所需的属性，则不能交换。

    查询树

    查询树是关系代数表达式的图形表示：

    查询树（Query Tree）

    一种树形结构，其中：

    • 叶节点：代表基本关系（base relations）
    • 内部节点：代表关系代数操作（选择、投影、连接等）
    • SQL 的执行顺序为自底向上（bottom-up）

    SQL 子句与关系代数操作的对应关系：

    SQL 子句 关系代数操作 说明
    FROM 笛卡尔积 \(\times\) 多表来源转化为笛卡尔积
    WHERE 选择 \(\sigma\) 筛选条件转化为选择操作
    SELECT 投影 \(\pi\) 输出列转化为投影操作

    优化总结

    查询优化的一般原则：

    1. 尽早执行选择：\(\sigma\) 下推，减少中间结果元组数
    2. 尽早执行投影：\(\pi\) 下推，减少中间结果属性数
    3. 将笛卡尔积与选择合并为连接：\(\sigma_{\theta}(E_1 \times E_2) = E_1 \bowtie_{\theta} E_2\)，避免先产生笛卡尔积的巨大中间结果
    4. 合并同一关系上的多个选择/投影：利用级联规则（规则 1、规则 3）将多层操作合并
    5. 合并投影与相邻操作：减少中间结果的属性数
    6. 存储公共子表达式的结果：对重复出现的子表达式，计算一次并缓存结果

    启发式优化步骤

    启发式优化通过等价规则系统地重写查询树，无需代价估计。具体步骤如下：

    步骤 1：构建查询树

    将 SQL 查询转化为初始查询树：FROM 对应笛卡尔积叶节点，WHERE 对应选择节点，SELECT 对应投影节点。

    步骤 2：分解选择条件

    利用选择的级联规则（规则 1），将复合选择条件 \(\sigma_{c_1 \wedge c_2 \wedge \cdots \wedge c_n}\) 分解为级联形式 \(\sigma_{c_1}(\sigma_{c_2}(\cdots \sigma_{c_n}(E) \cdots))\)，使得每个简单条件可以独立下推。

    步骤 3：下推选择操作

    利用选择的交换律（规则 2）和选择对连接的分配律（规则 7），将选择操作尽可能下推到查询树的叶节点附近。目标：让选择在笛卡尔积/连接之前执行，尽早减少中间结果规模。

    步骤 4：下推投影或移除多余投影

    利用投影的级联规则（规则 3）和投影对连接的分配律（规则 8），将投影操作下推；移除不必要的中间投影层。注意保留连接条件所需的属性。

    步骤 5：合并级联的选择与投影

    利用规则 1 和规则 3，将同一关系上连续的多层 \(\sigma\) 或多层 \(\pi\) 合并为单一操作，减少操作次数。

    步骤 6：调整连接顺序

    利用连接的交换律（规则 5）和结合律（规则 6），重新排列连接顺序。原则：小关系优先参与连接，使中间结果尽早缩小。

    步骤 7：合并笛卡尔积与选择为连接

    利用规则 4，将 \(\sigma_{\theta}(E_1 \times E_2)\) 转化为 \(E_1 \bowtie_{\theta} E_2\)，避免先产生笛卡尔积的巨大中间结果后再筛选。

    步骤 8：添加必要的叶节点投影并分组操作

    为每个叶节点（基本关系）添加投影操作，只保留后续操作所需的属性，进一步减少 I/O。将可并行的操作分组，形成最终的执行计划。
